量子力学中的许多基本物理定律都具有连续对称性，而连续对称性的数学语言正是李群及其表示理论。空间旋转对应旋转群，时间平移对应时间演化群，时空变换则与洛伦兹群及其覆盖群有关。量子态通常属于某个复 Hilbert 空间，而对称变换通过该空间上的酉算子表示实现。因此，研究量子系统的对称性，本质上就是研究李群在 Hilbert 空间上的表示。本章将从群表示出发，建立李群表示与量子力学之间的联系，并重点讨论角动量、自旋以及 \(SU(2)\) 与 \(SO(3)\) 的关系。

15.1 量子态与对称变换#

量子力学中，纯态由复 Hilbert 空间 \(\mathcal H\) 中的单位向量表示，但相差一个整体相位的向量对应同一个物理态，即 \(|\psi\rangle\) 与 \(e^{i\theta}|\psi\rangle\) 描述相同的物理状态。因此，物理纯态实际上对应 Hilbert 空间中的一维射线。

对称变换是保持物理规律及可观测量结构的变换。根据 Wigner 定理，保持跃迁概率的变换可以由酉算子或反酉算子实现。对于连续且包含单位元的对称变换，通常考虑酉表示。设 \(G\) 是李群，则其在 Hilbert 空间上的酉表示是一个映射 \(U:G\to\mathcal U(\mathcal H)\)，满足 \(U(gh)=U(g)U(h)\)，其中 \(\mathcal U(\mathcal H)\) 表示 \(\mathcal H\) 上的酉算子群。

在量子力学中，连续对称变换通常要求表示在适当意义下连续。对于有限维 Hilbert 空间，这意味着矩阵元连续；对于无限维 Hilbert 空间，通常要求强连续性，即对任意 \(|\psi\rangle\in\mathcal H\)，映射 \(g\mapsto U(g)|\psi\rangle\) 连续。

15.2 李群表示与李代数表示#

设 \(U:G\to\mathcal U(\mathcal H)\) 是一个强连续酉表示。对李代数元素 \(X\in\mathfrak g\)，考虑一参数子群 \(\exp(tX)\)，则 \(U(\exp(tX))\) 构成一参数酉算子群。根据 Stone 定理，在适当的定义域条件下，存在自伴算子 \(A_X\)，使得

\[ U(\exp(tX))=e^{-itA_X}. \]

这里采用物理学中常用的约定，将无穷小生成元写成自伴算子乘以 \(-i\)。因此，连续对称性的无穷小生成元对应量子力学中的可观测量。

若 \(X,Y\in\mathfrak g\)，则它们的生成元之间满足与李括号相对应的交换关系。具体而言，在共同定义域等适当条件下，

\[ [A_X,A_Y]=iA_{[X,Y]}. \]

这一关系说明，李代数的结构常数直接决定量子力学中对称性生成元的交换关系。

例如，空间旋转的生成元是角动量算子，而时间平移的生成元与 Hamilton 算子有关。它们的交换关系分别反映旋转对称性与时间平移对称性的代数结构。

15.3 空间旋转群与角动量#

三维空间中的旋转由特殊正交群 \(SO(3)\) 描述。其李代数为 \(\mathfrak{so}(3)\)，由所有实反对称 \(3\times3\) 矩阵构成。取三个基元素 \(J_1,J_2,J_3\)，使得

\[ [J_i,J_j]=\sum_k\varepsilon_{ijk}J_k, \]

其中 \(\varepsilon_{ijk}\) 是 Levi-Civita 符号。

在量子力学中，角动量算子 \(L_1,L_2,L_3\) 满足

\[ \boxed{ [L_i,L_j]=i\hbar\sum_k\varepsilon_{ijk}L_k. } \]

这里 \(\hbar\) 是约化普朗克常数。角动量算子是旋转群表示的无穷小生成元，其交换关系正是 \(\mathfrak{so}(3)\) 李代数关系的量子版本。

定义总角动量平方算子 \(L^2=L_1^2+L_2^2+L_3^2\)。由上述交换关系可以证明，\(L^2\) 与每个角动量分量都对易，即 \([L^2,L_i]=0\)。因此，可以选择共同本征态 \(|l,m\rangle\)，满足

\[ L^2|l,m\rangle=\hbar^2l(l+1)|l,m\rangle, \qquad L_3|l,m\rangle=\hbar m|l,m\rangle. \]

对于通常的 \(SO(3)\) 线性表示，\(l\) 取非负整数，\(m=-l,-l+1,\ldots,l\)。相应表示的维数为 \(2l+1\)。

15.4 升降算子与角动量表示#

为了研究角动量代数的不可约表示，定义升降算子

\[ L_\pm=L_1\pm iL_2. \]

利用角动量交换关系，可以得到

\[ [L_3,L_\pm]=\pm\hbar L_\pm, \qquad [L_+,L_-]=2\hbar L_3. \]

因此，若 \(|l,m\rangle\) 是 \(L_3\) 的本征态，则 \(L_+|l,m\rangle\) 与 \(L_-|l,m\rangle\) 分别对应磁量子数增加和减少一个单位的状态。

在适当归一化下，有

\[ L_\pm|l,m\rangle =\hbar\sqrt{l(l+1)-m(m\pm1)} \,|l,m\pm1\rangle. \]

由于表示空间有限维，升降过程必须在某些状态处终止。由此可以推出 \(m\) 的取值范围以及 \(l\) 的量子化条件。

这一结构是角动量表示理论的核心。它说明，有限维不可约表示中的所有状态可以由最高权态或最低权态通过升降算子生成。

15.5 \(SU(2)\) 与 \(SO(3)\)#

前面我们已经证明，\(SU(2)\) 与 \(SO(3)\) 具有同构的李代数，但二者作为李群并不同构。它们之间存在二重覆盖

\[ SU(2)\longrightarrow SO(3), \]

其核为 \(\{\pm I\}\)。

这一差异在量子力学中具有直接物理意义。对于 \(SO(3)\) 的普通线性表示，绕任意轴旋转 \(2\pi\) 后，表示算子必须回到恒等算子。但对于 \(SU(2)\) 的表示，覆盖群中的一个从单位元出发、对应于空间旋转 \(2\pi\) 的路径，其终点是 \(-I\)，而不是 \(I\)。因此，某些 \(SU(2)\) 表示在 \(2\pi\) 旋转下会获得负号，只有在 \(4\pi\) 旋转后才回到原状态向量。

这正是半整数自旋出现的数学原因。自旋为整数的表示可以下降为 \(SO(3)\) 的表示，而半整数自旋的表示只能自然地定义为 \(SU(2)\) 的表示，不能成为 \(SO(3)\) 的普通线性表示。

15.6 \(SU(2)\) 的不可约表示#

\(SU(2)\) 的李代数 \(\mathfrak{su}(2)\) 与角动量代数密切相关。其有限维复不可约表示由一个非负半整数 \(j\) 标记：

\[ j=0,\frac12,1,\frac32,\ldots. \]

对应表示的维数为

\[ \boxed{\dim V_j=2j+1.} \]

表示空间可以取一组基 \(\{|j,m\rangle\}\)，其中 \(m=-j,-j+1,\ldots,j\)。角动量算子满足

\[ J^2|j,m\rangle=\hbar^2j(j+1)|j,m\rangle, \qquad J_3|j,m\rangle=\hbar m|j,m\rangle. \]

当 \(j\) 为整数时，表示中的 \(-I\in SU(2)\) 作用为恒等算子，因此该表示可以下降为 \(SO(3)\) 的表示。当 \(j\) 为半整数时，\(-I\) 作用为负恒等算子，因此不能下降为 \(SO(3)\) 的普通表示。

例如，\(j=\frac12\) 对应二维基本表示，其表示空间为 \(\mathbb C^2\)，这就是自旋 \(1/2\) 粒子的自旋空间。\(j=1\) 对应三维表示，与经典三维向量的旋转表示相联系。

15.7 自旋与轨道角动量#

量子力学中的角动量通常分为轨道角动量与自旋角动量。轨道角动量来自粒子的空间运动，其算子定义为

\[ \mathbf L=\mathbf r\times\mathbf p. \]

在位置表象中，\(\mathbf p=-i\hbar\nabla\)，因此

\[ \mathbf L=-i\hbar\,\mathbf r\times\nabla. \]

它描述波函数在空间旋转下的变换性质。

自旋则是粒子内禀的角动量自由度，并不对应经典意义下粒子绕自身轴旋转。它通过 \(SU(2)\) 的不可约表示刻画。对于自旋 \(1/2\) 粒子，三个自旋算子可以写为

\[ S_i=\frac{\hbar}{2}\sigma_i, \]

其中 \(\sigma_i\) 是 Pauli 矩阵：

\[ \sigma_1= \begin{pmatrix}0&1\\1&0\end{pmatrix}, \quad \sigma_2= \begin{pmatrix}0&-i\\i&0\end{pmatrix}, \quad \sigma_3= \begin{pmatrix}1&0\\0&-1\end{pmatrix}. \]

它们满足

\[ [S_i,S_j]=i\hbar\sum_k\varepsilon_{ijk}S_k. \]

因此，自旋 \(1/2\) 的量子力学结构直接由 \(SU(2)\) 的二维不可约表示给出。

15.8 张量积与角动量耦合#

当一个量子系统由多个子系统组成时，其总 Hilbert 空间通常是各子系统 Hilbert 空间的张量积。若两个系统分别具有自旋 \(j_1,j_2\)，则总系统的旋转表示由两个表示的张量积给出：

\[ V_{j_1}\otimes V_{j_2}. \]

这一张量积表示一般不是不可约的，而可以分解为不可约表示的直和：

\[ \boxed{ V_{j_1}\otimes V_{j_2} \cong \bigoplus_{j=|j_1-j_2|}^{j_1+j_2}V_j. } \]

这里 \(j\) 按单位步长取值。这就是角动量耦合规则。

例如，两个自旋 \(1/2\) 系统的张量积空间维数为 \(2\times2=4\)，其分解为

\[ \frac12\otimes\frac12=1\oplus0. \]

其中三维子空间对应总自旋 \(1\) 的三重态，另一个一维子空间对应总自旋 \(0\) 的单态。

这一分解在原子物理、量子信息和粒子物理中都十分重要。Clebsch–Gordan 系数则描述张量积基与总角动量本征基之间的变换。

15.9 时间平移与 Hamilton 算子#

除空间旋转外，时间平移也是量子力学中的基本连续对称性。若系统的 Hamilton 算子 \(H\) 不显含时间，则时间演化算子满足

\[ U(t)=e^{-iHt/\hbar}. \]

这是一参数酉群，其无穷小生成元为 \(H/\hbar\)，因此 Hamilton 算子可以理解为时间平移群的生成元乘以 \(\hbar\)。

对于一般含时 Hamilton 算子，时间演化不再简单地由单个指数给出，而需要使用时间序指数或 Dyson 展开。这与上一章介绍的 BCH 公式及非交换指数乘法具有密切联系。

时间平移与能量守恒之间的关系则由 Noether 定理解释：当物理系统的动力学规律在时间平移下不变时，相应的守恒量就是能量。类似地，空间旋转对称性对应角动量守恒。

15.10 本章小结#

量子力学中的连续对称性通过李群的酉表示实现，而其无穷小生成元构成相应李代数的表示。空间旋转群 \(SO(3)\) 的李代数给出角动量交换关系，但半整数自旋要求使用其单连通覆盖群 \(SU(2)\) 的表示。\(SU(2)\) 的有限维不可约表示由半整数 \(j\) 分类，维数为 \(2j+1\)，并通过张量积分解描述多个角动量的耦合。时间平移则由 Hamilton 算子生成。由此，李群表示理论为量子力学中的角动量、自旋与守恒律提供了统一的数学框架。

习题#

基础题

  1. 验证 Pauli 矩阵满足 \([\sigma_i,\sigma_j]=2i\sum_k\varepsilon_{ijk}\sigma_k\)。
  2. 利用角动量交换关系推导 \([L^2,L_i]=0\)。
  3. 推导升降算子的交换关系。
  4. 验证自旋 \(1/2\) 表示的维数为 \(2\)。

理论题

  1. 利用升降算子推导有限维不可约角动量表示的维数 \(2j+1\)。
  2. 解释为什么半整数自旋不能成为 \(SO(3)\) 的普通线性表示。
  3. 证明 \(SU(2)\) 的整数自旋表示可以下降为 \(SO(3)\) 的表示。
  4. 推导两个自旋 \(1/2\) 系统的张量积分解。

深入题

  1. 计算自旋 \(1/2\) 在绕任意轴旋转角度 \(\theta\) 时的表示矩阵。
  2. 研究 Clebsch–Gordan 系数，并计算 \(1\otimes\frac12\) 的不可约分解。
  3. 研究 Wigner 的分类思想，了解为什么量子态的对称变换允许酉或反酉实现。
  4. 研究 Lorentz 群的覆盖群 \(SL(2,\mathbb C)\)，了解 Weyl 自旋量与 Dirac 自旋量的表示结构。
