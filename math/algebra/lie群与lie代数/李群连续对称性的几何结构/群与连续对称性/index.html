1.1 为什么研究群？#

数学中有一类问题反复出现：一个对象在某些变换下保持不变，那么这些变换具有什么共同结构？

例如，平面上的圆在绕圆心旋转后保持不变；正方形在旋转 \(90^\circ\) 或关于对称轴反射后仍然与自身重合；欧氏空间中的距离在刚体运动下保持不变。这些变换并非彼此孤立，它们可以进行复合，可以存在恒等变换，也可以撤销。因此，它们自然构成一种代数结构——群（group）。

群论研究的正是这种变换及其复合规律。它不关心对象的具体形状，而是抽取变换背后的抽象代数结构。进一步地，当变换能够连续地依赖某些参数时，我们便进入李群理论。旋转角度可以连续变化，空间平移可以连续变化，量子态也可以在连续对称变换下演化。李群正是描述这类连续对称性的数学语言。

1.2 群的定义#

一个非空集合 \(G\)，若配备二元运算 \((a,b)\mapsto ab\)，并满足以下四条公理，则称 \(G\) 为一个群：

  1. 封闭性： 对任意 \(a,b\in G\)，都有 \(ab\in G\)。
  2. 结合律： 对任意 \(a,b,c\in G\)，都有 \((ab)c=a(bc)\)。
  3. 单位元： 存在 \(e\in G\)，使得对任意 \(a\in G\)，有 \(ea=ae=a\)。
  4. 逆元： 对任意 \(a\in G\)，存在 \(a^{-1}\in G\)，使得 \(aa^{-1}=a^{-1}a=e\)。

这里的运算不一定是数的乘法。例如，矩阵乘法、函数复合以及几何变换的复合都可以作为群运算。

群的单位元是唯一的，且每个元素的逆元也是唯一的。事实上，若 \(e,e’\) 都是单位元，则 \(e=ee’=e’\)；若 \(b,c\) 都是 \(a\) 的逆元，则 \(b=b(ac)=(ba)c=c\)。

若群运算还满足交换律 \(ab=ba\)，则称 \(G\) 为交换群（abelian group），否则称为非交换群。交换性是重要的结构性质：例如实数加法群 \((\mathbb R,+)\) 是交换群，而一般可逆矩阵群在矩阵乘法下通常不是交换群。

1.3 群的典型例子#

例1：整数加法群。 整数集合 \(\mathbb Z\) 在加法下构成群，单位元为 \(0\)，整数 \(n\) 的逆元为 \(-n\)。它是交换群。

例2：非零实数乘法群。 \(\mathbb R^\times=\mathbb R\setminus\{0\}\) 在乘法下构成交换群，单位元为 \(1\)，逆元为 \(x^{-1}=1/x\)。

例3：一般线性群。 记 \(GL(n,\mathbb R)\) 为所有可逆 \(n\times n\) 实矩阵组成的集合。在矩阵乘法下，它构成一个群。单位元是单位矩阵 \(I_n\)，矩阵 \(A\) 的逆元是 \(A^{-1}\)。当 \(n\ge 2\) 时，该群一般是非交换的。

例4：置换群。 集合 \(\{1,\ldots,n\}\) 上所有双射组成的集合，在函数复合下构成群，记为 \(S_n\)。它有 \(n!\) 个元素，称为 \(n\) 次对称群。当 \(n\ge3\) 时，它是非交换群。

例5：旋转群。 三维欧氏空间中所有保持原点不动、保持长度和定向的线性变换构成特殊正交群 \(SO(3)\)。它将在后文详细研究。

这些例子体现了群的不同面貌：有的群是无限离散的，有的群由矩阵构成，有的群则直接描述几何空间中的对称变换。李群理论主要研究其中具有连续几何结构的群。

1.4 子群与群同态#

设 \(G\) 是一个群，\(H\subseteq G\) 非空。若 \(H\) 在 \(G\) 的同一运算下也构成群，则称 \(H\) 为 \(G\) 的子群（subgroup），记作 \(H\le G\)。

一个常用的子群判别法是：非空子集 \(H\subseteq G\) 是子群，当且仅当对任意 \(a,b\in H\)，都有 \(ab^{-1}\in H\)。这个判别法将单位元、封闭性和逆元条件合并为一个条件。

例如，\(SL(n,\mathbb R)=\{A\in GL(n,\mathbb R):\det A=1\}\) 是 \(GL(n,\mathbb R)\) 的子群，因为行列式满足 \(\det(AB)=\det A\det B\)，且 \(\det(A^{-1})=(\det A)^{-1}\)。

群之间还可以通过保持运算的映射联系起来。设 \(G,H\) 是群，映射 \(\varphi:G\to H\) 若满足 \(\varphi(ab)=\varphi(a)\varphi(b)\)，则称为群同态（group homomorphism）。若它是双射，则称为群同构。群同构意味着两个群虽然元素可能完全不同，但具有相同的代数结构。

群同态的核定义为 \(\ker\varphi=\{g\in G:\varphi(g)=e_H\}\)，其像定义为 \(\operatorname{Im}\varphi=\{\varphi(g):g\in G\}\)。核总是正规子群，而像总是子群。这些概念将在后续研究李群之间的映射、覆盖群与商群时反复出现。

1.5 群作用与对称性#

群不仅可以抽象地研究，还可以通过作用在集合上来描述具体的对称变换。

设 \(G\) 是群，\(X\) 是集合。若存在映射 \(G\times X\to X\)，记作 \((g,x)\mapsto g\cdot x\)，满足 \(e\cdot x=x\) 以及 \((gh)\cdot x=g\cdot(h\cdot x)\)，则称 \(G\) 在 \(X\) 上有一个群作用（group action）。

群作用将抽象群元素解释为对集合元素实施的变换。例如，旋转群 \(SO(3)\) 作用于 \(\mathbb R^3\)，方式是 \(x\mapsto Rx\)，其中 \(R\in SO(3)\)。由于正交矩阵保持内积，故 \(\|Rx\|=\|x\|\)。因此，\(SO(3)\) 的作用保持以原点为中心的球面不变。

对于 \(x\in X\)，集合 \(G\cdot x=\{g\cdot x:g\in G\}\) 称为 \(x\) 的轨道（orbit）；集合 \(G_x=\{g\in G:g\cdot x=x\}\) 称为 \(x\) 的稳定子群（stabilizer）。轨道描述一个点在群作用下能够到达的位置，稳定子群则描述保持该点不动的变换。

群作用是现代几何的重要工具。许多几何空间都可以表示为群作用下的轨道空间或商空间。例如，球面可以表示为 \(SO(3)/SO(2)\)：三维旋转群作用于单位球面，某一点的稳定子群同构于平面旋转群 \(SO(2)\)。

1.6 从离散对称性到连续对称性#

有限群和离散群能够描述有限或离散的对称变换，但许多几何与物理问题中的对称性具有连续参数。例如，平面旋转由角度 \(\theta\) 参数化，旋转角度可以连续变化。二维旋转矩阵为

\[ R(\theta)= \begin{pmatrix} \cos\theta&-\sin\theta\\ \sin\theta&\cos\theta \end{pmatrix}. \]

它满足 \(R(\theta_1)R(\theta_2)=R(\theta_1+\theta_2)\)，并且 \(R(0)=I\)、\(R(\theta)^{-1}=R(-\theta)\)。因此，所有二维旋转构成一个群，记为 \(SO(2)\)。

更重要的是，矩阵 \(R(\theta)\) 随参数 \(\theta\) 光滑变化。于是 \(SO(2)\) 不仅是一个群，还是一个一维光滑流形。群结构与流形结构兼容，正是李群的基本思想。

再看三维旋转。一个矩阵 \(R\) 属于 \(SO(3)\)，当且仅当 \(R^TR=I\) 且 \(\det R=1\)。这意味着 \(SO(3)\) 是矩阵空间中的一个具有光滑结构的集合。它是一个三维李群，而不是普通意义上的线性空间。

连续对称性还可以通过**一参数子群（one-parameter subgroup）**描述。若光滑映射 \(\gamma:\mathbb R\to G\) 满足 \(\gamma(s+t)=\gamma(s)\gamma(t)\)，且 \(\gamma(0)=e\)，则称其为一参数子群。二维旋转群中的 \(\gamma(\theta)=R(\theta)\) 就是一个例子。一参数子群将连续变化的对称变换组织为一个满足群运算规律的光滑曲线。

这引出一个核心问题：能否通过研究一参数子群在单位元处的切向量，来理解整个群的局部结构？答案是肯定的。这个切空间将成为李代数，而一参数子群则将由矩阵指数或更一般的指数映射来描述。下一章将正式建立李群的定义。

1.7 本章小结#

群通过抽象代数公理描述变换的复合结构；群作用将群元素解释为集合上的对称变换；轨道与稳定子分别刻画变换能够到达的位置和保持不动的对称性。当群本身还具有光滑流形结构，且群乘法与求逆运算均光滑时，我们便得到李群。连续对称性由此成为代数结构与微分几何的交汇点。

习题#

基础题

  1. 验证 \((\mathbb R,+)\)、\((\mathbb R^\times,\cdot)\) 与 \(GL(n,\mathbb R)\) 分别构成群。
  2. 证明群的单位元唯一，且每个元素的逆元唯一。
  3. 证明 \(SL(n,\mathbb R)\) 是 \(GL(n,\mathbb R)\) 的子群。
  4. 证明 \(SO(2)\) 在矩阵乘法下构成群。

理论题

  1. 证明子群判别法：非空子集 \(H\subseteq G\) 是子群，当且仅当对任意 \(a,b\in H\)，有 \(ab^{-1}\in H\)。
  2. 设 \(\varphi:G\to H\) 是群同态，证明 \(\ker\varphi\) 是 \(G\) 的正规子群。
  3. 证明群作用所定义的轨道构成 \(X\) 的一个划分。
  4. 证明稳定子群 \(G_x\) 是 \(G\) 的子群。

深入题

  1. 证明 \(SO(2)\) 与圆周 \(S^1\) 在群结构与拓扑结构上同构。
  2. 证明 \(SO(3)\) 的维数为 \(3\)。提示：考虑正交条件 \(R^TR=I\) 对矩阵自由度的约束。
  3. 研究 \(SO(3)\) 作用于单位球面 \(S^2\) 的轨道与稳定子群，并证明 \(S^2\cong SO(3)/SO(2)\)。
  4. 证明二维旋转矩阵满足 \(R(\theta)=\exp(\theta J)\)，其中 \(J=\begin{pmatrix}0&-1\\1&0\end{pmatrix}\)。思考矩阵指数为何能够自然描述连续旋转。
