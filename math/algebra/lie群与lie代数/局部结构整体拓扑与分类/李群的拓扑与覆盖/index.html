第十一章 李群的拓扑与覆盖

李代数刻画李群的局部结构，但无法完全决定李群的整体拓扑。上一章已经提到，\(SU(2)\) 与 \(SO(3)\) 具有同构的李代数，却不是同构的李群。这种差异来自李群的整体拓扑，尤其是连通性、单连通性与覆盖结构。本章将介绍李群的基本拓扑性质，说明单连通李群在李群理论中的特殊地位，并建立李代数与李群之间更完整的对应关系。

11.1 连通性与道路连通性#

设 \(G\) 是拓扑群。若 \(G\) 不能表示为两个非空不交开集的并，则称 \(G\) 是连通的。若任意两个点都可以通过一条连续曲线连接，则称 \(G\) 是道路连通的。对于一般拓扑空间，连通性与道路连通性并不等价；但对于流形，由于局部道路连通性，连通分支与道路连通分支一致。因此，李群的连通性也可以通过道路连通性来理解。

李群的单位连通分支记为 \(G_0\)，即包含单位元的连通分支。由于群乘法与求逆映射连续，\(G_0\) 是 \(G\) 的正规开子群。商群 \(G/G_0\) 称为李群的分支群，它记录了李群的连通分支结构。

对于连通李群，任意元素都可以通过一条连续曲线与单位元连接。但这并不意味着任意元素都能写成单个指数 \(e^X\)：指数映射的满射性是比连通性更强的性质。

11.2 单连通李群#

连通拓扑空间 \(X\) 若满足任意闭曲线都可以连续收缩为一点，则称为单连通空间。更严格地说，单连通要求 \(X\) 连通且其基本群平凡，即 \(\pi_1(X)=0\)。

单连通性刻画了空间中是否存在不可收缩的闭曲线。对于李群，这一性质尤其重要，因为它决定了李群覆盖结构的复杂程度，也影响李代数表示能否积分为群表示。

例如，\(SU(2)\) 作为流形同胚于三维球面 \(S^3\)，因而是单连通的；而 \(SO(3)\) 同胚于实射影三维空间 \(\mathbb{RP}^3\)，其基本群为 \(\mathbb Z/2\mathbb Z\)，因此不是单连通的。

11.3 基本群与覆盖空间#

设 \(X\) 是道路连通空间，选定基点 \(x_0\)。所有以 \(x_0\) 为起点和终点的闭曲线，在保持基点的连续变形意义下构成等价类。这些等价类在曲线复合运算下构成群，称为 \(X\) 的基本群，记作 \(\pi_1(X,x_0)\)。对于道路连通且局部道路连通的空间，不同基点处的基本群彼此同构，因此通常简记为 \(\pi_1(X)\)。

覆盖映射是拓扑空间之间的一种特殊映射。连续满射 \(p:\widetilde X\to X\) 称为覆盖映射，若对每个 \(x\in X\)，存在一个开邻域 \(U\)，使得 \(p^{-1}(U)\) 是若干个互不相交的开集之并，并且 \(p\) 在每个开集上都是到 \(U\) 的同胚。此时 \(\widetilde X\) 称为 \(X\) 的覆盖空间。

若覆盖空间 \(\widetilde X\) 本身单连通，则称其为 \(X\) 的万有覆盖空间（universal covering space）。对于连通、道路连通且半局部单连通的空间，万有覆盖空间存在且在适当意义下唯一。流形满足这些条件，因此每个连通李群都有万有覆盖空间。

11.4 李群的万有覆盖群#

覆盖空间理论可以进一步应用于李群。设 \(G\) 是连通李群，其万有覆盖空间记为 \(\widetilde G\)。可以证明，\(\widetilde G\) 自然具有李群结构，并且存在覆盖同态

\[ p:\widetilde G\longrightarrow G. \]

其核 \(\ker p\) 是 \(\widetilde G\) 的离散正规子群。由于 \(\widetilde G\) 连通，离散正规子群必然包含于中心，因此 \(\ker p\subseteq Z(\widetilde G)\)。

于是，任意连通李群都可以表示为其单连通覆盖李群对一个离散中心子群取商：

\[ \boxed{G\cong\widetilde G/\Gamma,} \]

其中 \(\Gamma\) 是 \(\widetilde G\) 的离散中心子群。这一结论说明，连通李群的整体拓扑差异可以通过其单连通覆盖群及离散中心子群来理解。

更重要的是，覆盖映射在单位元处的微分是李代数同构。因此，\(G\) 与 \(\widetilde G\) 具有同构的李代数。换言之，同一个李代数可以对应多个不同的连通李群，而单连通李群在这一对应中具有唯一性。

11.5 李代数与单连通李群的对应#

李群与李代数之间存在一个基本定理：

Lie 第三基本定理： 每个有限维实李代数都同构于某个单连通李群的李代数，并且该单连通李群在李群同构意义下唯一。

因此，有限维实李代数与单连通李群之间存在一一对应关系。对于任意有限维实李代数 \(\mathfrak g\)，都存在唯一的单连通李群 \(\widetilde G\)，使得 \(\operatorname{Lie}(\widetilde G)\cong\mathfrak g\)。

若不要求李群单连通，则这一对应不再唯一。所有具有相同李代数的连通李群，都可以通过其单连通积分群对离散中心子群取商得到。这正是李代数只能决定局部结构、不能决定整体拓扑的严格体现。

此外，李群同态与李代数同态之间也有相应的积分定理：若 \(G\) 是连通李群、\(H\) 是单连通李群，则任意李代数同态 \(\varphi:\mathfrak g\to\mathfrak h\) 都可以唯一积分为李群同态 \(F:G\to H\)，满足 \(dF_e=\varphi\)。这里单连通条件施加在目标群 \(H\) 上，而不是源群 \(G\) 上。

11.6 经典例子：\(SU(2)\) 与 \(SO(3)\)#

\(SU(2)\) 是所有满足 \(U^\dagger U=I\)、\(\det U=1\) 的复 \(2\times2\) 矩阵构成的李群。其李代数为

\[ \mathfrak{su}(2) =\{X\in M_2(\mathbb C):X^\dagger=-X,\ \operatorname{tr}X=0\}. \]

它是三维实李代数。

另一方面，\(SO(3)\) 是三维实空间中的旋转群，其李代数 \(\mathfrak{so}(3)\) 也是三维实李代数。事实上，存在李代数同构 \(\mathfrak{su}(2)\cong\mathfrak{so}(3)\)。

然而，两个李群的拓扑结构不同。\(SU(2)\) 同胚于 \(S^3\)，是单连通的；\(SO(3)\) 同胚于 \(\mathbb{RP}^3\)，其基本群为 \(\mathbb Z/2\mathbb Z\)。因此二者并不同构。

它们之间存在一个二重覆盖同态

\[ \boxed{SU(2)\longrightarrow SO(3),} \]

其核为 \(\{I,-I\}\)。于是

\[ SO(3)\cong SU(2)/\{\pm I\}. \]

这也说明 \(SU(2)\) 是 \(SO(3)\) 的万有覆盖群。

这一关系在量子力学中尤为重要。\(SO(3)\) 描述经典三维空间中的旋转，而 \(SU(2)\) 与自旋表示密切相关。二者具有相同的无穷小旋转结构，却允许不同的整体表示理论。

11.7 其他经典李群的拓扑#

不同经典李群具有不同的连通性与基本群。几个重要例子如下：

李群连通性基本群
\(GL(n,\mathbb R)\)不连通（\(n\geq1\)）单位分支的基本群依 \(n\) 而定
\(SL(n,\mathbb R)\)连通（\(n\geq2\)）依 \(n\) 而定
\(SO(2)\)连通\(\mathbb Z\)
\(SO(3)\)连通\(\mathbb Z/2\mathbb Z\)
\(SU(n)\)连通、单连通平凡群
\(U(n)\)连通\(\mathbb Z\)
\(Sp(n)\)连通、单连通平凡群

这里 \(Sp(n)\) 表示紧辛群，即保持标准四元数 Hermitian 结构的紧李群；不同文献对辛群的记号可能存在差异。需要注意，\(GL(n,\mathbb R)\) 的两个连通分支由行列式的正负决定，而 \(SL(n,\mathbb R)\) 在 \(n\geq2\) 时是连通的。

对于 \(SO(2)\)，它同胚于圆周 \(S^1\)，所以基本群为 \(\mathbb Z\)，其万有覆盖群为加法群 \((\mathbb R,+)\)，覆盖映射可写为 \(t\mapsto R(t)\)。这也是最简单的李群覆盖例子。

11.8 本章小结#

李群的整体拓扑由连通性、基本群与覆盖结构等性质描述。每个连通李群都有唯一的单连通万有覆盖群，其核是离散中心子群，因此连通李群可以表示为单连通李群对离散中心子群取商。Lie 第三基本定理进一步说明，每个有限维实李代数都对应唯一的单连通李群；但若不要求单连通，则同一个李代数可能对应多个不同的李群。\(SU(2)\) 与 \(SO(3)\) 的二重覆盖是这一理论最重要的例子之一。

习题#

基础题

  1. 证明李群的单位连通分支 \(G_0\) 是正规开子群。
  2. 计算圆周群 \(S^1\) 的基本群，并描述其万有覆盖空间。
  3. 证明覆盖同态的微分在单位元处是李代数同构。
  4. 证明连通李群的离散正规子群必然包含于中心。

理论题

  1. 证明若 \(G\) 是连通李群，则其万有覆盖空间具有自然的李群结构。
  2. 解释为什么两个具有同构李代数的连通李群具有相同的局部结构，却未必具有相同的整体拓扑。
  3. 证明 \(SO(2)\) 的万有覆盖群为 \((\mathbb R,+)\)，覆盖映射为 \(t\mapsto R(t)\)。
  4. 研究 \(U(n)\) 的基本群，并解释行列式映射在其中的作用。

深入题

  1. 构造 \(SU(2)\to SO(3)\) 的二重覆盖映射，并验证其核为 \(\{\pm I\}\)。
  2. 研究 \(SL(2,\mathbb R)\) 的万有覆盖群，说明它与 \(SL(2,\mathbb R)\) 的拓扑差异。
  3. 证明单连通李群之间的李代数同态可以唯一积分为李群同态，并思考目标群单连通这一条件的作用。
  4. 研究连通紧李群的基本群与其中心之间的关系，了解紧李群的普遍覆盖结构。
