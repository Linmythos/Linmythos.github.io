第 2 讲：外测度与 Lebesgue 测度的构造

上一讲我们引入了 σ-代数，并说明它规定了哪些集合能够被测量。但还有一个问题没有解决：测度本身究竟如何构造？

我们当然可以直接规定区间 \((a,b)\) 的测度为 \(b-a\)，但这还远远不够。我们需要一种方法，将区间长度推广到任意复杂的集合，同时保证非负性、单调性和可列可加性。

Lebesgue 的思想非常巧妙：不直接尝试测量一个复杂集合，而是先用简单的区间覆盖它，再寻找所有覆盖所需的最小总长度。

这就是外测度的基本思想。

2.1 从区间覆盖出发#

考虑实数轴上的一个任意子集 \(E\subseteq\mathbb R\)。我们希望定义它的长度。

如果 \(E\) 本身是一个区间，那么长度已经有自然定义。例如，\((a,b)\) 的长度为 \(b-a\)。

但如果 \(E\) 是一个非常复杂的集合，我们可以尝试用一列开区间 \(\{I_n\}_{n=1}^{\infty}\) 覆盖它，即要求 \(E\subseteq\bigcup_{n=1}^{\infty}I_n\)。

对于每一种覆盖，我们计算区间长度之和 \(\sum_{n=1}^{\infty}|I_n|\)。不同覆盖可能产生不同的总长度。自然地，我们希望找到所有可能覆盖中最小的总长度。

于是定义：

\(\displaystyle m^*(E)=\inf\left\{\sum_{n=1}^{\infty}|I_n|:\ E\subseteq\bigcup_{n=1}^{\infty}I_n,\ I_n\text{ 为开区间}\right\}.\)

这里的 \(m^*(E)\) 称为集合 \(E\) 的 Lebesgue 外测度（Lebesgue outer measure）。

注意，外测度可以取 \(+\infty\)。如果 \(E\) 无界，或者无法用有限总长度的区间族覆盖，那么外测度可能为无穷大。

这个定义的关键在于：我们不要求集合本身具有任何规则结构，只要求它能够被区间覆盖。

因此，外测度可以定义在实数轴的所有子集上。

2.2 外测度的三个基本性质#

外测度虽然还不是我们最终想要的测度，但它已经满足三个重要性质。

定理 2.1（外测度的基本性质） 对任意 \(A,B\subseteq\mathbb R\)，有：

  1. 非负性：\(m^*(A)\geq0\)，且 \(m^*(\varnothing)=0\)；
  2. 单调性：若 \(A\subseteq B\)，则 \(m^*(A)\leq m^*(B)\)；
  3. 可列次可加性：\(m^*(\bigcup_{n=1}^{\infty}A_n)\leq\sum_{n=1}^{\infty}m^*(A_n)\)。

前两个性质比较直接。空集可以被任意短的区间覆盖，因此外测度为零；若 \(A\subseteq B\)，那么覆盖 \(B\) 的区间族也覆盖 \(A\)，所以 \(m^*(A)\leq m^*(B)\)。

第三个性质最重要。对于每个 \(A_n\)，我们分别选择一个区间覆盖，使其总长度尽可能接近 \(m^*(A_n)\)。将这些覆盖全部合并，就得到 \(\bigcup_n A_n\) 的一个覆盖。由此便得到可列次可加性。

这里有一个细节：为什么我们得到的是不等式，而不是等式？

因为不同集合之间可能存在重叠。分别覆盖每个集合时，可能重复计算了某些区域。因此，外测度的可列次可加性并不意味着它已经具有测度所要求的可列可加性。

我们还需要进一步筛选集合。

2.3 外测度与区间长度一致#

外测度构造得是否合理，首先要检查它能否恢复我们熟悉的区间长度。

定理 2.2 对任意区间 \(I\subseteq\mathbb R\)，其外测度等于区间长度，即 \(m^*(I)=|I|\)。

这里允许 \(I\) 是开区间、闭区间、半开区间，也允许它是无界区间。

证明的核心是两个方向：

  • 用区间自身（或稍作扩张的开区间）覆盖它，得到 \(m^*(I)\leq |I|\)；
  • 利用区间覆盖的紧致性性质，对有限子覆盖应用区间长度的基本不等式，得到 \(m^*(I)\geq |I|\)。

第二个方向需要注意：对于闭区间，可以利用 Heine–Borel 定理从任意开覆盖中提取有限子覆盖；对于一般开区间，则先取其内部的紧子区间，再令端点逐渐逼近原区间端点。

因此，外测度确实保留了通常的区间长度。

2.4 为什么需要 Carathéodory 可测性条件？#

现在我们已经有了定义在所有子集上的外测度。但它只有可列次可加性，并不保证可列可加性。

Carathéodory 提出了一个极其自然的判定条件。

定义 2.1（Carathéodory 可测集） 称集合 \(E\subseteq\mathbb R\) 是 \(m^*\)-可测的，如果对于任意集合 \(A\subseteq\mathbb R\)，都有

\(\displaystyle m^*(A)=m^*(A\cap E)+m^*(A\setminus E).\)

这就是 Carathéodory 可测性条件。

它的含义非常直观：无论拿什么集合 \(A\) 来测量，将它沿着 \(E\) 分成内部部分与外部部分之后，总测度必须恰好等于两部分测度之和。

由外测度的可列次可加性，我们总有

\(m^*(A)\leq m^*(A\cap E)+m^*(A\setminus E)\)。

因此，真正需要要求的是反方向的不等式。换句话说，Carathéodory 条件要求集合 \(E\) 不会在测度意义上造成无法控制的切割。

2.5 Carathéodory 定理#

现在给出测度论中最重要的构造定理之一。

定理 2.3（Carathéodory 定理） 设 \(m^*\) 是定义在 \(X\) 的所有子集上的外测度。所有满足 Carathéodory 条件的集合构成一个 σ-代数，记为 \(\mathcal M\)。并且，外测度在 \(\mathcal M\) 上的限制是一个测度。

也就是说：

  1. \(X\in\mathcal M\)；
  2. 若 \(E\in\mathcal M\)，则 \(E^c\in\mathcal M\)；
  3. 若 \(E_1,E_2,\ldots\in\mathcal M\)，则 \(\bigcup_nE_n\in\mathcal M\)；
  4. 对两两不交的可测集 \(E_n\)，有 \(m^*(\bigcup_nE_n)=\sum_nm^*(E_n)\)。

这一定理极其深刻。我们从一个只满足次可加性的外测度出发，通过一个几何分割条件，最终得到真正的测度空间。

其证明的核心思想是反复使用 Carathéodory 条件，将一个集合分割成多个部分，再利用外测度的次可加性和集合的互不相交性建立等式。

完整证明涉及对有限并、可列并的逐步处理，可以作为本讲的核心习题。

2.6 Lebesgue 可测集与 Lebesgue 测度#

现在我们可以正式定义 Lebesgue 测度。

对于实数轴上的 Lebesgue 外测度 \(m^*\)，满足 Carathéodory 条件的集合称为 Lebesgue 可测集。

所有 Lebesgue 可测集构成一个 σ-代数，记作 \(\mathcal L(\mathbb R)\)。

在这个 σ-代数上定义 \(m(E)=m^*(E)\)，便得到 Lebesgue 测度。

于是我们获得了一个测度空间：

\((\mathbb R,\mathcal L(\mathbb R),m)\)。

这里三个对象分别是：

  • \(\mathbb R\)：底层集合；
  • \(\mathcal L(\mathbb R)\)：可测集合构成的 σ-代数；
  • \(m\)：定义在可测集上的 Lebesgue 测度。

这就是后续 Lebesgue 积分理论的起点。

2.7 Borel 测度与 Lebesgue 测度#

上一讲我们已经介绍了 Borel σ-代数 \(\mathcal B(\mathbb R)\)。

由于所有开区间都是 Lebesgue 可测集，因此所有 Borel 集也都是 Lebesgue 可测集，即 \(\mathcal B(\mathbb R)\subseteq\mathcal L(\mathbb R)\)。

但反过来并不成立。

Lebesgue σ-代数比 Borel σ-代数更大。一个重要的事实是：Lebesgue σ-代数包含所有 Borel 零测集的任意子集。

例如，Cantor 集是 Borel 集，且其 Lebesgue 测度为零。因此，它的任意子集都是 Lebesgue 可测的，即使某些子集并不是 Borel 集。

这说明 Lebesgue 测度具有完备性。

定义 2.2（完备测度） 如果测度空间满足：对于任意零测集 \(N\)，其任意子集 \(A\subseteq N\) 都是可测集，那么称该测度空间是完备的。

Lebesgue 测度是完备测度，而定义在 Borel σ-代数上的 Lebesgue 测度限制通常并不完备。

这一区别在后续 \(L^p\) 空间的构造中十分重要。

2.8 一个经典例子：有理数集的测度#

我们已经知道 \(\mathbb Q\) 在 \(\mathbb R\) 中稠密，但稠密并不意味着测度很大。

由于 \(\mathbb Q\) 是可数集，可以将其写成 \(\mathbb Q=\{q_1,q_2,\ldots\}\)。

对于任意 \(\varepsilon>0\)，我们可以为每个 \(q_n\) 取一个长度小于 \(\varepsilon/2^n\) 的开区间 \(I_n\)，使得 \(q_n\in I_n\)。于是这些区间覆盖整个有理数集，且总长度小于 \(\varepsilon\)。

因此 \(m^*(\mathbb Q)\leq\varepsilon\)。由于 \(\varepsilon\) 任意，得到 \(m(\mathbb Q)=0\)。

这给出一个非常重要的结论：

稠密性与测度大小是完全不同的概念。

有理数在实数轴上处处稠密，但它的 Lebesgue 测度为零；无理数同样处处稠密，却具有满测度，即 \(m(\mathbb R\setminus\mathbb Q)=+\infty\)，而在区间 \([0,1]\) 中其测度为 1。

这也提醒我们：拓扑结构与测度结构描述的是空间的不同性质。前者关注邻域、连续性和极限；后者关注集合的大小、积分和几乎处处性质。

本讲习题#

习题 2.1 根据外测度的定义，证明 \(m^*(\varnothing)=0\)、单调性和可列次可加性。

习题 2.2 证明任意可数集的 Lebesgue 外测度为零。进一步证明，任意可数集都是 Lebesgue 可测集。

习题 2.3 证明：若 \(E\subseteq\mathbb R\) 是零测集，则它的任意子集都是 Lebesgue 可测集。

习题 2.4 证明任意开区间都是 Lebesgue 可测集。提示：利用区间覆盖与区间长度的基本性质，验证 Carathéodory 条件。

习题 2.5 证明：所有 Lebesgue 可测集构成一个 σ-代数。可以先证明有限并与补集封闭，再利用外测度的可列次可加性处理可列并。

习题 2.6 证明：若 \(E\) 是 Lebesgue 可测集，则其补集也是 Lebesgue 可测集。

习题 2.7 证明：有理数集 \(\mathbb Q\) 在 \([0,1]\) 中的测度为零，而无理数集在 \([0,1]\) 中的测度为 1。

习题 2.8 证明：若 \(E\) 是可测集且 \(m(E)<\infty\)，则对任意 \(\varepsilon>0\)，存在开集 \(G\supseteq E\)，使得 \(m(G\setminus E)<\varepsilon\)。这称为 Lebesgue 测度的外正则性。

本讲核心： 外测度通过区间覆盖将长度推广到任意集合；Carathéodory 条件从所有子集中筛选出适合测量的集合；最终得到 Lebesgue σ-代数及其上的完备测度。整个构造体现了现代数学的一种典型方法：先在较大的对象类上建立一个宽松的结构，再通过适当条件筛选出具有良好代数性质的子类。
