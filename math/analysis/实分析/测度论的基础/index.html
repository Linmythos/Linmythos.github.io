第一篇：测度论的基础

1 讲：集合运算与集合序列

上一讲我们提出了一个问题：如何将区间长度推广到一般集合？要回答这个问题，首先必须明确我们究竟允许对集合进行哪些运算，以及这些运算在无穷情形下具有怎样的性质。 测度论并不只是给集合赋予一个数值。它首先需要建立一套能够稳定处理可列集合运算的结构。尤其是可列并、可列交以及集合序列的极限，它们构成了后续可测性与测度构造的基础。 1.1 集合的基本运算 设 \(X\) 是一个非空集合，\(A,B\subseteq X\)。 我们首先回顾几种基本运算。 并集：\(A\cup B=\{x:x\in A\text{ 或 }x\in B\}\)。 交集：\(A\cap B=\{x:x\in A\text{ 且 }x\in B\}\)。 差集：\(A\setminus B=\{x:x\in A,\ x\notin B\}\)。 补集：\(A^c=X\setminus A\)。 其中，补集依赖于全集 \(X\)。因此，讨论集合的补集时，必须明确所处的全集。 两个集合若满足 \(A\cap B=\varnothing\)，称它们互不相交或不交（disjoint）。 集合运算满足熟悉的代数规律。例如，交换律、结合律和分配律： \(A\cup B=B\cup A,\quad A\cap B=B\cap A\)； \(A\cup(B\cup C)=(A\cup B)\cup C\)； \(A\cap(B\cup C)=(A\cap B)\cup(A\cap C)\)。 此外，还有 De Morgan 定律：\((A\cup B)^c=A^c\cap B^c\)，以及 \((A\cap B)^c=A^c\cup B^c\)。 这些规律不仅对有限集合成立，也将自然推广到任意指标集所标记的集合族。 1.2 可列集合运算 设 \(\{A_n\}_{n=1}^{\infty}\) 是 \(X\) 中的一列子集。 我们定义它们的可列并与可列交： \(\displaystyle \bigcup_{n=1}^{\infty}A_n=\{x\in X:\exists n,\ x\in A_n\}\)； ...

第 0 讲：从 Riemann 积分到 Lebesgue 积分

0.1 积分究竟在计算什么？ 微积分中，我们最早接触的积分是 Riemann 积分。对于定义在闭区间 \([a,b]\) 上的函数 \(f\)，我们将区间分割为若干小区间，选择每个小区间中的一点 \(\xi_i\)，构造 Riemann 和：\(S(P)=\sum_{i=1}^{n}f(\xi_i)\Delta x_i\)。当分割的最大长度趋于零，并且 Riemann 和趋于一个与取点方式无关的极限时，我们便定义 \(\int_a^b f(x)\,dx\) 为这个极限。 这一构造具有非常直观的几何意义：当 \(f\geq0\) 时，积分描述曲线 \(y=f(x)\) 与横轴围成的面积。但从数学结构上看，Riemann 积分实际上是通过对定义域进行分割，再利用函数在各个小区间上的取值来逼近积分。 这里有一个值得追问的问题：为什么一定要分割定义域？能不能反过来，从函数值的分布出发构造积分？ 这正是 Lebesgue 积分的出发点。 0.2 Riemann 积分的局限 先看一个经典例子。定义函数 \(f:[0,1]\to\mathbb R\)： \[ f(x)= \begin{cases} 1,&x\in\mathbb Q,\\ 0,&x\notin\mathbb Q. \end{cases} \] 这就是 Dirichlet 函数。 由于有理数与无理数在实数中都稠密，所以无论我们取多么小的区间，在其中都能找到有理数和无理数。因此，函数在任何区间上的上确界都是 1，下确界都是 0。 于是，任意分割下的 Darboux 上和均为 1，下和均为 0。两者永远不能趋于同一个极限。因此，Dirichlet 函数在 \([0,1]\) 上不是 Riemann 可积的。 然而，从直觉上看，有理数虽然稠密，却在整个实数区间中只占据极其微小的部分。我们希望能够严谨地表达这种意义上的“大小”。 这就引出了测度论。 0.3 从长度到测度 对于区间 \([a,b]\)，我们自然地将其长度定义为 \(b-a\)。但对于更复杂的集合，例如 Cantor 集、有理数集或某些不规则集合，我们应当如何定义它们的大小？ 测度论的基本思想是：将长度的概念推广到一般集合。 我们希望建立一个集合函数 \(\mu\)，使其满足： ...

第 2 讲：外测度与 Lebesgue 测度的构造

上一讲我们引入了 σ-代数，并说明它规定了哪些集合能够被测量。但还有一个问题没有解决：测度本身究竟如何构造？ 我们当然可以直接规定区间 \((a,b)\) 的测度为 \(b-a\)，但这还远远不够。我们需要一种方法，将区间长度推广到任意复杂的集合，同时保证非负性、单调性和可列可加性。 Lebesgue 的思想非常巧妙：不直接尝试测量一个复杂集合，而是先用简单的区间覆盖它，再寻找所有覆盖所需的最小总长度。 这就是外测度的基本思想。 2.1 从区间覆盖出发 考虑实数轴上的一个任意子集 \(E\subseteq\mathbb R\)。我们希望定义它的长度。 如果 \(E\) 本身是一个区间，那么长度已经有自然定义。例如，\((a,b)\) 的长度为 \(b-a\)。 但如果 \(E\) 是一个非常复杂的集合，我们可以尝试用一列开区间 \(\{I_n\}_{n=1}^{\infty}\) 覆盖它，即要求 \(E\subseteq\bigcup_{n=1}^{\infty}I_n\)。 对于每一种覆盖，我们计算区间长度之和 \(\sum_{n=1}^{\infty}|I_n|\)。不同覆盖可能产生不同的总长度。自然地，我们希望找到所有可能覆盖中最小的总长度。 于是定义： \(\displaystyle m^*(E)=\inf\left\{\sum_{n=1}^{\infty}|I_n|:\ E\subseteq\bigcup_{n=1}^{\infty}I_n,\ I_n\text{ 为开区间}\right\}.\) 这里的 \(m^*(E)\) 称为集合 \(E\) 的 Lebesgue 外测度（Lebesgue outer measure）。 注意，外测度可以取 \(+\infty\)。如果 \(E\) 无界，或者无法用有限总长度的区间族覆盖，那么外测度可能为无穷大。 这个定义的关键在于：我们不要求集合本身具有任何规则结构，只要求它能够被区间覆盖。 因此，外测度可以定义在实数轴的所有子集上。 2.2 外测度的三个基本性质 外测度虽然还不是我们最终想要的测度，但它已经满足三个重要性质。 定理 2.1（外测度的基本性质） 对任意 \(A,B\subseteq\mathbb R\)，有： 非负性：\(m^*(A)\geq0\)，且 \(m^*(\varnothing)=0\)； 单调性：若 \(A\subseteq B\)，则 \(m^*(A)\leq m^*(B)\)； 可列次可加性：\(m^*(\bigcup_{n=1}^{\infty}A_n)\leq\sum_{n=1}^{\infty}m^*(A_n)\)。 前两个性质比较直接。空集可以被任意短的区间覆盖，因此外测度为零；若 \(A\subseteq B\)，那么覆盖 \(B\) 的区间族也覆盖 \(A\)，所以 \(m^*(A)\leq m^*(B)\)。 ...

第 3 讲：Lebesgue 可测集的性质与测度空间

上一讲，我们通过外测度与 Carathéodory 条件构造了 Lebesgue 测度。现在需要进一步研究这个测度空间本身：哪些集合具有零测度？可测集能否被开集和紧集逼近？为什么测度论特别重视完备性？ 这些问题看似属于集合论的技术细节，实际上决定了 Lebesgue 积分能否稳定地处理函数极限，也是 \(L^p\) 空间得以建立的基础。 3.1 测度的基本性质 设 \((X,\mathcal F,\mu)\) 是一个测度空间，其中 \(X\) 是底层集合，\(\mathcal F\) 是 σ-代数，\(\mu\) 是定义在 \(\mathcal F\) 上的测度。 首先回顾测度的定义：\(\mu:\mathcal F\to[0,+\infty]\) 满足 \(\mu(\varnothing)=0\)，并且对于任意两两不交的可测集列 \(\{E_n\}\)，有 \(\mu(\bigcup_{n=1}^{\infty}E_n)=\sum_{n=1}^{\infty}\mu(E_n)\)。 由此可以推出一系列重要性质。 定理 3.1（单调性） 若 \(A,B\in\mathcal F\)，且 \(A\subseteq B\)，则 \(\mu(A)\leq\mu(B)\)。 证明只需注意 \(B=A\cup(B\setminus A)\)，且这两个集合不交，因此 \(\mu(B)=\mu(A)+\mu(B\setminus A)\geq\mu(A)\)。 定理 3.2（有限次可加性） 若 \(A_1,\ldots,A_n\) 两两不交，则 \(\mu(\bigcup_{k=1}^n A_k)=\sum_{k=1}^n\mu(A_k)\)。 这是可列可加性的直接推论。 定理 3.3（次可加性） 对任意可测集列 \(\{A_n\}\)，有 \(\mu(\bigcup_nA_n)\leq\sum_n\mu(A_n)\)。 证明时，可以将集合列改写成互不相交的集合列：令 \(B_1=A_1\)，\(B_n=A_n\setminus\bigcup_{k=1}^{n-1}A_k\)。于是 \(B_n\subseteq A_n\)，且 \(B_n\) 两两不交，并且 \(\bigcup_nB_n=\bigcup_nA_n\)。利用可列可加性和单调性即可得到结论。 这三个性质将在后续证明中反复出现。 3.2 零测集与几乎处处 定义 3.1（零测集） 若可测集 \(E\) 满足 \(\mu(E)=0\)，则称 \(E\) 为零测集（null set）。 ...

第 4 讲：可测函数

前面三讲，我们建立了测度论的集合基础：从外测度构造 Lebesgue 测度，再通过 σ-代数确定可测集合，并研究了零测集、完备性与正则性。 现在，我们从集合转向函数。 在经典微积分中，函数主要通过连续性、可微性等性质进行研究。但在 Lebesgue 积分理论中，一个更基础的问题是：函数是否能够与测度结构相容？ 这就是可测函数（measurable function）的概念。它是从测度论走向积分理论的关键桥梁。 4.1 从集合的可测性到函数的可测性 设 \((X,\mathcal F)\) 是一个可测空间，即 \(X\) 是一个集合，\(\mathcal F\) 是其上的 σ-代数。考虑一个实值函数 \(f:X\to\mathbb R\)。 我们希望通过 \(f\) 将实数轴上的集合拉回到定义域 \(X\)。对于任意集合 \(B\subseteq\mathbb R\)，定义其原像： \(f^{-1}(B)=\{x\in X:f(x)\in B\}\)。 这里需要注意：原像运算并不要求 \(f\) 可逆。即使 \(f\) 不是单射，也可以定义原像。 定义 4.1（可测函数） 若对于任意 Borel 集 \(B\in\mathcal B(\mathbb R)\)，都有 \(f^{-1}(B)\in\mathcal F\)，则称 \(f\) 是 \(\mathcal F\)-可测函数。 这个定义看起来抽象，但其核心思想非常简单： 一个函数是可测的，当且仅当实数轴上的 Borel 集经过函数原像运算后，仍然得到定义域中的可测集。 为什么采用原像，而不是像集？ 因为原像运算具有良好的集合代数性质： \(f^{-1}(B^c)=(f^{-1}(B))^c\)； \(f^{-1}(\bigcup_nB_n)=\bigcup_nf^{-1}(B_n)\)； \(f^{-1}(\bigcap_nB_n)=\bigcap_nf^{-1}(B_n)\)。 因此，原像能够保持补集、可列并和可列交结构。这使得 σ-代数与函数之间自然建立联系。 4.2 可测性的等价刻画 定义 4.1 要求任意 Borel 集的原像可测。但实际使用时，我们通常不需要检查所有 Borel 集。 ...
