第 13 讲：乘积测度与 Fubini 定理

在前面的讲次中，我们主要研究单个测度空间上的积分。但许多重要问题天然涉及多个变量：二重积分、联合概率分布、多粒子系统、函数空间上的积分等。此时，我们需要回答一个基本问题：如何将两个测度空间组合成一个新的测度空间？

例如，已知区间上的 Lebesgue 测度，我们希望在平面上定义面积；已知两个概率空间，我们希望构造联合概率空间。这些问题都指向同一个数学结构——乘积测度（product measure）。

乘积测度建立之后，一个极其重要的问题随之出现：对于二元函数 \(f(x,y)\)，什么时候可以交换积分次序？什么时候二重积分可以写成迭代积分？这便是 Tonelli 定理与 Fubini 定理所解决的问题。

1. 两个测度空间的乘积#

设 \((X,\mathcal A,\mu)\) 与 \((Y,\mathcal B,\nu)\) 是两个测度空间。我们首先构造集合空间 \(X\times Y\)。

对于 \(A\in\mathcal A\)、\(B\in\mathcal B\)，集合 \(A\times B\) 称为可测矩形。由所有可测矩形生成的 σ-代数记为 \(\mathcal A\otimes\mathcal B\)，称为乘积 σ-代数。

这里需要注意：\(\mathcal A\otimes\mathcal B\) 是 \(X\times Y\) 上的 σ-代数，它由矩形集合生成，但一般不应直接将其与某个更大的 σ-代数混为一谈。

我们的目标是在 \(\mathcal A\otimes\mathcal B\) 上定义测度，使每个可测矩形满足

\[ (\mu\times\nu)(A\times B)=\mu(A)\nu(B). \]

这个要求十分自然：在平面上，矩形的面积等于长乘宽；在概率论中，独立事件的联合概率等于各自概率的乘积。

不过，这个公式首先只规定了矩形的测度。如何将它扩展到整个乘积 σ-代数，才是测度论真正需要解决的问题。

2. 从矩形到乘积测度#

假设 \(\mu\) 与 \(\nu\) 都是 σ-有限测度。也就是说，存在可测集合列 \(X_n\in\mathcal A\)、\(Y_n\in\mathcal B\)，满足 \(X=\bigcup_nX_n\)、\(Y=\bigcup_nY_n\)，并且每个 \(\mu(X_n)\)、\(\nu(Y_n)\) 都有限。

在这一条件下，可以通过测度扩张定理构造乘积测度。

首先，在可测矩形上定义集合函数

\[ \pi(A\times B)=\mu(A)\nu(B). \]

在适当处理有限测度矩形及其有限不交并之后，可以证明这一集合函数具有可列可加性，并利用 Carathéodory 外测度构造，将其扩张为 \(\mathcal A\otimes\mathcal B\) 上的测度。

所得测度记为 \(\mu\times\nu\)，满足

\[ (\mu\times\nu)(A\times B) = \mu(A)\nu(B). \]

在两个测度均为 σ-有限的条件下，这个乘积测度在乘积 σ-代数上唯一。

因此，我们得到一个新的测度空间：

\[ (X\times Y,\mathcal A\otimes\mathcal B,\mu\times\nu). \]

这里的 σ-有限性并非无关紧要的技术条件。它保证了乘积测度的标准构造与唯一性理论具有良好的性质。若不满足 σ-有限性，乘积测度的构造可能出现更复杂的情况。

3. Lebesgue 测度的乘积#

取 \(X=\mathbb R^m\)、\(Y=\mathbb R^n\)，分别配备 Lebesgue 测度 \(m_m\)、\(m_n\)。它们都是 σ-有限测度，因此可以构造乘积测度。

自然地，我们希望这个乘积测度就是 \(\mathbb R^{m+n}\) 上的 Lebesgue 测度。

事实上，在适当识别 \(\mathbb R^m\times\mathbb R^n\cong\mathbb R^{m+n}\) 后，有

\[ m_{m+n}=m_m\times m_n. \]

例如，在平面上，矩形 \(A\times B\) 的面积就是 \(m_1(A)m_1(B)\)。更一般的可测集合，其高维体积则由这一乘积测度统一描述。

这说明我们熟悉的多维 Lebesgue 测度并不是与一维测度完全独立地定义出来的，而是可以从低维测度通过乘积结构构造得到。

4. 可测函数的截面#

设 \(E\subseteq X\times Y\)。对于固定的 \(x\in X\)，定义集合

\[ E_x=\{y\in Y:(x,y)\in E\}. \]

称 \(E_x\) 为 \(E\) 在 \(x\) 处的截面。

类似地，对固定的 \(y\in Y\)，定义 \(E^y=\{x\in X:(x,y)\in E\}\)。

直观地说，截面就是用一条固定坐标的方式切割集合。例如，平面区域 \(E\subseteq\mathbb R^2\) 在固定横坐标 \(x\) 处的截面，就是该区域与直线 \(x=\text{常数}\) 的交集所对应的纵向部分。

一个重要结论是：若 \(E\in\mathcal A\otimes\mathcal B\)，则对每个 \(x\in X\)，都有 \(E_x\in\mathcal B\)；同样，对每个 \(y\in Y\)，都有 \(E^y\in\mathcal A\)。

这一性质可以从矩形集合出发证明。对于矩形 \(A\times B\)，其截面为

\[ (A\times B)_x= \begin{cases} B,&x\in A,\\ \varnothing,&x\notin A. \end{cases} \]

截面运算又与可列并、可列交和补集相容，因此由生成 σ-代数的定义，结论成立。

5. 截面测度与可测函数#

对乘积空间中的集合 \(E\)，我们希望研究函数 \(x\mapsto\nu(E_x)\)。

如果 \(E=A\times B\)，那么

\[ \nu(E_x)=\mathbf1_A(x)\nu(B). \]

显然，这是一个可测函数。

更一般地，在 \(\mu,\nu\) 为 σ-有限测度的条件下，有如下重要结论：

定理。 若 \(E\in\mathcal A\otimes\mathcal B\)，则函数 \(x\mapsto\nu(E_x)\) 是 \(\mathcal A\)-可测的，并且

\[ (\mu\times\nu)(E) = \int_X\nu(E_x)\,d\mu(x). \]

这个公式称为乘积测度的截面公式。

它揭示了一个非常深刻的结构：一个乘积空间中集合的测度，可以通过对各个截面的测度积分得到。

对于平面区域 \(E\)，这正是我们熟悉的面积计算思想：固定一个横坐标，测量相应纵向截面的长度，再对横坐标积分。

例如，考虑单位正方形中的三角形区域 \(E=\{(x,y):0\le y\le x\le1\}\)。固定 \(x\in[0,1]\)，其截面为 \(E_x=[0,x]\)，因此

\[ (m_2)(E) = \int_0^1m_1(E_x)\,dx = \int_0^1x\,dx = \frac12. \]

这便从测度论角度解释了三角形面积公式。

6. Tonelli 定理：非负函数的迭代积分#

集合的截面公式可以推广到非负可测函数。

定理（Tonelli 定理）。 设 \((X,\mathcal A,\mu)\)、\((Y,\mathcal B,\nu)\) 是 σ-有限测度空间。若 \(f:X\times Y\to[0,\infty]\) 是关于乘积 σ-代数可测的非负函数，则：

  1. 对几乎所有 \(x\in X\)，函数 \(y\mapsto f(x,y)\) 可测；
  2. 函数 \(x\mapsto\int_Yf(x,y)\,d\nu(y)\) 可测；
  3. 有

\[ \boxed{ \int_{X\times Y}f\,d(\mu\times\nu) = \int_X\left(\int_Yf(x,y)\,d\nu(y)\right)d\mu(x) } \]

并且反过来交换积分次序也成立：

\[ \int_{X\times Y}f\,d(\mu\times\nu) = \int_Y\left(\int_Xf(x,y)\,d\mu(x)\right)d\nu(y). \]

这里允许积分取值为 \(+\infty\)。

Tonelli 定理的关键在于：非负性使我们能够使用单调收敛定理，而不必预先假设积分有限。

证明思路。 首先对非负简单函数证明结论。若 \(f=\mathbf1_{A\times B}\)，那么结论就是乘积测度的定义：

\[ \int_{X\times Y}\mathbf1_{A\times B}\,d(\mu\times\nu) = \mu(A)\nu(B). \]

而迭代积分给出的也是同一个值。

利用简单函数的有限线性组合，可以将结论推广到非负简单函数。再取非负简单函数列 \(s_n\uparrow f\)，由单调收敛定理，

\[ \int_{X\times Y}s_n\,d(\mu\times\nu) \uparrow \int_{X\times Y}f\,d(\mu\times\nu). \]

另一方面，对截面积分再次使用单调收敛定理，即可将简单函数情形的结论推广到一般非负可测函数。

完整证明还需要处理乘积 σ-代数上可测函数的截面可测性，以及迭代积分函数的可测性。这些性质可以通过对简单函数逼近与单调类论证建立。

7. Fubini 定理：可积函数的积分次序交换#

Tonelli 定理允许非负函数的积分取无穷大。但在实际分析中，我们还经常遇到有正有负的函数，或者复值函数。

此时，仅仅知道函数可测还不够。为了保证积分次序交换成立，我们需要绝对可积性。

定理（Fubini 定理）。 设 \((X,\mathcal A,\mu)\)、\((Y,\mathcal B,\nu)\) 是 σ-有限测度空间，且 \(f:X\times Y\to\mathbb C\) 是乘积可测函数。若

\[ \int_{X\times Y}|f|\,d(\mu\times\nu)<\infty, \]

则：

  1. 对几乎所有 \(x\in X\)，函数 \(y\mapsto f(x,y)\) 属于 \(L^1(Y,\nu)\)；
  2. 对几乎所有 \(y\in Y\)，函数 \(x\mapsto f(x,y)\) 属于 \(L^1(X,\mu)\)；
  3. 两个迭代积分均存在，且

\[ \boxed{ \int_{X\times Y}f\,d(\mu\times\nu) = \int_X\left(\int_Yf(x,y)\,d\nu(y)\right)d\mu(x) = \int_Y\left(\int_Xf(x,y)\,d\mu(x)\right)d\nu(y) } \]

这就是 Fubini 定理。

证明思路。 由于 \(|f|\ge0\)，可以先对 \(|f|\) 使用 Tonelli 定理，得到

\[ \int_X\left(\int_Y|f(x,y)|\,d\nu(y)\right)d\mu(x) = \int_{X\times Y}|f|\,d(\mu\times\nu)<\infty. \]

因此，内层积分 \(\int_Y|f(x,y)|\,d\nu(y)\) 对几乎所有 \(x\) 都有限。这说明几乎所有截面函数都是 \(L^1\) 函数。

接着将 \(f\) 分解为实部与虚部，再分别分解为正部与负部。对这些非负函数使用 Tonelli 定理，最后利用积分的线性性即可得到 Fubini 公式。

因此，Fubini 定理可以理解为：先用 Tonelli 定理控制绝对值，再利用正负部分分解处理一般可积函数。

8. Tonelli 与 Fubini 的区别#

两条定理的结论形式相似，但适用条件不同。

比较Tonelli 定理Fubini 定理
函数条件非负可测绝对可积
积分是否允许无穷大允许不允许绝对积分发散
主要工具单调收敛定理Tonelli 定理与积分线性性
核心作用非负积分的迭代计算交换可积函数的积分次序

特别要注意：可积性不是一个可以随意省略的技术条件。

若函数既有正值又有负值，而其绝对值不可积，那么两个迭代积分可能分别存在，却不相等；也可能其中一个存在而另一个不存在。

下面的经典例子将说明这一点。

9. 积分次序为什么不能随意交换？#

考虑 \(\mathbb N\times\mathbb N\) 上的函数

\[ a_{mn}= \begin{cases} 1,&m=n,\\ -1,&m=n+1,\\ 0,&\text{其他情况}. \end{cases} \]

这里使用计数测度，因此二重积分对应双重级数。

先固定 \(m\)，考察 \(\sum_{n=1}^\infty a_{mn}\)。当 \(m=1\) 时，和为 \(1\)；当 \(m\ge2\) 时，和为 \(1-1=0\)。因此

\[ \sum_{m=1}^\infty \left(\sum_{n=1}^\infty a_{mn}\right)=1. \]

但如果先固定 \(n\)，则当 \(n=1\) 时，列和为 \(1-1=0\)；对每个 \(n\ge2\)，列和也为 \(1-1=0\)。因此

\[ \sum_{n=1}^\infty \left(\sum_{m=1}^\infty a_{mn}\right)=0. \]

两种求和次序得到不同结果。

这并不违反 Fubini 定理，因为

\[ \sum_{m,n=1}^\infty|a_{mn}|=\infty. \]

该级数不绝对收敛，因此不满足 Fubini 定理的条件。

这个例子揭示了一个重要事实：交换无限求和次序与交换积分次序，本质上都需要控制绝对收敛或非负性。

10. 多重积分与高维积分#

现在回到最初的问题：如何计算多重积分？

设 \(f\) 是 \(\mathbb R^2\) 上的可积函数，那么 Fubini 定理允许我们写成

\[ \int_{\mathbb R^2}f(x,y)\,dx\,dy = \int_{\mathbb R} \left(\int_{\mathbb R}f(x,y)\,dy\right)dx. \]

在适当条件下，也可以交换积分顺序。

例如，在矩形区域 \(R=[a,b]\times[c,d]\) 上，若 \(f\) 连续，则 \(f\) 绝对可积，并且

\[ \int_Rf(x,y)\,dx\,dy = \int_a^b\int_c^df(x,y)\,dy\,dx. \]

这就是经典微积分中的二重积分迭代计算公式。

Lebesgue 理论的优势在于，它将这一结论推广到一般可测函数，而不再局限于连续函数或 Riemann 可积函数。

进一步地，对多个 σ-有限测度空间，可以反复构造乘积测度，并在绝对可积或非负可测条件下使用 Fubini–Tonelli 定理，将高维积分分解为多重迭代积分。

11. 乘积测度与概率论#

乘积测度在概率论中具有直接的解释。

设 \((\Omega_1,\mathcal F_1,P_1)\) 与 \((\Omega_2,\mathcal F_2,P_2)\) 是两个概率空间。它们的乘积空间配备乘积概率测度 \(P_1\times P_2\)。

对于事件 \(A\in\mathcal F_1\)、\(B\in\mathcal F_2\)，有

\[ (P_1\times P_2)(A\times B)=P_1(A)P_2(B). \]

这正是两个随机变量独立时联合事件概率的乘积公式。

更一般地，若 \(X,Y\) 是两个随机变量，它们的联合分布可以被理解为某个乘积空间上的概率测度，联合期望则是乘积空间上的积分。

对于非负随机变量，Tonelli 定理允许我们交换期望与积分；对于绝对可积的随机变量，Fubini 定理则保证迭代期望与联合期望相等。

因此，概率论中许多关于独立性、条件期望与联合分布的计算，都可以在乘积测度的框架下得到统一理解。

12. 本讲的结构总结#

本讲的理论脉络可以概括为：

  • 从可测矩形出发，构造乘积 σ-代数；
  • 利用测度扩张定理构造乘积测度；
  • 通过截面将集合的测度转化为积分；
  • 用 Tonelli 定理处理非负可测函数；
  • 用 Fubini 定理处理绝对可积函数；
  • 将多重积分、联合概率与迭代积分统一到乘积测度框架中。

其中最重要的逻辑关系是：

乘积测度提供多变量积分的基础，Tonelli 定理处理非负函数，Fubini 定理处理绝对可积函数。

习题#

1. 乘积 σ-代数。 证明：若 \(E\in\mathcal A\otimes\mathcal B\)，则对任意 \(x\in X\)，其截面 \(E_x\in\mathcal B\)。提示：先对矩形集合证明，再利用生成 σ-代数的性质。

2. 矩形上的乘积测度。 设 \(\mu,\nu\) 是 σ-有限测度，证明乘积测度满足 \((\mu\times\nu)(A\times B)=\mu(A)\nu(B)\)。

3. 截面公式。 设 \(E\in\mathcal A\otimes\mathcal B\)，利用 Tonelli 定理证明 \((\mu\times\nu)(E)=\int_X\nu(E_x)\,d\mu(x)\)。

4. Tonelli 定理。 对非负简单函数证明迭代积分公式，再利用单调收敛定理推广到一般非负可测函数。

5. Fubini 定理。 设 \(f\in L^1(X\times Y)\)，证明几乎所有截面 \(f(x,\cdot)\) 都属于 \(L^1(Y)\)，并证明相应的迭代积分公式。

6. 积分次序交换。 计算 \(\int_0^1\int_0^1(x+y)^2\,dx\,dy\)，分别按照两种积分次序进行计算，并验证结果一致。

7. 绝对可积性。 构造一个二元函数，使其两个迭代积分均存在，但交换积分次序后结果不同。可以从本讲的双重级数例子出发，尝试构造对应的可测函数。

8. 概率论应用。 设 \(X,Y\) 是独立的非负随机变量，证明在适当的可测性条件下，\(\mathbb E[XY]=\mathbb E[X]\mathbb E[Y]\)，允许期望取 \(+\infty\)。

9. 思考题。 为什么 Tonelli 定理只要求非负性，而 Fubini 定理要求绝对可积性？从正负部分分解与积分的可列可加性出发，解释这两种条件的本质区别。
