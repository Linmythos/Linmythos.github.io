前面我们已经建立了 Lebesgue 积分、\(L^p\) 空间、分布理论与 Fourier 分析。本讲将把这些理论汇集起来，研究现代偏微分方程（PDE）的基本语言：Sobolev 空间与弱解。

经典微分方程通常要求解具有足够高阶的连续导数，但许多实际问题中的解并不光滑。例如，物理系统中的介质界面可能导致解的导数发生跳跃；椭圆型方程的解也可能只有有限阶弱导数。

如果坚持要求经典解，就可能排除大量具有实际意义的解。

现代 PDE 的基本策略是：放宽对解的光滑性要求，将微分方程转化为积分恒等式，再利用泛函分析研究其存在性、唯一性与正则性。

这一策略的核心工具就是 Sobolev 空间。

1. 从经典导数到弱导数#

设 \(\Omega\subset\mathbb R^n\) 是开集，\(f\in L^1_{\mathrm{loc}}(\Omega)\)。

如果 \(f\) 具有经典偏导数，那么对任意测试函数 \(\varphi\in C_c^\infty(\Omega)\)，分部积分得到

\[ \int_\Omega \partial_i f\,\varphi\,dx = -\int_\Omega f\,\partial_i\varphi\,dx. \]

这里没有边界项，因为 \(\varphi\) 具有紧支撑。

注意，右侧只涉及 \(f\) 本身，而不涉及它的经典导数。

因此，我们可以反过来定义导数。

定义（弱导数）。 若存在 \(g\in L^1_{\mathrm{loc}}(\Omega)\)，使得对任意 \(\varphi\in C_c^\infty(\Omega)\)，都有

\[ \boxed{ \int_\Omega g\varphi\,dx = -\int_\Omega f\,\partial_i\varphi\,dx, } \]

则称 \(g\) 是 \(f\) 关于第 \(i\) 个变量的弱导数，记为 \(\partial_i f=g\)。

这个定义有两个重要特点：

第一，它不要求 \(f\) 具有经典导数。

第二，弱导数在几乎处处意义下唯一。

事实上，若 \(g_1,g_2\in L^1_{\mathrm{loc}}\) 都满足上述关系，则

\[ \int_\Omega(g_1-g_2)\varphi\,dx=0 \]

对所有测试函数成立。由局部可积函数诱导分布的单射性，得到 \(g_1=g_2\) 几乎处处。

因此，弱导数虽然通过积分定义，却仍然具有良好的唯一性。

2. 一个例子：绝对值函数#

考虑

\[ f(x)=|x|. \]

它在 \(x=0\) 处不可导，但在其他位置可导：

\[ f’(x)= \begin{cases} -1,&x<0,\\ 1,&x>0. \end{cases} \]

令 \(g(x)=\operatorname{sgn}(x)\)，其中 \(g(0)\) 的取值任意。

我们验证 \(g\) 是 \(f\) 的弱导数。

对任意 \(\varphi\in C_c^\infty(\mathbb R)\)，有

\[ \begin{aligned} -\int_{\mathbb R}|x|\varphi’(x)\,dx &= -\int_{-\infty}^0(-x)\varphi’(x)\,dx\\ &\quad-\int_0^\infty x\varphi’(x)\,dx. \end{aligned} \]

分别分部积分，边界项在原点相互抵消，得到

\[ -\int_{\mathbb R}|x|\varphi’(x)\,dx = \int_{\mathbb R}\operatorname{sgn}(x)\varphi(x)\,dx. \]

所以

\[ \boxed{D|x|=\operatorname{sgn}(x)} \]

在弱导数意义下成立。

这说明经典不可导点并不必然妨碍弱微分。

3. Sobolev 空间的定义#

现在可以正式定义 Sobolev 空间。

设 \(\Omega\subset\mathbb R^n\) 为开集，\(1\le p\le\infty\)，\(k\in\mathbb N\)。

定义

\[ W^{k,p}(\Omega) \]

为所有满足以下条件的函数等价类 \(u\)：

  • \(u\in L^p(\Omega)\)；
  • 对每个多重指标 \(\alpha\)，只要 \(|\alpha|\le k\)，其弱导数 \(D^\alpha u\) 都属于 \(L^p(\Omega)\)。

这里多重指标为 \(\alpha=(\alpha_1,\ldots,\alpha_n)\)，并定义

\[ D^\alpha = \partial_1^{\alpha_1}\cdots \partial_n^{\alpha_n}. \]

对于 \(1\le p<\infty\)，定义范数

\[ \boxed{ \|u\|_{W^{k,p}} = \left( \sum_{|\alpha|\le k} \|D^\alpha u\|_p^p \right)^{1/p}. } \]

当 \(p=\infty\) 时，定义

\[ \|u\|_{W^{k,\infty}} = \max_{|\alpha|\le k} \|D^\alpha u\|_\infty. \]

特别地，

\[ W^{0,p}(\Omega)=L^p(\Omega). \]

而

\[ W^{1,p}(\Omega) = \{u\in L^p(\Omega):D_i u\in L^p(\Omega),\ i=1,\ldots,n\}. \]

Sobolev 空间将函数本身的可积性与其弱导数的可积性放在同一个框架中。

当 \(p=2\) 时，通常记

\[ H^k(\Omega)=W^{k,2}(\Omega). \]

由于 \(L^2\) 是 Hilbert 空间，\(H^k\) 也具有自然的 Hilbert 空间结构。

4. Sobolev 空间是 Banach 空间#

定理。 对任意开集 \(\Omega\subset\mathbb R^n\)，以及 \(1\le p\le\infty\)、\(k\in\mathbb N\)，\(W^{k,p}(\Omega)\) 在上述范数下是 Banach 空间。

证明的核心是：如果 \((u_m)\) 是 Sobolev 范数下的 Cauchy 列，那么对每个 \(|\alpha|\le k\)，数列

\[ D^\alpha u_m \]

都在 \(L^p(\Omega)\) 中收敛。

因此存在 \(v_\alpha\in L^p(\Omega)\)，使得

\[ D^\alpha u_m\to v_\alpha \quad\text{in }L^p. \]

特别地，令 \(u=v_0\)。

接下来需要证明 \(v_\alpha\) 确实是 \(u\) 的弱导数。

对任意测试函数 \(\varphi\)，有

\[ \int_\Omega D^\alpha u_m\,\varphi\,dx = (-1)^{|\alpha|} \int_\Omega u_mD^\alpha\varphi\,dx. \]

令 \(m\to\infty\)，利用 \(L^p\) 收敛以及测试函数的有界性和紧支撑性，可以得到

\[ \int_\Omega v_\alpha\varphi\,dx = (-1)^{|\alpha|} \int_\Omega uD^\alpha\varphi\,dx. \]

因此 \(v_\alpha=D^\alpha u\) 是 \(u\) 的弱导数。

所以 \(u\in W^{k,p}(\Omega)\)，并且 \(u_m\to u\) 于 Sobolev 范数。

这证明了完备性。

因此，Sobolev 空间是研究弱解的自然 Banach 空间。

5. Sobolev 空间的光滑逼近#

一个自然的问题是：Sobolev 函数是否可以通过光滑函数逼近？

答案在适当条件下是肯定的。

对于任意 \(u\in W^{k,p}(\mathbb R^n)\)，其中 \(1\le p<\infty\)，可以找到一列光滑函数 \(u_m\in C^\infty(\mathbb R^n)\)，使得

\[ u_m\to u \quad\text{in }W^{k,p}(\mathbb R^n). \]

通常的构造是先截断，再卷积平滑。

第一步，选择光滑截断函数 \(\chi_R\)，使其在较大的球内等于 \(1\)，在更远处为零。令

\[ u_R=\chi_Ru. \]

当 \(R\to\infty\) 时，\(u_R\to u\) 于 \(W^{k,p}\)。

第二步，选择光滑近似恒等核 \(\rho_\varepsilon\)，令

\[ u_{R,\varepsilon}=u_R*\rho_\varepsilon. \]

由于卷积与弱导数可以交换，并且近似恒等核在 \(L^p\) 中具有逼近性质，因此

\[ u_{R,\varepsilon}\to u_R \quad\text{in }W^{k,p}. \]

综合两步即可得到光滑逼近。

这说明 Sobolev 函数虽然不一定经典光滑，但在 Sobolev 范数意义下，可以由光滑函数任意逼近。

需要注意，在一般开集上，\(C_c^\infty(\Omega)\) 是否在整个 \(W^{k,p}(\Omega)\) 中稠密，取决于边界与空间的具体定义。通常它在 \(W_0^{k,p}(\Omega)\) 中稠密，而对一般 Sobolev 函数，需要使用适当的延拓定理。

6. 零边界值与 \(W_0^{1,p}\)#

偏微分方程通常还涉及边界条件。

例如，Poisson 方程

\[ -\Delta u=f \]

可能要求

\[ u|_{\partial\Omega}=0. \]

但 Sobolev 函数不一定具有经典连续代表元，因此不能总是直接谈论边界上的逐点取值。

一个自然的方法是定义

\[ W_0^{1,p}(\Omega) = \overline{C_c^\infty(\Omega)}^{\,W^{1,p}}. \]

也就是说，\(W_0^{1,p}\) 是紧支撑光滑函数在 \(W^{1,p}\) 范数下的闭包。

它可以理解为具有零边界迹的 Sobolev 函数空间，尤其在边界足够规则时，这一解释与迹定理相吻合。

对于 \(p=2\)，记为

\[ H_0^1(\Omega)=W_0^{1,2}(\Omega). \]

它是求解齐次 Dirichlet 边界条件问题的自然函数空间。

7. Poincaré 不等式#

对于零边界值函数，有一个非常重要的不等式。

定理（Poincaré 不等式）。 设 \(\Omega\subset\mathbb R^n\) 是有界区域，并满足适当的几何条件。则存在常数 \(C>0\)，使得对任意 \(u\in W_0^{1,p}(\Omega)\)，有

\[ \boxed{ \|u\|_{L^p(\Omega)} \le C\|\nabla u\|_{L^p(\Omega)}. } \]

这说明对于零边界值函数，函数本身的大小可以由其梯度控制。

其几何直觉是：若函数在边界上为零，那么它在内部的取值不能任意偏离零而同时保持梯度很小。

例如，在一维区间 \(\Omega=(0,L)\) 上，若 \(u\in C_c^\infty(0,L)\)，则

\[ u(x)=\int_0^xu’(t)\,dt. \]

由 Hölder 不等式，

\[ |u(x)| \le x^{1-1/p}\|u’\|_p. \]

进一步积分即可得到 Poincaré 不等式。

通过稠密性，可以将结论推广到 \(W_0^{1,p}\)。

对于 \(p=2\)，Poincaré 不等式说明

\[ \|u\|_{H_0^1} \]

与

\[ \|\nabla u\|_2 \]

定义等价范数。

因此，在 \(H_0^1(\Omega)\) 上，梯度范数本身就足以描述函数的完整大小。

8. Sobolev 嵌入定理#

Sobolev 空间的一个核心问题是：弱导数的可积性，能否推出函数具有更强的连续性或可积性？

答案由 Sobolev 嵌入定理给出。

定理（Sobolev 嵌入定理的基本形式）。 设 \(\Omega\subset\mathbb R^n\) 是有界 Lipschitz 区域，且 \(1\le p<n\)。则

\[ W^{1,p}(\Omega) \hookrightarrow L^{p^*}(\Omega), \]

其中

\[ \boxed{ p^*=\frac{np}{n-p}. } \]

这里符号 \(\hookrightarrow\) 表示连续嵌入，即存在常数 \(C>0\)，使得

\[ \|u\|_{p^*} \le C\|u\|_{W^{1,p}}. \]

这意味着一阶弱导数属于 \(L^p\)，会迫使函数本身具有更高的可积性。

例如，在三维空间中，取 \(p=2\)，则

\[ p^*=\frac{3\cdot2}{3-2}=6. \]

因此

\[ H^1(\Omega)\hookrightarrow L^6(\Omega). \]

这个结果在三维量子力学与非线性 PDE 中非常重要，因为它允许我们控制波函数的 \(L^6\) 范数，从而处理某些非线性项。

当 \(p=n\) 时，情况发生变化。此时不再有一个有限的临界指数 \(p^*\)，但在有界区域上可以得到对任意有限 \(q\) 的相应嵌入结论（需要适当的区域条件）。

当 \(p>n\) 时，函数具有更强的正则性，能够嵌入 Hölder 连续函数空间。

9. Morrey 嵌入定理#

进一步，当 \(p>n\) 时，有：

定理（Morrey 嵌入定理）。 设 \(\Omega\) 是有界 Lipschitz 区域，且 \(p>n\)。则

\[ W^{1,p}(\Omega)\hookrightarrow C^{0,\alpha}(\overline\Omega), \]

其中

\[ \alpha=1-\frac np. \]

这里 \(C^{0,\alpha}\) 表示 Hölder 连续函数空间，即存在常数 \(C\)，使得

\[ |u(x)-u(y)| \le C|x-y|^\alpha. \]

这说明当弱导数的可积性足够强时，Sobolev 函数甚至具有连续代表元。

例如，在三维空间中，若 \(p=6\)，则

\[ \alpha=1-\frac36=\frac12. \]

因此 \(W^{1,6}\) 函数具有 \(1/2\)-Hölder 连续代表元。

这一结论将积分意义下的微分控制转化为逐点正则性。

10. Poisson 方程的弱形式#

现在进入本讲的核心应用。

考虑有界区域 \(\Omega\subset\mathbb R^n\) 上的 Poisson 方程：

\[ \begin{cases} -\Delta u=f,&x\in\Omega,\\ u=0,&x\in\partial\Omega. \end{cases} \]

经典解要求 \(u\) 至少具有二阶导数。但如果我们只假设

\[ u\in H_0^1(\Omega), \]

就不能直接写出经典的 \(\Delta u\)。

于是，我们将方程乘以测试函数 \(v\)，并进行分部积分：

\[ \int_\Omega(-\Delta u)v\,dx = \int_\Omega\nabla u\cdot\nabla v\,dx, \]

这里边界项因 \(v\) 的零边界条件而消失。

因此，Poisson 方程可以改写为

\[ \boxed{ \int_\Omega\nabla u\cdot\nabla v\,dx = \int_\Omega fv\,dx, \qquad \forall v\in H_0^1(\Omega). } \]

这就是 Poisson 方程的弱形式。

定义（弱解）。 若 \(u\in H_0^1(\Omega)\)，并且对所有 \(v\in H_0^1(\Omega)\)，都有

\[ \int_\Omega\nabla u\cdot\nabla v\,dx = \int_\Omega fv\,dx, \]

则称 \(u\) 是 Poisson 方程的弱解。

注意，这个定义不要求 \(u\) 存在经典二阶导数。

它只要求一阶弱导数属于 \(L^2\)，并满足一个积分恒等式。

这正是现代 PDE 理论的基本思想：通过积分形式定义解，而不是直接要求逐点满足微分方程。

11. Lax–Milgram 定理#

弱解的定义解决了什么是解的问题，但还没有证明解一定存在。

我们需要一个泛函分析工具。

定理（Lax–Milgram 定理）。 设 \(H\) 是实 Hilbert 空间，\(a:H\times H\to\mathbb R\) 是连续双线性型，并且具有强制性：存在 \(c>0\)，使得

\[ a(u,u)\ge c\|u\|_H^2. \]

设 \(F\in H^*\) 是连续线性泛函。

那么存在唯一的 \(u\in H\)，使得

\[ \boxed{ a(u,v)=F(v), \qquad\forall v\in H. } \]

这里：

  • 连续性要求存在 \(C>0\)，使得 \(|a(u,v)|\le C\|u\|_H\|v\|_H\)；
  • 强制性保证双线性型不会在非零方向上退化；
  • \(F\) 是给定的连续线性泛函。

这个定理是许多椭圆型 PDE 弱解理论的核心。

12. 用 Lax–Milgram 定理证明 Poisson 方程存在唯一弱解#

令

\[ H=H_0^1(\Omega). \]

在这个空间上，利用 Poincaré 不等式，可以将

\[ \|u\|_H=\|\nabla u\|_2 \]

作为等价范数。

定义双线性型

\[ a(u,v)= \int_\Omega\nabla u\cdot\nabla v\,dx, \]

以及线性泛函

\[ F(v)=\int_\Omega fv\,dx. \]

首先验证连续性。

由 Cauchy–Schwarz 不等式，

\[ |a(u,v)| \le \|\nabla u\|_2\|\nabla v\|_2. \]

因此 \(a\) 连续。

其次验证强制性：

\[ a(u,u) = \int_\Omega|\nabla u|^2\,dx = \|u\|_H^2. \]

所以强制性成立，且 \(c=1\)。

最后验证 \(F\) 连续。

若 \(f\in L^2(\Omega)\)，则

\[ \begin{aligned} |F(v)| &\le\|f\|_2\|v\|_2\\ &\le C\|f\|_2\|\nabla v\|_2. \end{aligned} \]

第二个不等式使用了 Poincaré 不等式。

因此 \(F\in H^*\)。

由 Lax–Milgram 定理，存在唯一 \(u\in H_0^1(\Omega)\)，使得

\[ \int_\Omega\nabla u\cdot\nabla v\,dx = \int_\Omega fv\,dx \]

对所有 \(v\in H_0^1(\Omega)\) 成立。

因此，Poisson 方程存在唯一弱解。

这个证明非常典型：

\[ \boxed{ \text{Sobolev 空间} \longrightarrow \text{双线性型} \longrightarrow \text{强制性} \longrightarrow \text{Lax–Milgram} \longrightarrow \text{弱解}. } \]

13. 能量泛函与变分原理#

Poisson 方程的弱形式还可以从变分原理得到。

定义能量泛函

\[ J(u) = \frac12\int_\Omega|\nabla u|^2\,dx - \int_\Omega fu\,dx. \]

我们希望寻找 \(u\in H_0^1(\Omega)\)，使得 \(J(u)\) 取得最小值。

考虑变分 \(u+\varepsilon v\)，其中 \(v\in H_0^1(\Omega)\)。则

\[ \begin{aligned} \frac{d}{d\varepsilon} J(u+\varepsilon v)\bigg|_{\varepsilon=0} &= \int_\Omega\nabla u\cdot\nabla v\,dx\\ &\quad-\int_\Omega fv\,dx. \end{aligned} \]

若 \(u\) 是极小点，则对所有 \(v\) 有

\[ \int_\Omega\nabla u\cdot\nabla v\,dx = \int_\Omega fv\,dx. \]

这恰好就是 Poisson 方程的弱形式。

因此，弱解也可以理解为能量泛函的极小点。

这一观点在数学物理中非常重要：许多物理系统的平衡态由某个能量泛函的极小值决定，而其 Euler–Lagrange 方程正是相应的偏微分方程。

14. 本讲的理论总结#

本讲建立了 Sobolev 空间与弱解理论的基本框架：

  • 弱导数通过分部积分恒等式定义；
  • Sobolev 空间要求函数及其弱导数具有指定的可积性；
  • \(W^{k,p}\) 是 Banach 空间，\(H^k\) 是 Hilbert 空间；
  • 光滑函数在适当 Sobolev 空间中稠密；
  • \(W_0^{1,p}\) 刻画零边界条件；
  • Poincaré 不等式控制函数本身；
  • Sobolev 与 Morrey 嵌入定理将可积性转化为更强的正则性；
  • Poisson 方程可以通过积分恒等式定义弱解；
  • Lax–Milgram 定理给出弱解的存在唯一性；
  • 弱解与能量泛函的极小化问题密切相关。

本讲最重要的思想是：

微分方程不必要求解逐点满足经典微分关系；只要它满足适当的积分恒等式，就可以在 Sobolev 空间中建立完整的存在唯一性理论。

习题#

1. 弱导数唯一性。 证明若 \(g_1,g_2\in L^1_{\mathrm{loc}}(\Omega)\) 都是 \(f\) 的弱导数，则 \(g_1=g_2\) 几乎处处。

2. 绝对值函数。 证明 \(f(x)=|x|\) 的弱导数为 \(\operatorname{sgn}(x)\)，并说明它属于哪些一阶 Sobolev 空间。

3. Sobolev 完备性。 补全 \(W^{k,p}\) 完备性的证明，特别是证明 \(L^p\) 极限确实保持弱导数关系。

4. Poincaré 不等式。 对 \(u\in C_c^\infty(0,L)\)，证明 \(\|u\|_{L^p(0,L)}\le C\|u’\|_{L^p(0,L)}\)。

5. Sobolev 嵌入。 对三维有界 Lipschitz 区域，计算 \(W^{1,2}\) 的临界 Sobolev 指数。

6. 弱形式。 从 Poisson 方程的经典形式出发，通过分部积分推导弱形式，并解释为什么测试函数需要满足零边界条件。

7. Lax–Milgram。 验证 Poisson 方程对应的双线性型满足连续性与强制性。

8. 变分原理。 证明 Poisson 方程的弱解是能量泛函 \(J\) 的唯一极小点。

9. 思考题。 为什么一个函数即使没有经典二阶导数，仍然可能满足 Poisson 方程的弱形式？

10. 进阶题。 设 \(u\in W^{1,p}(\Omega)\)，且 \(p>n\)。结合 Morrey 嵌入定理，解释为什么 \(u\) 可以选取一个 Hölder 连续代表元。
