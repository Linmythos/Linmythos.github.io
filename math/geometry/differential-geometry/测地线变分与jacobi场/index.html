Geodesic Variations and Jacobi Fields

上一章我们讨论了截面曲率，它描述流形沿不同二维方向的弯曲程度。但曲率究竟如何影响测地线？一个自然的办法是考察一族彼此邻近的测地线：如果从同一点出发的测地线具有相近的初始方向，它们在之后会逐渐靠近还是彼此远离？这种相对变化与流形的曲率密切相关。描述这一现象的核心工具就是 Jacobi 场（Jacobi field）。它将测地线变分、曲率与指数映射联系起来，也是理解共轭点和整体黎曼几何的重要基础。

15.1 测地线变分与变分向量场#

设 \(\gamma:(a,b)\to M\) 是一条测地线。考虑一族光滑曲线 \(\gamma_s(t)\)，其中参数 \(s\) 描述曲线族中的不同曲线，并假设对每个固定的 \(s\)，曲线 \(t\mapsto\gamma_s(t)\) 都是一条仿射参数化测地线。这样的曲线族称为测地线变分。

取基准曲线 \(\gamma_0(t)=\gamma(t)\)，定义沿 \(\gamma\) 的向量场

\[ \boxed{ J(t)=\left.\frac{\partial\gamma_s(t)}{\partial s}\right|_{s=0}. } \]

它称为变分向量场。由于所有曲线都取值于同一个流形，参数方向的导数在每一点都属于相应的切空间，因此 \(J(t)\in T_{\gamma(t)}M\)。

几何上，\(J(t)\) 描述当变分参数 \(s\) 发生微小变化时，测地线在时刻 \(t\) 的位置如何变化。特别地，若 \(\gamma_s(0)=p\) 对所有 \(s\) 都成立，则 \(J(0)=0\)，表示这一族测地线从同一点出发；若初始速度随 \(s\) 改变，则 \(J\) 描述这些初始方向差异如何随时间演化。

15.2 Jacobi 方程#

由于每条 \(\gamma_s\) 都是测地线，因此有 \(\nabla_{\partial_t}\partial_t\gamma_s=0\)。对这一等式沿变分参数 \(s\) 求协变导数，并利用曲率张量刻画协变导数不对易的性质，可以得到变分向量场满足的微分方程：

\[ \boxed{ \frac{D^2J}{dt^2}+R(J,\dot\gamma)\dot\gamma=0. } \]

这就是 Jacobi 方程（Jacobi equation）。这里 \(D/dt\) 表示沿基准测地线的协变导数，\(R\) 采用本文此前固定的曲率符号约定。若采用相反的曲率张量定义，Jacobi 方程中的曲率项符号也会相应改变。

Jacobi 方程是沿测地线定义的二阶线性常微分方程。给定某一点处的初始数据 \(J(0)\) 与 \(DJ/dt(0)\)，便可以唯一确定局部 Jacobi 场。因此，Jacobi 场描述的并非任意向量场，而是能够由测地线变分产生的特殊向量场。

15.3 Jacobi 场的几何意义#

Jacobi 方程最重要的意义在于描述邻近测地线之间的相对分离。考虑一族从同一点 \(p\) 出发的测地线，若其初始速度略有不同，那么在短时间内，它们的位置差异可以由 Jacobi 场的一阶变化刻画。换言之，Jacobi 场是测地线族对初始条件变化的线性响应。

曲率决定了这种响应的性质。对于正截面曲率空间，邻近测地线倾向于汇聚；对于负截面曲率空间，邻近测地线倾向于发散；而在欧氏空间中，曲率为零，Jacobi 方程退化为 \(D^2J/dt^2=0\)，其解沿测地线呈线性变化。

球面提供了正曲率的典型例子：从北极出发的不同经线在南极再次相交。它们在初始方向上的差异随着运动逐渐缩小，反映了正曲率空间中的测地线汇聚现象。相反，在双曲空间中，邻近测地线通常会逐渐远离，体现了负曲率的发散效应。

需要强调的是，上述描述是典型模型中的几何图像，并不意味着只凭某一点的截面曲率符号，就能直接判断任意两条测地线在整个区间上的距离变化。严格的比较需要结合 Jacobi 方程及相应的曲率条件。

15.4 共轭点#

Jacobi 场还引出一个重要概念：共轭点（conjugate points）。设 \(\gamma\) 是一条测地线，若存在一个不恒为零的 Jacobi 场 \(J\)，使得 \(J(t_0)=J(t_1)=0\)，其中 \(t_0\neq t_1\)，则称 \(\gamma(t_0)\) 与 \(\gamma(t_1)\) 沿该测地线共轭。

直观而言，共轭点意味着存在一族测地线变分，它们在两个不同参数时刻具有相同的端点。换言之，测地线族在这两个位置发生了某种聚焦现象。

共轭点与指数映射的奇异性密切相关。固定 \(p\in M\)，考虑指数映射 \(\exp_p:T_pM\to M\)。若沿从 \(p\) 出发的测地线出现共轭点，则相应位置的指数映射微分会发生退化，即不再是线性同构。因此，共轭点也是研究指数映射局部性质的重要工具。

此外，共轭点还与测地线的长度极小性质有关。若一条测地线在两个端点之间存在共轭点，则它在经过第一个共轭点之后不再是局部长度极小曲线。这一结论是整体黎曼几何中研究测地线极小性质的重要基础。

15.5 本章小结#

测地线变分描述一族邻近测地线随参数变化的情况，其变分向量场 \(J\) 满足 Jacobi 方程 \(\frac{D^2J}{dt^2}+R(J,\dot\gamma)\dot\gamma=0\)。该方程说明曲率控制着邻近测地线的相对变化：正曲率倾向于使测地线汇聚，负曲率则倾向于使其发散。若非零 Jacobi 场在两个不同时刻同时消失，则相应点称为共轭点。共轭点与指数映射的奇异性以及测地线的局部极小性质密切相关。至此，我们已经建立了从黎曼度量、Levi-Civita 联络、测地线到曲率与 Jacobi 场的基本理论。下一部分将进入整体黎曼几何，研究完备性、测地线延拓以及曲率条件对流形整体结构的限制。

习题#

基础题

  1. 给出测地线变分与变分向量场的定义，并解释 \(J(t)\) 的几何意义。
  2. 写出 Jacobi 方程，并说明其中曲率项与协变加速度项分别承担什么作用。
  3. 证明：若 \(\gamma_s(0)=p\) 对所有 \(s\) 均成立，则相应变分向量场满足 \(J(0)=0\)。

理论题

  1. 从测地线变分方程出发，利用曲率张量的定义推导 Jacobi 方程。
  2. 证明：欧氏空间中的 Jacobi 方程退化为普通二阶线性微分方程，并求其一般解。
  3. 解释共轭点与指数映射微分退化之间的关系。

深入题

  1. 在常截面曲率空间中，将 Jacobi 场分解为沿测地线切向与正交方向的分量，研究两类分量分别满足什么方程。
  2. 在球面上研究从北极出发的一族测地线，利用 Jacobi 场解释经线在南极相交的现象。
  3. 证明：若一条测地线在两个端点之间存在共轭点，则它不再是这两个端点之间的局部长度极小曲线。
