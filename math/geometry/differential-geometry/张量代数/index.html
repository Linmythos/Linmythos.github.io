Tensor Algebra

张量是微分几何中最基本的代数对象之一。向量、余向量、双线性型、黎曼度量以及曲率张量，都可以纳入统一的张量语言。引入张量的目的，是将这些对象组织成一种不依赖坐标选择的代数结构，并使它们能够在流形上自然地变化。

5.1 多重线性映射与张量#

设 \(V\) 是有限维实向量空间，\(V^*\) 表示其对偶空间。一个 \(k+l\) 重多重线性映射，是指一个映射

\[ T:\underbrace{V^*\times\cdots\times V^*}_{k}\times \underbrace{V\times\cdots\times V}_{l}\longrightarrow\mathbb R, \]

它对每一个变量分别线性。这样的对象称为一个 \((k,l)\) 型张量。这里采用如下约定：第一个指标 \(k\) 表示向量空间 \(V\) 的张量因子数，第二个指标 \(l\) 表示对偶空间 \(V^*\) 的张量因子数。因此，\((k,l)\) 型张量与张量积空间

\[ T^k_l(V)=V^{\otimes k}\otimes(V^*)^{\otimes l} \]

中的元素自然对应。特别地，向量属于 \(T^1_0(V)=V\)，余向量属于 \(T^0_1(V)=V^*\)。

这里需要注意一个容易混淆的地方：虽然张量积表达式中 \(V\) 出现在前、\(V^*\) 出现在后，但多重线性映射的输入恰好相反。一个 \((k,l)\) 型张量接受 \(k\) 个余向量和 \(l\) 个向量作为输入。这是因为 \(V\) 与 \(V^*\) 之间存在自然配对，而有限维条件下有自然同构 \((V^*)^*\cong V\)。

张量空间的维数满足 \(\dim T^k_l(V)=(\dim V)^{k+l}\)。当 \(k=l=0\) 时，约定 \(T^0_0(V)=\mathbb R\)，因而标量也是张量。

5.2 常见张量类型#

张量语言将许多熟悉的线性代数对象统一起来。标量 \(a\in\mathbb R\) 是 \((0,0)\) 型张量；向量 \(v\in V\) 是 \((1,0)\) 型张量；余向量 \(\alpha\in V^*\) 是 \((0,1)\) 型张量，其作用为 \(\alpha(v)\in\mathbb R\)。

线性映射 \(A:V\to V\) 可以视为 \((1,1)\) 型张量。事实上，它对应于双线性映射 \((\alpha,v)\mapsto\alpha(Av)\)。双线性型 \(B:V\times V\to\mathbb R\) 则是 \((0,2)\) 型张量。特别地，内积就是一个对称、正定的 \((0,2)\) 型张量；在黎曼几何中，黎曼度量正是定义在每个切空间上的这一类对象。

同样，线性映射 \(A:V\to W\) 可以自然地看作 \(W\otimes V^*\) 中的元素。若 \(V,W\) 都是有限维向量空间，这一对应由 \(w\otimes\alpha\mapsto(v\mapsto\alpha(v)w)\) 给出。因此，张量不仅统一了同一向量空间上的多重线性映射，也描述了不同向量空间之间的线性关系。

5.3 张量积#

设 \(S\in T^k_l(V)\)，\(T\in T^p_q(V)\)。它们的张量积定义为 \(S\otimes T\in T^{k+p}_{l+q}(V)\)，其作用方式是分别将前一组输入交给 \(S\)，后一组输入交给 \(T\)，再将所得实数相乘。张量积具有双线性、结合性以及自然的分配律，但一般不满足交换律，即通常 \(S\otimes T\neq T\otimes S\)。

张量积的核心意义在于：它将多个多重线性对象组合成一个更高阶的多重线性对象。例如，若 \(\alpha,\beta\in V^*\)，则 \(\alpha\otimes\beta\) 是一个 \((0,2)\) 型张量，满足 \((\alpha\otimes\beta)(v,w)=\alpha(v)\beta(w)\)。注意，\(\alpha\otimes\beta\) 一般不是对称双线性型，因为交换 \(v,w\) 后得到的是 \(\alpha(w)\beta(v)\)。

从抽象代数的角度看，张量积具有一个重要的泛性质：任意分别对两个变量线性的双线性映射 \(B:V\times W\to U\)，都唯一对应一个线性映射 \(\widetilde B:V\otimes W\to U\)，使得 \(B(v,w)=\widetilde B(v\otimes w)\)。这意味着张量积将多重线性问题转化为线性问题，是张量代数得以建立的根本原因。

5.4 张量的坐标表示#

取 \(V\) 的一组基 \(\{e_i\}\)，以及对偶基 \(\{\varepsilon^i\}\)，满足 \(\varepsilon^i(e_j)=\delta^i_j\)。则任意 \((k,l)\) 型张量都可以唯一表示为

\[ T=T^{i_1\cdots i_k}{}_{j_1\cdots j_l}\, e_{i_1}\otimes\cdots\otimes e_{i_k} \otimes\varepsilon^{j_1}\otimes\cdots\otimes\varepsilon^{j_l}. \]

其中 \(T^{i_1\cdots i_k}{}_{j_1\cdots j_l}\) 称为张量的分量，重复指标按照 Einstein 求和约定求和。上标对应 \(V\) 的因子，下标对应 \(V^*\) 的因子。

若进行基变换，张量的分量必须按照相应的变换规律变化。对于坐标变换 \(x^i\mapsto \widetilde x^a\)，向量基与余向量基分别满足

\[ \frac{\partial}{\partial \widetilde x^a} =\frac{\partial x^i}{\partial\widetilde x^a} \frac{\partial}{\partial x^i}, \qquad d\widetilde x^a =\frac{\partial\widetilde x^a}{\partial x^i}dx^i. \]

因此，张量分量中的每个上标按照逆坐标变换的 Jacobian 变换，每个下标按照正向坐标变换的 Jacobian 变换。具体而言，

\[ \widetilde T^{a_1\cdots a_k}{}_{b_1\cdots b_l} = \frac{\partial\widetilde x^{a_1}}{\partial x^{i_1}} \cdots \frac{\partial\widetilde x^{a_k}}{\partial x^{i_k}} \frac{\partial x^{j_1}}{\partial\widetilde x^{b_1}} \cdots \frac{\partial x^{j_l}}{\partial\widetilde x^{b_l}} T^{i_1\cdots i_k}{}_{j_1\cdots j_l}. \]

这就是张量的坐标变换律。一个具有正确坐标变换律的分量族，才真正定义了几何意义上的张量；仅仅具有若干个上标和下标，并不足以保证它是张量。

5.5 张量缩并#

缩并（contraction）是张量代数中的基本运算。由于 \(V\) 与 \(V^*\) 之间存在自然配对，可以将一个张量中的一个 \(V\) 因子与一个 \(V^*\) 因子配对，从而得到阶数降低两个的张量。若 \(T\) 是 \((k,l)\) 型张量，且 \(k,l\geq1\)，则缩并可以得到一个 \((k-1,l-1)\) 型张量。

在坐标表达式中，缩并就是对一个上指标和一个下指标求和。例如，对于 \((1,1)\) 型张量 \(A=A^i{}_j e_i\otimes\varepsilon^j\)，其迹定义为 \(\operatorname{tr}A=A^i{}_i\)。对于更高阶张量，也可以选择任意一对上、下指标进行缩并。由于缩并来自自然配对，它不依赖坐标选择。

缩并在微分几何中极为重要。例如，黎曼曲率张量可以通过缩并得到 Ricci 曲率张量，而 Ricci 张量进一步可以得到标量曲率。由此可见，许多几何不变量本质上都是张量缩并的结果。

5.6 对称张量与反对称张量#

对于一个二阶协变张量 \(T\in T^0_2(V)\)，可以定义其对称部分与反对称部分：\(T_{\mathrm{sym}}(v,w)=\frac12[T(v,w)+T(w,v)]\)，\(T_{\mathrm{alt}}(v,w)=\frac12[T(v,w)-T(w,v)]\)。于是 \(T=T_{\mathrm{sym}}+T_{\mathrm{alt}}\)，并且这一分解是唯一的。对称部分满足 \(T_{\mathrm{sym}}(v,w)=T_{\mathrm{sym}}(w,v)\)，反对称部分满足 \(T_{\mathrm{alt}}(v,w)=-T_{\mathrm{alt}}(w,v)\)。

这一分解可以推广到任意阶张量。对一个 \(k\) 阶协变张量，完全对称化是对所有指标置换求和并取平均，完全反对称化则是在求和时按照置换的符号加权。相应地，二阶对称张量构成的空间记为 \(S^2(V^*)\)，二阶反对称张量构成的空间记为 \(\Lambda^2(V^*)\)。

对称张量与反对称张量在几何中承担不同角色。黎曼度量是对称的二阶协变张量，而微分形式则属于反对称张量空间。后者将在下一章中系统讨论。

5.7 张量场与张量丛#

前面讨论的是单个向量空间上的张量。对于光滑流形 \(M\)，每一点 \(p\in M\) 都有切空间 \(T_pM\)，因而可以在每一点定义相应的张量空间 \(T^k_l(T_pM)\)。将这些空间沿流形逐点组织起来，便得到 \((k,l)\) 型张量丛，记作 \(T^k_lM\)。它是一个向量丛，其纤维满足 \((T^k_lM)_p=T^k_l(T_pM)\)。

一个光滑 \((k,l)\) 型张量场，就是张量丛 \(T^k_lM\) 的一个光滑截面。换言之，它为每一点 \(p\in M\) 指定一个张量 \(T_p\in T^k_l(T_pM)\)，并且这些张量随 \(p\) 光滑变化。我们通常将张量场直接记为 \(T\)。

在局部坐标 \((x^1,\ldots,x^n)\) 下，张量场可以写成 \(T=T^{i_1\cdots i_k}{}_{j_1\cdots j_l}\,\partial_{i_1}\otimes\cdots\otimes\partial_{i_k}\otimes dx^{j_1}\otimes\cdots\otimes dx^{j_l}\)，其中系数 \(T^{i_1\cdots i_k}{}_{j_1\cdots j_l}\) 是光滑函数。它们在不同坐标图之间按照上一节的张量变换律相互联系，因此局部表达式能够拼接成一个全局几何对象。

特别地，光滑函数是 \((0,0)\) 型张量场，向量场是 \((1,0)\) 型张量场，微分 1-形式是 \((0,1)\) 型张量场，黎曼度量是 \((0,2)\) 型张量场。这些对象并非彼此孤立，而是同一张量理论中的不同类型。

5.8 本章小结#

张量代数以向量空间及其对偶空间为基础，通过张量积构造高阶多重线性对象。张量的类型由其 \(V\) 与 \(V^*\) 因子数决定；张量积将不同阶张量组合起来，缩并则利用自然配对降低张量阶数；对称化与反对称化进一步揭示张量的代数结构。将这一理论逐点应用于流形，便得到张量丛与张量场。微分几何中的度量、曲率、微分形式等对象，都将在这一统一框架下得到描述。

习题#

基础题

  1. 设 \(V\) 是 \(n\) 维向量空间，求 \(T^2_1(V)\) 的维数，并写出其中元素的一般坐标表达式。
  2. 设 \(\alpha,\beta\in V^*\)。证明 \(\alpha\otimes\beta\) 是二阶协变张量，并判断它在什么条件下是对称张量。
  3. 设 \(A:V\to V\) 是线性映射。将其表示为 \((1,1)\) 型张量，并证明其缩并等于线性代数中的迹。
  4. 证明任意二阶协变张量都可以唯一分解为对称部分与反对称部分。

理论题

  1. 利用张量积的泛性质，证明双线性映射 \(B:V\times W\to U\) 与线性映射 \(\widetilde B:V\otimes W\to U\) 一一对应。
  2. 证明张量缩并与坐标选择无关。
  3. 设 \(T\) 是一个 \((k,l)\) 型张量，证明完全对称化与完全反对称化都是线性算子。
  4. 证明若 \(T\in T^0_2(V)\) 是反对称张量，且 \(\dim V=1\)，则 \(T=0\)。

深入题

  1. 设 \(V\) 为 \(n\) 维向量空间，证明完全反对称的 \(k\) 阶协变张量空间 \(\Lambda^k(V^*)\) 的维数为 \(\binom nk\)。
  2. 证明对于有限维向量空间 \(V,W\)，有自然同构 \(\operatorname{Hom}(V,W)\cong W\otimes V^*\)。
  3. 设 \(g\) 是 \(V\) 上的非退化对称双线性型。证明映射 \(v\mapsto g(v,\cdot)\) 给出 \(V\) 与 \(V^*\) 之间的线性同构，并说明正定性在这一结论中是否必要。
  4. 设 \(T\in T^0_3(V)\)。写出其完全反对称化，并证明所得张量属于 \(\Lambda^3(V^*)\)。
