笔者在学习微分几何时，被符号体系和各种名称肘击地很惨，以下采用一种笔者认为比较舒适的记号体系和名称体系。

以下设 \(M,N\) 为光滑流形，\(f:M\to N\) 为光滑映射。

一、切空间与切映射#

1. 切空间#

流形 \(M\) 在点 \(p\) 处的切空间记为 \(T_pM\)，其对偶空间称为余切空间，记为 \(T_p^*M\)。

切空间中的元素称为切向量，余切空间中的元素称为余切向量。

切丛定义为

\[ TM=\coprod_{p\in M}T_pM, \]

余切丛定义为

\[ T^*M=\coprod_{p\in M}T_p^*M. \]

自然投影分别记为 \(\pi_M:TM\to M\) 和 \(\pi_M^*:T^*M\to M\)。

2. 切映射（Tangent Map）#

光滑映射 \(f:M\to N\) 在 \(p\in M\) 处诱导线性映射

\[ f_{*p}:T_pM\longrightarrow T_{f(p)}N.\]

称为 \(f\) 在 \(p\) 处的切映射。

将各点处的切映射组合起来，得到整体切丛映射

\[ f_*:TM\longrightarrow TN,\qquad (p,v)\longmapsto(f(p),f_{*p}v). \]

因此，\(f_{*p}\) 是单点处的线性映射，\(f_*\) 是整体切丛之间的光滑映射。二者属于同一结构的局部与整体形式。

切映射满足链式法则。若 \(g:N\to P\)，则

\[ (g\circ f)_{*p} =g_{*f(p)}\circ f_{*p}. \]

若 \(f\) 是微分同胚，则 \(f_{*p}\) 是线性同构，并且

\[ (f_{*p})^{-1} =(f^{-1})_{*f(p)}. \]

二、余切映射与拉回#

1. 余切映射（Cotangent Map）#

由线性映射 \(f_{*p}:T_pM\to T_{f(p)}N\)，可以取其线性对偶，得到余切映射

\[ (f_{*p})^\vee: T_{f(p)}^*N\longrightarrow T_p^*M. \]

这里 \(\vee\) 表示线性对偶。

对于 \(\alpha\in T_{f(p)}^*N\) 和 \(v\in T_pM\)，其定义为

\[ \big((f_{*p})^\vee\alpha\big)(v) =\alpha(f_{*p}v). \]

注意，余切映射的方向与切映射相反。这是线性对偶的直接结果，而不是额外规定。

2. 拉回（Pullback）#

对于 \(k\)-形式 \(\omega\in\Omega^k(N)\)，映射 \(f\) 诱导拉回

\[ f^*:\Omega^k(N)\longrightarrow\Omega^k(M). \]

其定义为

\[ \begin{aligned} (f^*\omega)_p(v_1,\ldots,v_k) ={}&\omega_{f(p)}( f_{*p}v_1,\ldots,f_{*p}v_k). \end{aligned} \]

特别地，对于 1-形式 \(\alpha\)，有

\[ (f^*\alpha)_p =(f_{*p})^\vee\alpha_{f(p)}. \]

因此，余切映射是单点处的线性对偶，而拉回是余切映射在微分形式上的自然延拓。

拉回满足复合规律：

\[ (g\circ f)^*=f^*\circ g^*. \]

注意顺序反转，这与线性对偶的复合规律完全一致。

三、向量场与推前#

1. 向量场#

光滑向量场是切丛 \(TM\) 的光滑截面，即光滑映射 \(X:M\to TM\)，满足

\[ \pi_M\circ X=\operatorname{id}_M. \]

在每一点 \(p\in M\)，向量场取值为 \(X_p\in T_pM\)。

全体光滑向量场记为

\[ \mathfrak X(M)=\Gamma(TM). \]

这里 \(\Gamma(TM)\) 表示切丛的光滑截面空间。

2. 推前（Pushforward）#

若 \(f:M\to N\) 是微分同胚，则向量场 \(X\in\mathfrak X(M)\) 可以推前为 \(N\) 上的向量场 \(f_*X\)，定义为

\[ \boxed{ (f_*X)_{f(p)}=f_{*p}(X_p). } \]

这里需要注意：\(f_*\) 既表示整体切丛映射，也表示向量场的推前。具体含义由作用对象决定。

如果 \(f\) 不是微分同胚，仍然可以逐点应用切映射，但一般不能将任意向量场推前为目标流形上的全局向量场，因为不同原像处的切向量可能产生不一致的结果。

3. 向量场对函数的作用#

向量场可以自然地作用于光滑函数。对 \(X\in\mathfrak X(M)\) 和 \(h\in C^\infty(M)\)，定义

\[ \boxed{ X(h)(p)=X_p(h). } \]

右侧的 \(X_p\) 被视为切向量对函数的作用。

因此，向量场也可以理解为光滑函数代数上的一种线性算子。

四、导子（Derivation）#

这是一个非常重要的联系：向量场与光滑函数代数上的导子之间存在自然的一一对应。

1. 导子的定义#

设 \(A\) 是一个代数。线性映射 \(D:A\to A\) 若满足 Leibniz 法则

\[ \boxed{ D(ab)=D(a)b+aD(b), } \]

则称 \(D\) 为 \(A\) 上的导子。

对于光滑流形 \(M\)，考虑光滑函数代数 \(C^\infty(M)\)。其上的导子是满足

\[ D:C^\infty(M)\to C^\infty(M) \]

以及

\[ D(fg)=D(f)g+fD(g) \]

的实线性映射。

全体导子记为

\[ \operatorname{Der}(C^\infty(M)). \]

2. 向量场给出导子#

每个光滑向量场 \(X\) 都定义一个导子：

\[ D_X:C^\infty(M)\to C^\infty(M), \qquad D_X(h)=X(h). \]

这是因为切向量满足 Leibniz 法则：

\[ X_p(fg)=X_p(f)g(p)+f(p)X_p(g). \]

所以

\[ D_X(fg)=D_X(f)g+fD_X(g). \]

3. 导子反过来给出向量场#

反过来，在通常的光滑流形条件下，每个 \(C^\infty(M)\) 上的实线性导子都来自唯一的光滑向量场。

因此有自然的对应关系

\[ \boxed{ \mathfrak X(M) \cong \operatorname{Der}(C^\infty(M)). } \]

这不是单纯的形式类比，而是光滑流形的一个基本代数刻画。

从局部坐标来看，若取坐标 \((x^1,\ldots,x^n)\)，则向量场可以写成

\[ X=\sum_{i=1}^n X^i\frac{\partial}{\partial x^i}, \]

它对应的导子作用为

\[ D_X(h)= \sum_{i=1}^n X^i \frac{\partial h}{\partial x^i}. \]

其中 \(\frac{\partial}{\partial x^i}\) 是坐标方向的坐标向量场，同时也是一个导子。

4. 导子与李括号#

向量场之间存在李括号（Lie Bracket）：

\[ [X,Y]\in\mathfrak X(M). \]

它可以通过导子的交换子定义：

\[ \boxed{ D_{[X,Y]}=D_X\circ D_Y-D_Y\circ D_X. } \]

也就是说，

\[ [X,Y](h)=X(Y(h))-Y(X(h)). \]

导子的交换子仍然是导子，因此向量场构成一个李代数：

\[ \big(\mathfrak X(M),[\cdot,\cdot]\big). \]

这也是从代数角度理解李括号的自然方式。

五、外微分与微分形式#

1. 微分形式#

\(k\)-形式是余切丛外代数丛 \(\Lambda^kT^*M\) 的光滑截面：

\[ \Omega^k(M)=\Gamma(\Lambda^kT^*M). \]

特别地，

\[ \Omega^0(M)=C^\infty(M), \qquad \Omega^1(M)=\Gamma(T^*M). \]

微分形式之间可以通过楔积 \(\wedge\) 进行运算。

2. 外微分（Exterior Derivative）#

外微分是一个线性算子

\[ \boxed{ d:\Omega^k(M)\longrightarrow\Omega^{k+1}(M). } \]

它满足：

Leibniz 法则：

\[ d(\omega\wedge\eta) =d\omega\wedge\eta +(-1)^k\omega\wedge d\eta, \]

其中 \(\omega\in\Omega^k(M)\)。

幂零性：

\[ d^2=0. \]

对于光滑函数 \(h\in C^\infty(M)\)，其外微分 \(dh\) 是一个 1-形式，满足

\[ (dh)_p(v)=v(h). \]

这里特别注意：\(dh\) 是余切向量场，而 \(d\) 是外微分算子。我们保留 \(d\) 专门表示这一结构，不再用它表示切映射。

3. 外微分与拉回的相容性#

对于光滑映射 \(f:M\to N\)，有

\[ \boxed{ f^*(d\omega)=d(f^*\omega). } \]

这表明拉回与外微分可交换。它是微分形式理论中极为重要的自然性性质，也是 de Rham 上同调能够在光滑映射下保持良好行为的基础。

六、李群中的应用#

设 \(G\) 为李群，单位元为 \(e\)。对任意 \(g\in G\)，定义左平移

\[ L_g:G\to G,\qquad h\mapsto gh. \]

由于 \(L_g\) 是微分同胚，其在单位元处诱导线性同构

\[ (L_g)_{*e}:T_eG\longrightarrow T_gG. \]

逆映射为

\[ \big((L_g)_{*e}\big)^{-1} =(L_{g^{-1}})_{*g}. \]

因此，给定 \(X_e\in T_eG\)，可以将其延拓为左不变向量场：

\[ X_g=(L_g)_{*e}X_e. \]

于是每个左不变向量场都由单位元处的一个切向量唯一决定。特别地，李代数可以定义为

\[ \boxed{\mathfrak g=T_eG,} \]

其李括号由左不变向量场的李括号诱导。

从导子的角度看，左不变向量场又可以视为 \(C^\infty(G)\) 上的导子；而这些左不变导子在交换子下封闭，构成李代数。

七、最终采用的记号约定#

为了避免全文出现不必要的符号混用，我建议严格采用以下规则：

几何映射层面：

  • \(f_{*p}\)：单点处的切映射。
  • \(f_*\)：整体切丛映射。
  • \((f_{*p})^\vee\)：单点处的余切映射。
  • \(f^*\)：微分形式的整体拉回。

向量场与代数层面：

  • \(\mathfrak X(M)\)：光滑向量场空间。
  • \(f_*X\)：向量场的推前（在适当条件下）。
  • \(D_X\)：向量场 \(X\) 对应的导子。
  • \(\operatorname{Der}(C^\infty(M))\)：光滑函数代数上的导子空间。
  • \([X,Y]\)：向量场的李括号，也就是对应导子的交换子。

微分形式层面：

  • \(\Omega^k(M)\)：光滑 \(k\)-形式空间。
  • \(\wedge\)：楔积。
  • \(d\)：外微分。
  • \(dh\)：函数 \(h\) 的外微分，即一个 1-形式。

特别注意三个容易混淆的对象：

  1. \(f_{*p}\) 是切空间之间的线性映射；\(f_*\) 是切丛之间的整体映射。
  2. \((f_{*p})^\vee\) 是单点处的对偶映射；\(f^*\) 是微分形式上的整体拉回。
  3. \(D_X\) 是函数代数上的导子；\(d\) 是微分形式上的外微分。二者都满足 Leibniz 法则，但作用空间和数学结构不同。

这套体系最重要的优点，是把微分几何中几种经常交织在一起的结构分开了：映射诱导切结构，线性对偶诱导余切结构，向量场对应函数代数上的导子，而外微分组织起整个微分形式复形。 它们彼此联系，却不再需要依赖同一个符号来表达。
