The Riemann Curvature Tensor

上一章我们通过 Levi-Civita 联络定义了测地线，并将其解释为速度向量沿自身平行移动的曲线。现在考虑一个更深刻的问题：沿着不同路径平行移动同一个向量，最终得到的结果是否相同？在欧氏空间中，平行移动与路径无关；但在一般黎曼流形上，结果可能依赖于路径。这种差异正是曲率的来源。曲率衡量联络的不平坦程度，也刻画了流形偏离欧氏几何的方式。

13.1 Riemann 曲率张量的定义#

设 \((M,g)\) 是黎曼流形，\(\nabla\) 是其 Levi-Civita 联络。对任意向量场 \(X,Y,Z\)，定义

\[ \boxed{ R(X,Y)Z =\nabla_X\nabla_YZ-\nabla_Y\nabla_XZ -\nabla_{[X,Y]}Z. } \]

这个对象称为 Riemann 曲率张量（Riemann curvature tensor）。这里采用 Lee 的曲率符号约定，后续所有曲率公式均以此为准。

这个定义可以从协变导数的不对易性理解。对于普通偏导数，若函数足够光滑，则混合偏导数满足 \(\partial_i\partial_j f=\partial_j\partial_i f\)。但在流形上，协变导数作用于向量场时，两个方向的协变微分一般不再交换。曲率正是这种不对易性的度量。定义中的第三项 \(\nabla_{[X,Y]}Z\) 用来扣除方向向量场自身不交换所产生的影响，因此 \(R\) 具有张量性质。

在平坦空间中，曲率张量恒为零，即 \(R\equiv0\)。反过来，若一个联络的曲率张量处处为零，则称该联络是平坦的。对于黎曼几何而言，曲率为零意味着局部几何具有欧氏空间的平坦性质；不过，局部平坦并不意味着整个流形必然与欧氏空间全局等距。

13.2 局部坐标表达式#

取局部坐标 \((x^1,\ldots,x^n)\)，记 \(\nabla_{\partial_i}\partial_j=\Gamma^k_{ij}\partial_k\)。根据曲率定义，并利用坐标向量场满足 \([\partial_i,\partial_j]=0\)，有

\[ R(\partial_i,\partial_j)\partial_k =\nabla_{\partial_i}\nabla_{\partial_j}\partial_k -\nabla_{\partial_j}\nabla_{\partial_i}\partial_k. \]

记 \(R(\partial_i,\partial_j)\partial_k=R^\ell{}_{kij}\partial_\ell\)，展开协变导数便得到

\[ \boxed{ R^\ell{}_{kij} =\partial_i\Gamma^\ell_{jk} -\partial_j\Gamma^\ell_{ik} +\Gamma^\ell_{im}\Gamma^m_{jk} -\Gamma^\ell_{jm}\Gamma^m_{ik}. } \]

这个公式表明，曲率分量由 Christoffel 符号及其一阶偏导数构成。由于 Christoffel 符号本身不是张量，但上述组合具有张量变换性质，因此 \(R\) 是一个真正的 \((1,3)\) 型张量场。

从公式中可以看出，曲率不仅取决于联络系数本身，还取决于它们在空间中的变化。即使某个坐标系下 Christoffel 符号在一点处全部为零，曲率仍然可能非零，因为其偏导数项未必消失。这也解释了为什么法坐标只能在一点消去联络系数，却不能一般地在一个邻域内消去曲率。

13.3 曲率张量的代数性质#

Riemann 曲率张量具有丰富的对称性。首先，由定义立即得到前两个输入的反对称性：\(R(X,Y)Z=-R(Y,X)Z\)。其次，由度量相容性可以证明 \(g(R(X,Y)Z,W)=-g(R(X,Y)W,Z)\)，即在最后两个变量之间也具有反对称性。

为了更清楚地表达这些性质，将曲率张量降指标，定义 \(R(X,Y,Z,W)=g(R(X,Y)Z,W)\)。对于 Levi-Civita 联络，它还满足交换对称性 \(R(X,Y,Z,W)=R(Z,W,X,Y)\)。因此，降指标后的曲率张量具有典型的代数对称结构：前两个变量反对称，后两个变量反对称，交换两对变量不变。

此外，曲率张量还满足两个重要恒等式。

第一 Bianchi 恒等式（First Bianchi Identity）：对任意向量场 \(X,Y,Z\)，有

\[ \boxed{ R(X,Y)Z+R(Y,Z)X+R(Z,X)Y=0. } \]

它说明曲率张量的三个输入之间存在循环对称关系。该恒等式与联络的无挠性密切相关。

第二 Bianchi 恒等式（Second Bianchi Identity）：对任意向量场 \(X,Y,Z\)，有

\[ \boxed{ (\nabla_XR)(Y,Z) +(\nabla_YR)(Z,X) +(\nabla_ZR)(X,Y)=0. } \]

这里 \(\nabla R\) 表示曲率张量的协变导数。与第一 Bianchi 恒等式描述曲率的代数结构不同，第二 Bianchi 恒等式涉及曲率在流形上的变化，是进一步构造 Ricci 曲率、标量曲率和 Einstein 张量的重要工具。

13.4 Ricci 曲率、标量曲率与 Einstein 张量#

Riemann 曲率张量包含丰富的信息，但其指标较多。通过缩并，我们可以构造出更低阶的曲率张量。首先，将曲率张量的一个上指标与一个下指标缩并，得到 Ricci 张量（Ricci curvature tensor）。按照本文采用的指标约定，定义为

\[ \boxed{\operatorname{Ric}_{ij}=R^k{}_{ikj}.} \]

Ricci 张量是一个 \((0,2)\) 型张量，能够描述曲率在不同方向上的平均效应。由于曲率符号约定与指标排列会影响具体表达式，使用不同教材中的 Ricci 张量公式时，必须先确认其曲率约定。

进一步利用逆度量 \(g^{ij}\) 对 Ricci 张量缩并，得到一个标量函数：

\[ \boxed{\operatorname{Scal}=g^{ij}\operatorname{Ric}_{ij}.} \]

它称为标量曲率（scalar curvature），是黎曼流形上最简单的曲率不变量之一。与完整的 Riemann 曲率张量相比，标量曲率包含的信息较少，但它能够反映一点附近整体曲率的某种平均特征。

在广义相对论中，还会使用由 Ricci 张量与标量曲率构造的 Einstein 张量（Einstein tensor）：

\[ \boxed{ G_{ij}=\operatorname{Ric}_{ij} -\frac12\operatorname{Scal}\,g_{ij}. } \]

它满足 \(\nabla^iG_{ij}=0\)，这一性质可由第二 Bianchi 恒等式经过缩并得到，称为收缩 Bianchi 恒等式。Einstein 张量在广义相对论场方程中具有核心地位，其协变散度为零与能量动量守恒之间存在深刻联系。

13.5 本章小结#

Riemann 曲率张量由协变导数的不对易性定义，衡量联络的局部弯曲程度。它是一个 \((1,3)\) 型张量，在局部坐标中由 Christoffel 符号及其偏导数表示。对于 Levi-Civita 联络，曲率具有丰富的代数对称性，并满足第一、第二 Bianchi 恒等式。通过缩并，我们进一步得到 Ricci 张量、标量曲率与 Einstein 张量。它们分别从不同层次提取曲率信息，并在黎曼几何与广义相对论中发挥重要作用。下一章将进一步讨论截面曲率：通过考察切空间中的二维平面，我们可以将抽象的 Riemann 曲率张量转化为更直观的几何量。

习题#

基础题

  1. 根据曲率张量的定义，证明 \(R(X,Y)Z=-R(Y,X)Z\)。
  2. 在局部坐标下推导曲率分量公式 \(R^\ell{}_{kij}\)，注意保持本文的指标约定。
  3. 证明：若某个坐标邻域内 Christoffel 符号恒为零，则该邻域内 Riemann 曲率张量恒为零。

理论题

  1. 证明：对于度量相容的联络，\(g(R(X,Y)Z,W)=-g(R(X,Y)W,Z)\)。
  2. 证明第一 Bianchi 恒等式，并说明无挠性在证明中的作用。
  3. 从第二 Bianchi 恒等式出发，推导收缩 Bianchi 恒等式，并证明 Einstein 张量满足 \(\nabla^iG_{ij}=0\)。

深入题

  1. 在法坐标下，证明 \(R^\ell{}_{kij}(p)\) 可以由 Christoffel 符号的一阶偏导数表示，并解释为什么不能仅凭 \(\Gamma^k_{ij}(p)=0\) 得出曲率为零。
  2. 研究 Riemann 曲率张量的代数对称性，证明降指标后的曲率张量满足交换对称性 \(R(X,Y,Z,W)=R(Z,W,X,Y)\)。
  3. 讨论 Riemann 曲率张量、Ricci 张量与标量曲率之间的信息关系：在不同维数下，Ricci 张量是否能够唯一确定完整的 Riemann 曲率张量？
