Connections and Covariant Derivatives

黎曼度量为流形赋予了长度、角度与距离，但它仍然没有解决一个基本问题：如何比较不同点的切向量？对于欧氏空间，我们可以利用平移将不同点的向量视为同一个向量空间中的元素；但在一般流形上，\(T_pM\) 与 \(T_qM\) 是不同的向量空间，并不存在天然的同构。为了定义向量场的导数、沿曲线的加速度以及不同点之间的向量比较，我们需要引入一种额外结构——联络（connection）。联络所定义的微分运算称为协变导数（covariant derivative）。

10.1 为什么需要联络#

设 \(M\) 是光滑流形，\(X,Y\) 是光滑向量场。我们希望定义 \(X\) 方向上 \(Y\) 的变化率，记为 \(\nabla_XY\)。在欧氏空间的标准坐标下，这就是熟悉的方向导数：若 \(Y=Y^j\partial_j\)，则 \(\nabla_XY=X(Y^j)\partial_j\)。

但在一般流形上，这一表达式存在根本困难。向量场 \(Y\) 在点 \(p\) 的取值属于 \(T_pM\)，在邻近点 \(q\) 的取值属于 \(T_qM\)，二者不能直接相减。即使选定局部坐标，坐标基底本身也可能随位置变化。因此，我们不仅需要对向量场的分量求导，还必须考虑基底的变化。联络正是提供这一额外结构的工具。

10.2 仿射联络的定义#

记 \(\mathfrak X(M)\) 为流形 \(M\) 上的光滑向量场空间。一个仿射联络是一个映射 \(\nabla:\mathfrak X(M)\times\mathfrak X(M)\to\mathfrak X(M)\)，记为 \((X,Y)\mapsto\nabla_XY\)，满足以下三条性质：

  1. 对第一个变量 \(C^\infty(M)\)-线性：\(\nabla_{fX+gY}Z=f\nabla_XZ+g\nabla_YZ\)。
  2. 对第二个变量实线性：\(\nabla_X(aY+bZ)=a\nabla_XY+b\nabla_XZ\)，其中 \(a,b\in\mathbb R\)。
  3. 满足 Leibniz 法则：\(\nabla_X(fY)=(Xf)Y+f\nabla_XY\)，其中 \(f\in C^\infty(M)\)。

这三条性质刻画了协变导数的基本行为。第一条意味着 \((\nabla_XY)_p\) 只依赖于 \(X_p\)，而不依赖于 \(X\) 在其他点的取值；第三条则说明协变导数在第二个变量上类似普通微分，必须对函数系数求导。

需要注意，联络对第一个变量是光滑函数线性的，对第二个变量却不是。正是这种不对称性，使它能够描述向量场的微分行为。一个光滑流形上通常存在无穷多个仿射联络；仅仅给定光滑结构，并不能唯一确定联络。

10.3 Christoffel 符号#

取局部坐标 \((x^1,\ldots,x^n)\)，坐标向量场 \(\partial_i=\frac{\partial}{\partial x^i}\) 构成局部标架。根据联络的定义，\(\nabla_{\partial_i}\partial_j\) 仍然是一个向量场，因此可以唯一表示为 \(\nabla_{\partial_i}\partial_j=\Gamma^k_{ij}\partial_k\)。其中的函数 \(\Gamma^k_{ij}\) 称为 Christoffel 符号，它们在局部完全确定联络。

对一般向量场 \(Y=Y^j\partial_j\)，利用 Leibniz 法则可得

\[ \boxed{ \nabla_{\partial_i}Y = \left(\partial_iY^k+\Gamma^k_{ij}Y^j\right)\partial_k. } \]

因此，协变导数的分量为 \((\nabla_iY)^k=\partial_iY^k+\Gamma^k_{ij}Y^j\)。其中 \(\partial_iY^k\) 描述向量场分量的变化，而 \(\Gamma^k_{ij}Y^j\) 则补偿坐标基底随位置变化所产生的贡献。

必须强调：Christoffel 符号不是张量。 它们的坐标变换公式包含二阶坐标导数所产生的非齐次项，因此不能按照普通张量的变换律变换。真正具有几何意义的是联络本身，而不是某一坐标系下的 Christoffel 符号。

一个很好的例子是二维欧氏平面上的极坐标。标准欧氏度量写为 \(g=dr^2+r^2d\theta^2\)，虽然空间本身是平坦的，但其极坐标下的 Christoffel 符号并不全为零。这说明 Christoffel 符号可以反映坐标基底的变化，而不直接等同于空间曲率。

10.4 张量场的协变导数#

联络最初定义在向量场上，但可以自然推广到任意张量场。对于余向量场 \(\omega=\omega_jdx^j\)，协变导数满足

\[ \boxed{ \nabla_i\omega_j = \partial_i\omega_j-\Gamma^k_{ij}\omega_k. } \]

与向量场的公式相比，Christoffel 项的符号发生了变化。这一差异来自对偶配对必须在协变微分下保持一致：若 \(\omega(Y)\) 是一个函数，则必须满足 \(X(\omega(Y))=(\nabla_X\omega)(Y)+\omega(\nabla_XY)\)。

对于一般 \((k,l)\) 型张量场 \(T\)，协变导数仍然是一个 \((k,l)\) 型张量场再增加一个协变指标。其坐标表达式遵循统一规则：每一个上标贡献一个正号的 Christoffel 项，每一个下标贡献一个负号的 Christoffel 项。具体而言，

\[ \begin{aligned} \nabla_i T^{a_1\cdots a_k}{}_{b_1\cdots b_l} ={}&\partial_iT^{a_1\cdots a_k}{}_{b_1\cdots b_l}\\ &+\sum_{r=1}^k\Gamma^{a_r}_{im} T^{a_1\cdots m\cdots a_k}{}_{b_1\cdots b_l}\\ &-\sum_{s=1}^l\Gamma^m_{ib_s} T^{a_1\cdots a_k}{}_{b_1\cdots m\cdots b_l}. \end{aligned} \]

这里每一项中的 \(m\) 都替换相应位置的指标，并按照 Einstein 求和约定求和。这个公式将普通偏导数推广为张量意义下的微分，使协变导数本身具有良好的坐标变换性质。

10.5 沿曲线的协变导数#

考虑一条光滑曲线 \(\gamma:I\to M\)。沿曲线的向量场是指对每个 \(t\in I\)，指定一个向量 \(V(t)\in T_{\gamma(t)}M\)，并要求其随参数光滑变化。注意，沿曲线的向量场不一定能够延拓为整个流形上的向量场。

联络可以定义沿曲线的协变导数，记为 \(\frac{DV}{dt}\)。取局部坐标，设 \(\gamma(t)=(x^1(t),\ldots,x^n(t))\)，且 \(V(t)=V^k(t)\partial_k|_{\gamma(t)}\)，则

\[ \boxed{ \frac{DV^k}{dt} = \frac{dV^k}{dt} +\Gamma^k_{ij}(\gamma(t))\dot x^i(t)V^j(t). } \]

第一项是向量分量沿曲线的变化率，第二项则补偿坐标基底的变化。若联络是欧氏空间标准坐标下的标准联络，则所有 Christoffel 符号为零，协变导数便退化为普通的逐分量求导。

10.6 平行移动#

若沿曲线的向量场满足 \(\frac{DV}{dt}=0\)，则称 \(V\) 沿曲线 \(\gamma\) 平行移动（parallel transport）。在局部坐标下，它满足常微分方程组

\[ \boxed{ \frac{dV^k}{dt} +\Gamma^k_{ij}(\gamma(t))\dot x^i(t)V^j(t)=0. } \]

这是关于 \(V^k(t)\) 的线性常微分方程组。给定初始条件 \(V(t_0)=V_0\)，在适当的定义区间内，存在唯一解。因此，联络能够将曲线起点处的向量传递到曲线上其他点，得到一个线性同构 \(P_\gamma:T_{\gamma(t_0)}M\to T_{\gamma(t_1)}M\)，称为沿曲线的平行移动映射。

平行移动可以理解为在曲线上尽可能保持向量不变，但这里的“不变”不是说坐标分量恒定，而是说协变导数为零。不同坐标系下的分量可能发生变化，然而这一几何条件不依赖坐标选择。

平行移动通常依赖于所选择的路径。即使两条曲线具有相同的起点与终点，沿它们得到的平行移动映射也未必相同。特别地，沿闭合曲线平行移动一个向量，最终得到的向量可能与初始向量不同。这种绕行一周后产生的差异与曲率密切相关，下一部分将对此进行讨论。

10.7 联络与几何结构#

联络不仅定义了向量场的微分，也为许多重要几何概念提供了基础。首先，它允许我们定义沿曲线的加速度：对于曲线 \(\gamma\)，其速度场为 \(\dot\gamma\)，协变加速度为 \(\frac{D\dot\gamma}{dt}\)。其次，它允许我们定义平行移动，从而比较不同点的切向量。最后，通过考察协变导数是否满足交换关系，可以定义曲率；通过考察联络是否满足特定的反对称关系，可以定义挠率。

需要注意，仿射联络本身并不要求来自某个黎曼度量。一个流形可以先被赋予联络，而不必先指定度量；反过来，给定黎曼度量之后，则可以进一步寻找与该度量相容的特殊联络。下一章将证明，这样的联络存在且唯一，它就是 Levi-Civita 联络。

10.8 本章小结#

联络解决了不同点切空间之间缺乏天然比较方式的问题。它通过协变导数定义向量场及张量场的微分，并在局部坐标下由 Christoffel 符号描述。协变导数沿曲线的形式给出了平行移动，而平行移动使我们能够将不同点的切向量联系起来。联络由此成为测地线、曲率与整体黎曼几何的基础。

习题#

基础题

  1. 设 \(\nabla\) 是仿射联络，证明 \(\nabla_{fX}Y=f\nabla_XY\)，并证明 \(\nabla_X(fY)=(Xf)Y+f\nabla_XY\)。
  2. 设 \(\nabla_{\partial_i}\partial_j=\Gamma^k_{ij}\partial_k\)，推导向量场 \(Y=Y^j\partial_j\) 的协变导数坐标表达式。
  3. 设 \(\omega=\omega_jdx^j\) 是 1-形式，利用配对公式 \(X(\omega(Y))=(\nabla_X\omega)(Y)+\omega(\nabla_XY)\)，推导其协变导数的坐标表达式。
  4. 在欧氏平面极坐标 \((r,\theta)\) 下，考虑度量 \(g=dr^2+r^2d\theta^2\)。计算其 Christoffel 符号。

理论题

  1. 证明协变导数 \(\nabla T\) 对任意张量场 \(T\) 都满足张量的坐标变换律。
  2. 证明平行移动映射 \(P_\gamma:T_{\gamma(0)}M\to T_{\gamma(1)}M\) 是线性同构。
  3. 证明若沿曲线 \(V,W\) 都是平行移动的向量场，则 \(aV+bW\) 也是平行移动的，其中 \(a,b\in\mathbb R\)。
  4. 证明平行移动的复合性质：若 \(\gamma_1\) 的终点是 \(\gamma_2\) 的起点，则沿拼接曲线的平行移动等于两个平行移动映射的复合。

深入题

  1. 在二维欧氏平面极坐标下，计算向量场 \(Y=Y^r\partial_r+Y^\theta\partial_\theta\) 沿任意曲线的协变导数，并说明为什么即使平面是平坦的，极坐标中的协变导数仍包含非零 Christoffel 项。
  2. 设 \(V(t)\) 沿曲线 \(\gamma\) 平行移动。证明其坐标分量满足一阶线性常微分方程组，并解释初值唯一性如何保证平行移动映射的存在与唯一性。
  3. 设 \(\nabla\) 是仿射联络，\(f\in C^\infty(M)\)。证明 \(\nabla_X(df)\) 是一个对称的二阶协变张量，当且仅当联络无挠。
  4. 设 \(\nabla\) 是两个仿射联络，证明它们之差 \((X,Y)\mapsto\nabla_XY-\widetilde\nabla_XY\) 是一个 \((1,2)\) 型张量场。
