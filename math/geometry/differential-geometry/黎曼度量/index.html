Riemannian Metrics

光滑流形只描述空间的微分结构，却没有天然的长度、角度与距离。为了讨论曲线的长度、向量之间的夹角以及空间的曲率，我们需要在每个切空间上引入内积，并要求这些内积随基点光滑变化。这一结构称为黎曼度量。赋予黎曼度量的光滑流形称为黎曼流形（Riemannian manifold），它是经典黎曼几何研究的基本对象。

9.1 黎曼度量的定义#

设 \(M\) 是一个 \(n\) 维光滑流形。一个黎曼度量 \(g\) 是定义在 \(M\) 上的光滑对称正定 \((0,2)\) 型张量场。具体而言，对每一点 \(p\in M\)，它给出一个双线性映射 \(g_p:T_pM\times T_pM\to\mathbb R\)，满足对任意 \(X,Y\in T_pM\)，有 \(g_p(X,Y)=g_p(Y,X)\)，且 \(g_p(X,X)>0\) 对所有非零 \(X\) 成立。除此之外，\(g_p\) 还必须随 \(p\) 光滑变化。

黎曼度量本质上就是切空间上的内积，但它并非只在某一个固定向量空间上定义，而是在流形的每一点都给出一个内积。由于不同点的切空间彼此不同，我们不能直接将它们视为同一个向量空间；黎曼度量只负责在每个切空间内部测量向量之间的几何关系。

在局部坐标 \((x^1,\ldots,x^n)\) 下，记 \(g_{ij}=g(\partial_i,\partial_j)\)，则度量可以表示为 \(g=g_{ij}\,dx^i\otimes dx^j\)，其中 \(g_{ij}=g_{ji}\)。若向量场 \(X=X^i\partial_i\)、\(Y=Y^j\partial_j\)，则 \(g(X,Y)=g_{ij}X^iY^j\)。因此，黎曼度量在局部由一个对称正定矩阵 \((g_{ij})\) 描述。其逆矩阵记为 \((g^{ij})\)，满足 \(g^{ik}g_{kj}=\delta^i_j\)。

在欧氏空间 \(\mathbb R^n\) 的标准坐标下，标准欧氏度量为 \(g=\delta_{ij}\,dx^i\otimes dx^j\)，即 \(g(X,Y)=\sum_i X^iY^i\)。但在一般坐标系下，即使仍然是欧氏空间，度量分量也未必是单位矩阵。度量分量依赖坐标选择，而度量本身是坐标无关的几何对象。

9.2 向量长度与夹角#

给定黎曼流形 \((M,g)\)，每个切向量 \(X\in T_pM\) 的长度定义为 \(|X|_g=\sqrt{g_p(X,X)}\)。两个非零切向量 \(X,Y\in T_pM\) 之间的夹角 \(\theta\) 由 \(\cos\theta=\frac{g_p(X,Y)}{|X|_g|Y|_g}\) 确定。由 Cauchy–Schwarz 不等式，右侧始终属于 \([-1,1]\)，因此这一角度定义是良好的。

黎曼度量还允许我们讨论正交性：若 \(g_p(X,Y)=0\)，则称 \(X,Y\) 正交。对于一个切空间，黎曼度量赋予它完整的欧氏内积结构；但不同切空间之间的向量仍然不能直接比较。要定义不同点之间的向量如何变化，还需要引入联络，这将在后续章节讨论。

9.3 曲线长度与黎曼距离#

设 \(\gamma:[a,b]\to M\) 是一条分段光滑曲线，其速度向量为 \(\dot\gamma(t)\in T_{\gamma(t)}M\)。曲线在时刻 \(t\) 的速度大小为 \(\sqrt{g_{\gamma(t)}(\dot\gamma(t),\dot\gamma(t))}\)，因此曲线长度定义为

\[ \boxed{ L(\gamma)=\int_a^b \sqrt{g_{\gamma(t)}(\dot\gamma(t),\dot\gamma(t))}\,dt. } \]

这一表达式将曲线长度转化为沿参数区间的积分。它不依赖曲线的具体参数化：只要重新参数化保持曲线的几何轨迹与方向，长度就保持不变。

对于两个位于同一连通分支中的点 \(p,q\in M\)，定义它们之间的黎曼距离为连接二者的所有分段光滑曲线长度的下确界：

\[ \boxed{d_g(p,q)=\inf_{\gamma:p\to q}L(\gamma).} \]

这里的下确界并不意味着一定存在一条长度恰好等于该值的曲线。若存在这样的曲线，它便是一条连接 \(p,q\) 的极小曲线。后续将看到，在适当的完备性条件下，极小测地线的存在可以得到保证。

黎曼距离具有非负性、对称性以及三角不等式，并且对不同点满足 \(d_g(p,q)>0\)。因此，在连通黎曼流形上，\(d_g\) 定义了一个真正的度量空间结构。它诱导的拓扑与流形原有的拓扑一致。这一事实说明，黎曼度量不仅赋予流形局部的长度与角度，也使其成为一个具有内在距离结构的空间。

9.4 黎曼体积形式#

在 \(n\) 维流形上，黎曼度量还可以诱导体积结构。设 \(M\) 是一个定向的 \(n\) 维黎曼流形，在局部坐标下记度量矩阵为 \(g=(g_{ij})\)，则定义黎曼体积形式

\[ \boxed{ \operatorname{vol}_g = \sqrt{\det(g_{ij})}\, dx^1\wedge\cdots\wedge dx^n. } \]

由于黎曼度量正定，矩阵 \(g\) 的行列式严格为正。上述表达式在保持定向的坐标变换下保持一致，因此给出了一个全局定义的最高阶微分形式。

在标准欧氏空间中，\(g_{ij}=\delta_{ij}\)，因而 \(\det(g_{ij})=1\)，于是 \(\operatorname{vol}_g=dx^1\wedge\cdots\wedge dx^n\)。这正是通常的欧氏体积形式。

需要注意，黎曼体积形式与上一章讨论的一般最高阶微分形式有所不同：前者由度量自然确定，而后者只需要流形的定向结构。若流形不可定向，则不存在全局的黎曼体积形式，但仍然可以定义黎曼体积密度，并据此进行积分。

9.5 梯度#

在欧氏空间中，函数 \(f\) 的梯度由偏导数组成。但在一般流形上，微分 \(df\) 是一个余切向量，而梯度应当是一个切向量。黎曼度量提供了二者之间的自然对应。

具体地，函数 \(f\in C^\infty(M)\) 的梯度 \(\operatorname{grad}f\) 定义为满足

\[ \boxed{ g(\operatorname{grad}f,X)=df(X) } \]

的唯一向量场，其中 \(X\) 是任意光滑向量场。由于 \(g\) 非退化，这一向量场存在且唯一。这个定义也称为由度量诱导的音乐同构：度量将余向量 \(df\) 转化为向量 \(\operatorname{grad}f\)。

在局部坐标下，设 \(\operatorname{grad}f=(\operatorname{grad}f)^i\partial_i\)，则由 \(g_{ij}(\operatorname{grad}f)^iX^j=\partial_jf\,X^j\)，得到 \((\operatorname{grad}f)^i=g^{ij}\partial_jf\)。因此，梯度的坐标表达式为

\[ \boxed{ \operatorname{grad}f = g^{ij}\partial_jf\,\partial_i. } \]

这里 \(g^{ij}\) 是度量矩阵的逆矩阵。可以看到，梯度并非简单地将偏导数作为向量分量，而是必须借助逆度量将协变分量转化为逆变分量。

9.6 散度#

散度描述向量场在局部的体积膨胀或收缩程度。在黎曼流形上，它可以通过黎曼体积形式自然定义。设 \(X\) 是光滑向量场，\(\mathcal L_X\) 表示沿 \(X\) 的 Lie 导数，则定义

\[ \boxed{ \mathcal L_X\operatorname{vol}_g = (\operatorname{div}X)\operatorname{vol}_g. } \]

这里 \(\mathcal L_X\operatorname{vol}_g\) 描述体积形式沿向量场流动时的变化，而散度 \(\operatorname{div}X\) 则是这一变化相对于原体积形式的比例。

在局部坐标下，令 \(|g|=\det(g_{ij})\)，向量场写为 \(X=X^i\partial_i\)，则散度可以表示为

\[ \boxed{ \operatorname{div}X = \frac{1}{\sqrt{|g|}} \partial_i\left(\sqrt{|g|}\,X^i\right). } \]

这一公式揭示了散度与体积结构之间的关系。它并不是简单地对向量场的坐标分量求偏导，而是还要考虑体积元素 \(\sqrt{|g|}\) 随坐标变化的影响。

在欧氏空间的标准笛卡尔坐标下，\(\sqrt{|g|}=1\)，于是散度退化为熟悉的表达式 \(\operatorname{div}X=\partial_iX^i\)。

9.7 Laplace–Beltrami 算子#

在欧氏空间中，Laplace 算子定义为 \(\Delta f=\sum_i\partial_i^2f\)。在黎曼流形上，我们可以利用梯度与散度构造其自然推广，即 Laplace–Beltrami 算子：

\[ \boxed{ \Delta f = \operatorname{div}(\operatorname{grad}f). } \]

将梯度与散度的局部坐标公式代入，得到

\[ \boxed{ \Delta f = \frac{1}{\sqrt{|g|}} \partial_i\left( \sqrt{|g|}\,g^{ij}\partial_jf \right). } \]

这就是 Laplace–Beltrami 算子的局部表达式。它是一个二阶线性微分算子，描述函数在黎曼流形上的二阶变化。

在标准欧氏空间中，\(g^{ij}=\delta^{ij}\)、\(|g|=1\)，因此 \(\Delta f=\sum_i\partial_i^2f\)，恢复经典 Laplace 算子。由此可见，Laplace–Beltrami 算子是欧氏 Laplace 算子在一般黎曼流形上的自然推广。它在调和函数理论、偏微分方程、几何分析以及数学物理中都有重要应用。

需要说明的是，不同领域对 Laplace 算子的符号约定可能不同。有些文献采用 \(-\operatorname{div}\operatorname{grad}\)，以保证相应算子的谱具有非负性。本讲义采用 \(\Delta=\operatorname{div}\operatorname{grad}\) 的约定。

9.8 本章小结#

黎曼度量是在光滑流形的每个切空间上光滑变化的内积结构。它赋予向量长度、夹角与正交性，并进一步定义曲线长度和黎曼距离。度量还诱导黎曼体积形式，使流形具有自然的体积结构；通过度量与余切空间之间的对应，可以定义梯度，再结合体积形式定义散度，最终得到 Laplace–Beltrami 算子。至此，我们已经为流形建立了完整的局部度量结构。但还有一个重要问题尚未解决：不同点的切向量如何比较，如何定义向量沿曲线的变化率？这正是下一章引入联络的动机。

习题#

基础题

  1. 设 \(M=\mathbb R^2\)，度量为 \(g=dx^2+dy^2\)。计算向量 \(X=2\partial_x+3\partial_y\) 的长度，以及 \(X\) 与 \(Y=\partial_x-\partial_y\) 的夹角。
  2. 设 \(\mathbb R^2\) 上的度量为 \(g=dx^2+f(x)^2dy^2\)，其中 \(f(x)>0\)。写出度量矩阵及其逆矩阵。
  3. 对上述度量，计算黎曼体积形式。
  4. 设 \(f(x,y)=x^2+y^2\)，在标准欧氏度量下计算 \(\operatorname{grad}f\) 与 \(\Delta f\)。

理论题

  1. 证明黎曼度量在每个切空间上诱导的长度满足三角不等式。
  2. 证明黎曼距离的定义不依赖连接两点的曲线所采用的参数化。
  3. 证明在连通黎曼流形上，黎曼距离诱导的拓扑与原有流形拓扑一致。
  4. 从黎曼体积形式出发，推导局部坐标下的散度公式 \(\operatorname{div}X=\frac1{\sqrt{|g|}}\partial_i(\sqrt{|g|}X^i)\)。

深入题

  1. 设 \(g\) 是黎曼度量。证明映射 \(X\mapsto g(X,\cdot)\) 给出切丛与余切丛之间的光滑向量丛同构。
  2. 推导 Laplace–Beltrami 算子的局部坐标表达式，并证明它在欧氏标准坐标下退化为经典 Laplace 算子。
  3. 设 \(M\) 是紧致定向黎曼流形，证明对任意光滑向量场 \(X\)，有 \(\int_M\operatorname{div}X\,\operatorname{vol}_g=0\)。
  4. 设 \(M\) 是黎曼流形，\(f\) 是光滑函数。证明 \(\operatorname{grad}f\) 与等值面 \(f^{-1}(c)\) 正交（在 \(df\neq0\) 的点处）。
