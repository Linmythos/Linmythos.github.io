智能计算的数学基础与科学前沿

第一讲：机器为什么能够学习？ ——从函数逼近到统计学习理论 0. 核心问题 考虑一个简单任务： 给定大量房屋的历史数据，包括面积、位置、房间数量和成交价格，希望构造一个模型，根据房屋特征预测其价格。 我们可以将每套房屋表示为一个向量： [ x=(x_1,x_2,\ldots,x_d)\in\mathbb R^d, ] 将其实际价格记为： [ y\in\mathbb R. ] 我们希望找到一个函数： [ f:\mathbb R^d\longrightarrow\mathbb R, ] 使得： [ f(x)\approx y. ] 问题在于：我们只知道有限数量的样本，却希望模型能够预测尚未出现的数据。 这就是机器学习的基本矛盾： [ \boxed{ \text{有限样本}\longrightarrow\text{未知规律} } ] 机器学习的核心并不是简单地记忆数据，而是从有限观测中提取能够推广到新样本的规律。 本讲将从数学角度解释这一过程。 一、机器学习的数学形式化 1.1 数据与未知分布 设输入空间为 (\mathcal X)，输出空间为 (\mathcal Y)。 数据由某个未知概率分布生成： [ (X,Y)\sim P. ] 我们观察到独立同分布的训练样本： [ S={(x_1,y_1),(x_2,y_2),\ldots,(x_n,y_n)}. ] 即： [ (x_i,y_i)\overset{\mathrm{i.i.d.}}{\sim}P. ] 这里有三个重要对象： (P)：真实的数据生成分布； (S)：有限的训练样本； (f)：我们希望学习的预测函数。 机器学习算法根据样本 (S)，从某个函数集合中选择模型： [ \mathcal H={f_\theta:\theta\in\Theta}. ] 因此，学习过程可以抽象为： [ A:S\longmapsto \widehat f. ] 其中 (A) 是学习算法，(\widehat f) 是训练得到的模型。 注意：学习算法并不知道真实分布 (P)，它只能利用有限样本间接推断规律。 ...

智能计算系统：从数学原理到芯片设计

第一册：计算系统与性能基础 第一讲　从算法到芯片：计算系统的全栈视角 Lecture 1 — From Algorithms to Silicon: A Full-Stack View of Computing Systems 1.1　引言：计算究竟是什么？ 计算机科学经常被简单地理解为研究算法与程序的学科，计算机工程则被理解为研究处理器和电路的学科。 但现代计算系统远比这种划分复杂。 一个算法最终需要在具体硬件上执行，而硬件所能提供的计算能力，又受到指令集、微体系结构、存储系统、制造工艺和功耗预算等因素的共同制约。 因此，现代计算系统设计的核心问题并不只是： 如何设计一个更快的算法？ 而是： 如何使算法、编程模型、编译器、指令集、处理器架构和物理电路协同工作，从而在给定资源约束下实现最优的计算性能？ 这就是**软硬件协同设计（Hardware–Software Co-design）**的基本思想。 1.1.1　计算系统的抽象层次 一个典型的计算系统可以分解为以下层次： [ \boxed{ \text{Algorithm} \longrightarrow \text{Program} \longrightarrow \text{Compiler} \longrightarrow \text{ISA} \longrightarrow \text{Microarchitecture} \longrightarrow \text{Logic Circuit} \longrightarrow \text{Transistor} } ] 各层承担不同职责。 层次 核心对象 主要问题 算法层 数学算法、数据结构 如何完成计算任务？ 程序层 源代码、算子 如何描述计算过程？ 编译层 中间表示、优化 Pass 如何将程序转化为高效代码？ 指令集层 ISA 软件可以使用哪些机器操作？ 微体系结构层 CPU、GPU、缓存、流水线 如何组织和执行指令？ 电路层 逻辑门、组合与时序电路 如何实现逻辑功能？ 器件层 CMOS 晶体管 如何通过物理器件实现电路？ 这些层次之间存在严格的依赖关系，但并非只能单向设计。 ...
