PART I · 光学与电磁场基础#

波动方程和平面波解#

考虑电场具有单一角频率 \(\omega\) 的情形：

\[ \mathbf E(\mathbf r,t) = \operatorname{Re} \left[ \boldsymbol{\mathcal E}(\mathbf r)e^{-i\omega t} \right]. \]

这里 \(\boldsymbol{\mathcal E}(\mathbf r)\) 是复振幅；

代入波动方程：

\[ \nabla^2\mathbf E -\mu\varepsilon \frac{\partial^2\mathbf E}{\partial t^2} =0. \]

由于

\[ \frac{\partial^2}{\partial t^2} e^{-i\omega t} =-\omega^2e^{-i\omega t}, \]

得到：

\[ \nabla^2\boldsymbol{\mathcal E} +\omega^2\mu\varepsilon \boldsymbol{\mathcal E}=0. \]

定义波数：

\[ k=\omega\sqrt{\mu\varepsilon} =\frac{n\omega}{c} =\frac{2\pi n}{\lambda_0}, \]

其中 \(\lambda_0\) 是真空波长。

于是：

\[ \boxed{ \nabla^2\boldsymbol{\mathcal E} +k^2\boldsymbol{\mathcal E}=0 } \]

这就是亥姆霍兹方程 (Helmholtz Equation).

考虑沿 \(z\) 方向传播的平面波：

\[ \boldsymbol{\mathcal E}(z) = \mathbf E_0e^{ikz}. \]

不难验证它是 Helmholtz Equation 的一个解，称为平面波解。

平板波导与导模本征值问题#

以硅光子平台为例：

  • 高折射率硅作为波导芯层（core）；
  • 低折射率二氧化硅作为包层（cladding）。

通常有：

\[ n_{\mathrm{core}}>n_{\mathrm{cladding}}. \]

光可以被限制在高折射率区域附近传播。

先研究最简单的平板波导。

几何模型与基本假设#

考虑一个沿 \(z\) 方向无限延伸的平板波导，其折射率分布为：

\[ n(x)= \begin{cases} n_1,& |x|<a\quad\text{芯层}\\ n_2,& |x|>a\quad \text{上下包层}\end{cases} \]

\(n_1>n_2\)，介质均匀、线性、各向同性、无损且非磁性。

我们先研究电场没有沿传播方向的分量的情况，也即 TE(Transverse Electric) 模式

电场可以写成

\[ \mathbf E(x,z,t) = \hat{\mathbf y}\, \operatorname{Re}\left[ \psi(x)e^{i\beta z-i\omega t} \right]. \]

其中：\(\psi(x)\)：横向场分布

电场只有 \(y\) 分量，并且沿 \(y\) 方向不变化，因此

\[ \frac{\partial^2\mathcal E_y}{\partial y^2}=0. \]

得到

\[ \frac{\partial^2\mathcal E_y}{\partial x^2} + \frac{\partial^2\mathcal E_y}{\partial z^2} + k_0^2n^2(x)\mathcal E_y=0. \]

由于

\[ \frac{\partial^2}{\partial z^2}e^{i\beta z} =-\beta^2e^{i\beta z}, \]

约去公共因子 \(e^{i\beta z}\)，得到

\[ \boxed{ \frac{d^2\psi}{dx^2} + \left[k_0^2n^2(x)-\beta^2\right]\psi=0. } \]

这就是平板波导的横向标量波动方程。

芯层中的振荡解与包层中的衰减解#

第一种情况：芯层 \(|x|<a\)

\[ \psi’’+ (k_0^2n_1^2-\beta^2)\psi=0. \]

定义横向波数

\[ h=\sqrt{k_0^2n_1^2-\beta^2}. \]

于是

\[ \psi’’+h^2\psi=0. \]

其通解为

\[ \boxed{ \psi_1(x)=A\cos(hx)+B\sin(hx). } \]

这是振荡解。

第二种情况：包层 \(|x|>a\)

\[ \psi’’+ (k_0^2n_2^2-\beta^2)\psi=0. \]

为了得到远离芯层时衰减的导模，要求

\[ \beta^2>k_0^2n_2^2. \]

定义

\[ q=\sqrt{\beta^2-k_0^2n_2^2}. \]

方程变为

\[ \psi’’-q^2\psi=0. \]

其通解是指数函数。考虑两侧无穷远处都必须衰减：

\[ \boxed{ \psi_2(x)= \begin{cases} C e^{-q(x-a)},&x>a,\\ D e^{q(x+a)},&x<-a. \end{cases} } \]

这两个场就是导模的倏逝场（evanescent field）。

导模存在的传播常数条件#

芯层中要有振荡解,包层中要有衰减解，共同要求 \[ \boxed{ n_2k_0<\beta<n_1k_0 } \]

定义有效折射率

\[ n_{\mathrm{eff}}=\frac{\beta}{k_0}, \]

于是

\[ \boxed{ n_2<n_{\mathrm{eff}}<n_1} \]

这就是导模的基本条件。

当 \(\beta\) 接近 \(n_2k_0\) 时，\(q\) 趋近于零，包层中的衰减变得很慢，场延伸得更远。这对应模式接近截止的情形。

传播模式的特征方程#

目前我们分别得到了芯层和包层中的通解，在界面 \(x=\pm a\) 处，必须满足 Maxwell 方程给出的电磁边界条件。

对于这里的 TE 模式，在没有表面电流、介质界面不存在奇异源的条件下：

\[ E_y \quad \text{连续}, \]

\[ H_z \quad \text{连续}. \]

由 Maxwell 方程可以得到 \(H_z\) 与 \(\partial_x E_y\) 成正比，因此在本模型中等价于要求

\[ \boxed{ \psi \text{ 连续}\qquad \psi’ \text{ 连续} } \]

接下来利用关于 \(x=0\) 的镜像对称性，将模式分成偶模和奇模。

偶模#

偶模满足

\[ \psi(-x)=\psi(x). \]

因此芯层解中正弦项消失：

\[ \psi_1(x)=A\cos(hx). \]

在右界面 \(x=a\)，包层解为

\[ \psi_2(x)=C e^{-q(x-a)}. \]

先用场连续条件：

\[ A\cos(ha)=C. \]

再用导数连续条件：

\[ -Ah\sin(ha)=-qC. \]

代入 \(C=A\cos(ha)\)，得到

\[ \boxed{ h\tan(ha)=q} \]

这就是偶 TE 模的特征方程。

奇模#

奇模满足

\[ \psi(-x)=-\psi(x). \]

因此芯层解为

\[ \psi_1(x)=A\sin(hx). \]

在 \(x=a\) 处，场连续：

\[ A\sin(ha)=C. \]

导数连续：

\[ Ah\cos(ha)=-qC. \]

代入 \(C=A\sin(ha)\)，得到

\[ \boxed{ -h\cot(ha)=q } \]

这就是奇 TE 模的特征方程。

无量纲形式#

进一步地，我们希望把它们改写成无量纲形式，以便研究不同波导参数下的模式结构。

定义归一化横向参数：

\[ u=ha,\qquad w=qa. \]

由 \(h,q\) 的定义：

\[ h^2+q^2 =k_0^2(n_1^2-n_2^2). \]

两边乘以 \(a^2\)：

\[ u^2+w^2 =k_0^2a^2(n_1^2-n_2^2). \]

定义归一化频率：

\[ \boxed{ V=k_0a\sqrt{n_1^2-n_2^2}. } \]

于是

\[ \boxed{u^2+w^2=V^2.} \tag{2.7} \]

偶模和奇模的特征方程分别变为

\[ \boxed{u\tan u=w} \qquad\text{（偶模）}, \]

\[ \boxed{-u\cot u=w} \qquad\text{（奇模）}. \]

再结合

\[ w=\sqrt{V^2-u^2}, \]

我们得到只包含 \(u\) 和参数 \(V\) 的方程。

所以给定波导结构和工作波长，就可以通过求解特征方程确定其允许的导模。

模式正交性#

我们将会看到，不同的传播常数对应不同的模式，它们之间是“正交”的。

事实上，对于当前的无损标量模型，横向方程可以写成

\[ -\frac{d^2\psi_m}{dx^2} -k_0^2n^2(x)\psi_m = -\beta_m^2\psi_m. \]

这是一个 Sturm–Liouville 型本征值问题。

考虑两个不同模式：

\[ \psi_m’’+ (k_0^2n^2-\beta_m^2)\psi_m=0, \]

\[ \psi_n’’+ (k_0^2n^2-\beta_n^2)\psi_n=0. \]

第一式乘以 \(\psi_n^*\)，第二式乘以 \(\psi_m^*\)，然后相减并积分：

\[ \int_{-\infty}^{\infty} \left( \psi_n^*\psi_m’’ -\psi_m^*\psi_n’’ \right)dx + (\beta_n^2-\beta_m^2) \int_{-\infty}^{\infty} \psi_m^*\psi_n\,dx=0. \]

对第一项分部积分：

\[ \left[ \psi_n^*\psi_m’ -\psi_m^*\psi_n’ \right]_{-\infty}^{\infty} =0. \]

边界项为零，是因为导模在无穷远处指数衰减。因此

\[ (\beta_n^2-\beta_m^2) \int_{-\infty}^{\infty} \psi_m^*(x)\psi_n(x)\,dx=0. \]

若 \(\beta_m^2\neq\beta_n^2\)，则

\[ \boxed{ \int_{-\infty}^{\infty} \psi_m^*(x)\psi_n(x)\,dx=0. } \tag{2.8} \]

这就是标量模型中的模式正交性，也可以写作 \(\langle\psi_m,\psi_n\rangle=0\)

我们可以进一步将模式归一化，使其满足

\[ \boxed{ \int_{-\infty}^{\infty} \psi_m^*(x)\psi_n(x)\,dx =\delta_{mn}. } \]

假设某个光场由多个波导模式叠加而成：

\[ \mathcal E(x,z) = \sum_m c_m\psi_m(x)e^{i\beta_m z}. \]

模式正交性使我们能够将不同模式的贡献分离出来，分别研究它们的振幅和相位演化。

PART II · 定向耦合器与 Mach–Zehnder 干涉仪#

如何让光在不同波导之间转移？又如何利用相位控制，实现可调节的光学矩阵变换？

这需要两个基本器件：

  • 定向耦合器（Directional Coupler, DC）：使相邻波导中的光发生耦合与功率交换。
  • Mach–Zehnder 干涉仪（MZI）：利用分束、相位调制和合束，实现可调的双通道光学变换。

从单模波导到双波导系统#

耦合模理论#

先考虑两个完全相同、彼此隔离的波导。

设它们具有相同的传播常数 \(\beta\)，各自的模式振幅为 \(a_1(z)\)、\(a_2(z)\)。

如果两个波导互不耦合，那么： \[ \frac{da_1}{dz}=i\beta a_1, \qquad \frac{da_2}{dz}=i\beta a_2. \]

解为 \[ a_j(z)=a_j(0)e^{i\beta z}. \]

现在让两个波导靠近。

由于倏逝场在空间中有一定延伸，波导 1 的场会进入波导 2 附近，反之亦然。于是两个原本独立的模式发生相互作用。原先简并的两个模式会发生分裂，形成两个新的本征模式：

  • 对称超模（symmetric supermode）；
  • 反对称超模（antisymmetric supermode）。它们的振幅分布分别为 \[ \boxed{ \mathbf a_+ = \frac{1}{\sqrt2} \begin{pmatrix} 1\\1 \end{pmatrix}, \qquad \mathbf a_- = \frac{1}{\sqrt2} \begin{pmatrix} 1\\-1 \end{pmatrix}. } \]

设这两个超模的传播常数分别为 \[ \beta_+,\qquad \beta_-. \]

定义平均传播常数和耦合系数： \[ \boxed{ \beta=\frac{\beta_++\beta_-}{2}, \qquad \kappa=\frac{\beta_+-\beta_-}{2}. } \]

因此 \[ \beta_+=\beta+\kappa, \qquad \beta_-=\beta-\kappa. \]

这里 \(\kappa\) 就刻画了两个波导之间的耦合强度。波导距离越近，通常模式重叠越大，超模传播常数分裂也越明显。

现在将超模变换回原始波导模式

定义 \[ a_+=\frac{a_1+a_2}{\sqrt2}, \qquad a_-=\frac{a_1-a_2}{\sqrt2}. \]

由于超模是耦合波导系统的本征模式，它们分别独立传播： \[ \boxed{ \frac{da_+}{dz}=i(\beta+\kappa)a_+, } \]

\[ \boxed{ \frac{da_-}{dz}=i(\beta-\kappa)a_-. } \]

现在反变换： \[ a_1=\frac{a_++a_-}{\sqrt2}, \qquad a_2=\frac{a_+-a_-}{\sqrt2}. \]

对第一式求导： \[ \begin{aligned} \frac{da_1}{dz} &=\frac{1}{\sqrt2} \left[ i(\beta+\kappa)a_+ +i(\beta-\kappa)a_- \right]\\ &=i\beta\frac{a_++a_-}{\sqrt2} +i\kappa\frac{a_+-a_-}{\sqrt2}. \end{aligned} \]

所以 \[ \boxed{ \frac{da_1}{dz}=i\beta a_1+i\kappa a_2. } \]

同理： \[ \boxed{ \frac{da_2}{dz}=i\beta a_2+i\kappa a_1. } \]

这就得到了两个耦合模方程： \[ \boxed{ \begin{aligned} \frac{da_1}{dz}&=i\beta a_1+i\kappa a_2,\\ \frac{da_2}{dz}&=i\beta a_2+i\kappa a_1. \end{aligned} } \]

将方程写成矩阵形式：

\[ \frac{d\mathbf a}{dz} = i \begin{pmatrix} \beta&\kappa\\ \kappa&\beta \end{pmatrix} \mathbf a. \]

定义耦合矩阵

\[ H= \begin{pmatrix} \beta&\kappa\\ \kappa&\beta \end{pmatrix}, \]

则

\[ \boxed{ \frac{d\mathbf a}{dz}=iH\mathbf a. } \]

理想对称定向耦合器#

注意到

\[ H=\beta I+\kappa\sigma_x, \]

其中

\[ \sigma_x= \begin{pmatrix} 0&1\\ 1&0 \end{pmatrix}. \]

由于 \(I\) 与 \(\sigma_x\) 对易

\[ \mathbf a(z)=e^{iHz}\mathbf a(0) =e^{i\beta z}e^{i\kappa z\sigma_x}\mathbf a(0). \]

利用

\[ \sigma_x^2=I, \]

将指数展开：

\[ e^{i\kappa z\sigma_x} = \sum_{n=0}^{\infty} \frac{(i\kappa z\sigma_x)^n}{n!}. \]

将偶数项和奇数项分开：

\[ e^{i\kappa z\sigma_x} = I\cos(\kappa z) +i\sigma_x\sin(\kappa z). \]

因此

\[ \boxed{ U(z)=e^{i\beta z} \begin{pmatrix} \cos(\kappa z)&i\sin(\kappa z)\\ i\sin(\kappa z)&\cos(\kappa z) \end{pmatrix}. } \]

这就是理想对称定向耦合器的传输矩阵。

暂时忽略整体相位 \(e^{i\beta z}\)，定义

\[ C(\theta)= \begin{pmatrix} \cos\theta&i\sin\theta\\ i\sin\theta&\cos\theta \end{pmatrix}, \qquad \theta=\kappa z. \]

那么定向耦合器的作用就是

\[ \boxed{\mathbf a_{\mathrm{out}}=C(\theta)\mathbf a_{\mathrm{in}}.} \]

\( C^\dagger C=I，C\) 是酉矩阵（unitary matrix）。酉性意味着

\[ \|\mathbf a_{\mathrm{out}}\|^2 = \|\mathbf a_{\mathrm{in}}\|^2. \]

即总光功率守恒。

但真实器件存在传播损耗、散射和吸收时，传输矩阵一般不再是酉矩阵。

功率交换与耦合长度#

假设输入光只进入波导 1：

\[ \mathbf a(0)= \begin{pmatrix} 1\\0 \end{pmatrix}. \]

代入传输矩阵：

\[ \mathbf a(z) = e^{i\beta z} \begin{pmatrix} \cos(\kappa z)\\ i\sin(\kappa z) \end{pmatrix}. \]

于是两个波导中的功率分别为

\[ P_1(z)=\cos^2(\kappa z), \]

\[ P_2(z)=\sin^2(\kappa z). \]

当 \( \kappa z=\frac{\pi}{4} \) 时， \[ P_1=P_2=\frac12. \]

此时器件实现 50:50 分光。

当 \( \kappa z=\frac{\pi}{2} \) 时，\[ P_1=0\qquad P_2=1. \]

输入光全部转移到另一个波导。

定义完全功率转移所需的长度为耦合长度：

\[ \boxed{ L_c=\frac{\pi}{2\kappa}. } \]

而实现 50:50 分光的长度为

\[ \boxed{ L_{50:50}=\frac{\pi}{4\kappa}=\frac{L_c}{2}. } \]

这说明定向耦合器可以通过几何参数调节耦合强度，再通过器件长度控制功率分配。

Mach–Zehnder 干涉仪：从分光到干涉#

定向耦合器能够分配光功率，但它本身并不能充分实现可编程的相位控制。

现在将两个分束器连接起来，中间放置两条可以独立调节相位的光路，就得到 Mach–Zehnder 干涉仪。

它由三个核心部分组成：

  1. 第一个分束器：将输入光分成两路；
  2. 两个相位调制器：分别改变两路光的相位；
  3. 第二个分束器：将两路光重新合并，使它们发生干涉。

为了简化推导，我们假设两个分束器都是理想的 50:50 耦合器。

定义

\[ C_{50:50} = \frac{1}{\sqrt2} \begin{pmatrix} 1&i\\ i&1 \end{pmatrix}. \]

它满足

\[ C_{50:50}^\dagger C_{50:50}=I. \]

相位调制器的矩阵表示#

对于两条独立光路，定义相位矩阵

\[ D= \begin{pmatrix} e^{i\phi_1}&0\\ 0&e^{i\phi_2} \end{pmatrix}. \]

因此 MZI 的总传输矩阵为

\[ \boxed{ U_{\mathrm{MZI}} = C_{50:50}DC_{50:50}. } \]

计算得到

\[ U_{\mathrm{MZI}} = \frac12 \begin{pmatrix} e^{i\phi_1}-e^{i\phi_2} &i(e^{i\phi_1}+e^{i\phi_2})\\ i(e^{i\phi_1}+e^{i\phi_2}) &e^{i\phi_2}-e^{i\phi_1} \end{pmatrix}. \]

引入平均相位和相对相位：

\[ \phi_+=\frac{\phi_1+\phi_2}{2}, \qquad \phi_-=\frac{\phi_1-\phi_2}{2}. \]

得到

\[ \boxed{ U_{\mathrm{MZI}} = ie^{i\phi_+} \begin{pmatrix} \sin\phi_-&\cos\phi_-\\ \cos\phi_-&-\sin\phi_- \end{pmatrix}. } \]

这里的整体相位 \(ie^{i\phi_+}\) 对单独一个 MZI 的输出功率没有影响，但在多器件干涉网络中，必须根据具体连接关系判断它是否可以忽略。

MZI对输出功率的控制#

假设只有第一个输入端有光：

\[ \mathbf a_{\mathrm{in}} = \begin{pmatrix} 1\\0 \end{pmatrix}. \]

输出为

\[ \mathbf a_{\mathrm{out}} = ie^{i\phi_+} \begin{pmatrix} \sin\phi_-\\ \cos\phi_- \end{pmatrix}. \]

因此

\[ \boxed{ P_1=\sin^2\phi_-, \qquad P_2=\cos^2\phi_-. } \]

因此，MZI 可以通过调节两臂相位，实现从一个输出端到另一个输出端的连续功率转移。这正是它能够成为可编程光子器件的原因。

MZI 与二维酉变换#

一个 \(2\times2\) 酉矩阵 \(U\) 有四个实自由度。去掉一个整体相位后，剩下三个自由度。

而一个可调 MZI 可以通过内部相位差和外部相位调节来控制这些自由度。

令 \( \theta=\phi_-, \) 并将可控的输出相位记为 \(\alpha,\beta\)，可以得到一种常用参数化：

\[ \boxed{ U(\theta,\alpha,\beta) = \begin{pmatrix} e^{i\alpha}\sin\theta&e^{i\alpha}\cos\theta\\ e^{i\beta}\cos\theta&-e^{i\beta}\sin\theta \end{pmatrix}. } \]

其中：

  • \(\theta\)：控制两个通道之间的混合程度；
  • \(\alpha,\beta\)：控制输出端的相位。

所以 MZI 是一个可编程的二维线性变换单元。这也是为什么 MZI mesh（MZI 网格）能够用于实现更高维的矩阵运算。

从一个 MZI 到 MZI 网格#

一个 MZI 只作用于两个光学通道。

如果我们将多个 MZI 按照一定结构连接，就可以实现更高维的变换。

假设有 \(N\) 个输入通道，其复振幅构成向量

\[ \mathbf a_{\mathrm{in}} = \begin{pmatrix} a_1\\ a_2\\ \vdots\\ a_N \end{pmatrix}. \] 经过一个线性、无损、静态的光学网络后，输出为

\[ \mathbf a_{\mathrm{out}}=U\mathbf a_{\mathrm{in}}, \]

其中 \(U\in\mathbb C^{N\times N}\) 是传输矩阵。

无损意味着总功率守恒：

\[ \mathbf a_{\mathrm{out}}^\dagger\mathbf a_{\mathrm{out}} = \mathbf a_{\mathrm{in}}^\dagger\mathbf a_{\mathrm{in}}. \implies \mathbf a_{\mathrm{in}}^\dagger U^\dagger U\mathbf a_{\mathrm{in}} = \mathbf a_{\mathrm{in}}^\dagger\mathbf a_{\mathrm{in}}. \]

因此 \( U^\dagger U=I \) ，所以 \(U\) 是酉矩阵。

每一个 MZI 只混合两个通道，因此可以表示为一个嵌入到 \(N\) 维空间中的二维酉矩阵。例如，作用于第 \(j\) 和第 \(k\) 个通道的变换可以写为

\[ T_{jk} = I_{j,k}^{\perp}\oplus \begin{pmatrix} u_{11}&u_{12}\\ u_{21}&u_{22} \end{pmatrix}, \]

这里 \(I_{j,k}^{\perp}\) 表示在其他通道上保持恒等变换。

多个 MZI 级联：

\[ \boxed{ U=T_mT_{m-1}\cdots T_2T_1. } \]

这就把一个光子芯片的结构设计问题转化成了矩阵分解问题。

如果我们能够证明：

任意 \(N\times N\) 酉矩阵，都能分解成有限个只作用于两个坐标的二维酉变换的乘积。

那么就能用 MZI 网络实现任意 \(N\) 维酉变换。

这就引出了 Givens变换和Reck 分解

PART III · Reck 与 Clements 架构#

Givens 变换#

在 \(\mathbb C^N\) 中，选择两个不同的坐标 \(j,k\)。定义一个矩阵 \(G_{jk}\)，它在第 \(j,k\) 个坐标构成的二维子空间上作用为

\[ G(\theta,\phi)= \begin{pmatrix} \cos\theta&e^{i\phi}\sin\theta\\ -e^{-i\phi}\sin\theta&\cos\theta \end{pmatrix}, \]

而在其余坐标上保持恒等变换，它显然是二维酉变换。

给定 \[ \mathbf x= \begin{pmatrix} x_1\\x_2 \end{pmatrix} \in\mathbb C^2. \]

第二个分量为

\[ -e^{-i\phi} x_1sin\theta+x_2cos\theta . \]

若 \(x_1\neq0\)，选择

\[ e^{-i\phi}=\frac{x_2}{|x_2|}\frac{|x_1|}{x_1} \]

并选择

\[ \tan\theta=\frac{|x_2|}{|x_1|}, \]

就能消去一个复数分量。

Reck 分解#

现在从二维向量推广到矩阵。设 \( U\in U(N), \) 其中 \(U(N)\) 表示所有 \(N\times N\) 酉矩阵构成的集合。

我们的目标是找到一系列 Givens 变换，使得

\[ U=G_1G_2\cdots G_mD, \]

其中 \(D\) 是对角酉矩阵。这样最后剩下的对角相位可以由相位调制器实现。

从一个 \(3\times3\) 例子出发

\[ U= \begin{pmatrix} u_{11}&u_{12}&u_{13}\\ u_{21}&u_{22}&u_{23}\\ u_{31}&u_{32}&u_{33} \end{pmatrix}. \]

第一步，选择一个作用于第 2、3 行的 Givens 变换 \(G_{23}\)，使得第一列的第三个元素消失：

\[ G_{23}U= \begin{pmatrix} u_{11}&u_{12}&u_{13}\\ *&*&*\\ 0&*&* \end{pmatrix}. \]

第二步，选择作用于第 1、2 行的变换 \(G_{12}\)，使第一列的第二个元素消失：

\[ G_{12}G_{23}U= \begin{pmatrix} *&*&*\\ 0&*&*\\ 0&*&* \end{pmatrix}. \]

第三步，选择作用于第 2、3 行的变换，消去第二列的第三个元素：

\[ G_{23}‘G_{12}G_{23}U = \begin{pmatrix} *&*&*\\ 0&*&*\\ 0&0&* \end{pmatrix}. \]

最终得到上三角矩阵：

\[ R=G_mG_{m-1}\cdots G_1U. \]

由于每个 \(G_j\) 都是酉矩阵，而 \(U\) 也是酉矩阵，所以 \(R\) 仍然是酉矩阵。

而且它自动成为一个对角矩阵！

设 \(R\) 是一个上三角酉矩阵：

\[ R= \begin{pmatrix} r_{11}&r_{12}&\cdots&r_{1N}\\ 0&r_{22}&\cdots&r_{2N}\\ \vdots&\ddots&\ddots&\vdots\\ 0&\cdots&0&r_{NN} \end{pmatrix}. \]

由于

\[ R^\dagger R=I, \]

每一列的范数都等于 1，而且不同列之间正交。

考虑第一列：

\[ \begin{pmatrix} r_{11}\\0\\\vdots\\0 \end{pmatrix}. \]

它的范数为 1，所以

\[ |r_{11}|=1. \]

再看第一列与第二列的内积：

\[ r_{11}^*r_{12}=0. \]

由于 \(r_{11}\neq0\)，所以

\[ r_{12}=0. \]

同理，第一列与所有其他列正交，得到

\[ r_{1j}=0,\qquad j>1. \]

于是第一行除对角元外全部为零。

对剩余的 \((N-1)\times(N-1)\) 子矩阵重复这一论证，即证。

所以任意有限维酉矩阵都可以分解为有限个二维酉变换与对角相位矩阵的乘积。

\[ \boxed{ U=G_1^\dagger G_2^\dagger\cdots G_m^\dagger D} \]

并且 \[ \boxed{ m\underline<\frac{N(N-1)}{2} } \]

这就是 Reck 分解

Reck 架构：三角形 MZI 网格#

Reck 架构的核心思想就是把上面的消元过程直接映射到光学芯片，每个 Givens 变换使用 MZI 实现，它的数量按 \(O(N^2)\) 增长。

Reck 架构通常呈三角形排列，其优点是：

  • 分解过程直观；
  • 数学上与 Givens 消元直接对应；
  • 能够构造任意有限维酉变换。

但它也存在实际工程问题：不同光路经历的器件数量和传播路径长度可能不同，导致损耗不均衡。

Clements 架构：矩形 MZI 网格#

Clements 架构是另一种实现任意有限维酉变换的光学网络结构。它与Reck 架构的区别主要在于二维变换的排列方式和矩阵消元顺序。

以五模系统为例进行交错消元

初始矩阵 \[ U= \begin{pmatrix} \bullet&\bullet&\bullet&\bullet&\bullet\\ \bullet&\bullet&\bullet&\bullet&\bullet\\ \bullet&\bullet&\bullet&\bullet&\bullet\\ \bullet&\bullet&\bullet&\bullet&\bullet\\ \bullet&\bullet&\bullet&\bullet&\bullet \end{pmatrix}. \]

第 1 步：右乘 \(G_{1,2}^{-1}\) 选择 \(G_{1,2}\)，混合前两列，使第一列最下面的元素变为零： \[UG_{1,2}^{-1}= \begin{pmatrix} \bullet&\bullet&\bullet&\bullet&\bullet\\ \bullet&\bullet&\bullet&\bullet&\bullet\\ \bullet&\bullet&\bullet&\bullet&\bullet\\ \bullet&\bullet&\bullet&\bullet&\bullet\\ 0&\bullet&\bullet&\bullet&\bullet \end{pmatrix}. \]

第 2 步：左乘 \(G_{3,4}\) 和 \(G_{4,5}\) 继续通过相邻行变换消去第一列底部的元素，同时推进第二列的消元： \[ G_{4,5}G_{3,4}UG_{1,2}^{-1}. \]

对应的零元素逐步增加。图中右侧的两次交叉，就是作用于相邻模式 \((3,4)\)、\((4,5)\) 的 MZI。

第 3 步：左右交替消元 接下来在右侧加入 \[ G_{3,4}^{-1},\quad G_{2,3}^{-1},\quad G_{1,2}^{-1}, \]

同时在左侧继续加入相邻行变换。

例如，图中的这一阶段可以表示为 \[ \begin{aligned} U_4={}& G_{4,5}G_{3,4} U G_{1,2}^{-1}G_{2,3}^{-1}G_{3,4}^{-1}, \end{aligned} \]

具体乘积的先后顺序取决于图中采用的消元约定；关键是每一步只混合相邻行或相邻列，并且不破坏已经得到的零元素。

第 4 步：继续交替，直到对角化 重复这一过程，最终得到

\[ D= \begin{pmatrix} e^{i\varphi_1}&0&0&0&0\\ 0&e^{i\varphi_2}&0&0&0\\ 0&0&e^{i\varphi_3}&0&0\\ 0&0&0&e^{i\varphi_4}&0\\ 0&0&0&0&e^{i\varphi_5} \end{pmatrix}. \]

引入光学深度（optical depth）：一束光从输入端到输出端，最多需要依次通过多少层 MZI。

同一层中的 MZI 作用于互不重叠的模式对，可以同时工作，因此不增加彼此的串行深度。

例如，五模系统中： \[ (1,2),\ (3,4) \]

可以放在同一层，因为它们不共享模式。

而 \[ (1,2),\ (2,3) \]

不能放在同一层，因为它们都作用于模式 2。

对于Reck 网格，可以分为两部分：

  • 前半部分：光路逐渐进入三角网格深处；
  • 后半部分：光路从网格深处逐渐离开。

最深处的模式需要依次与其余 \(N-1\) 个模式发生耦合；离开最深处后，还需要经过另外 \(N-2\) 层耦合器才能到达输出。 注意，最后一个模式不需要再额外经过一层，因此第二部分是 \(N-2\)，而不是 \(N-1\)

因此： \[ \boxed{D_{\mathrm{Reck}}=(N-1)+(N-2)=2N-3.} \]

而 Clements 将 MZI 排列成矩形网格，相邻层交替采用两种配对： \[ \begin{aligned} \mathcal E&={(1,2),(3,4),(5,6),\ldots},\\ \mathcal O&={(2,3),(4,5),(6,7),\ldots}. \end{aligned} \]

每一层内部的 MZI 可以并行执行。

对于 \(N\) 个模式，矩形网格可以安排为 \(N\) 层： \[ \mathcal E,\mathcal O,\mathcal E,\mathcal O,\ldots \]

每一层最多包含 \( \left\lfloor\frac N2\right\rfloor \) 个 MZI。

因此，任意输入模式到输出模式的路径最多穿过 \(N\) 层： \[ \boxed{D_{\mathrm{Clements}}=N.} \]

矩形结构的优势#

矩形排列的一个重要优点是光路深度更加均衡。

考虑每个 MZI 的功率透过率均为 \(\eta\)。如果某条光路经过 \(d\) 个 MZI，其总功率透过率近似为

\[ \eta_{\mathrm{total}}=\eta^d. \]

因此，不同路径经历的器件数量差异会导致不同的累积损耗。

Reck 三角网格中，不同通道的光路深度可能存在较明显差异。

Clements 矩形网格通过交错排列，使不同输入输出路径的光学深度更加均衡，从而有利于减小通道间的损耗不均匀性。

不过，矩形结构并不意味着所有光路具有完全相同的损耗。实际性能仍然取决于 MZI 插入损耗、波导弯曲损耗、相位调制器损耗以及制造误差等因素。

从酉矩阵推广到一般矩阵：SVD#

到目前为止，我们讨论的都是无损光学网络，对应酉矩阵。

但实际计算任务往往需要实现一般复矩阵：

\[ A\in\mathbb C^{M\times N}. \]

一般矩阵不一定是酉矩阵，甚至可能不是方阵。

这时需要引入奇异值分解（Singular Value Decomposition, SVD）

对于任意复矩阵 \(A\)，存在酉矩阵 \(U,V\) 和非负对角矩阵 \(\Sigma\)，使得

\[ \boxed{ A=U\Sigma V^\dagger. } \]

其中：

  • \(U\)：左奇异向量构成的酉矩阵；
  • \(V\)：右奇异向量构成的酉矩阵；
  • \(\Sigma\)：奇异值构成的对角矩阵。

如果 \(A\) 是 \(N\times N\) 方阵，则可以写成

\[ A=U \begin{pmatrix} \sigma_1&&0\\ &\ddots&\\ 0&&\sigma_N \end{pmatrix} V^\dagger. \]

这对光学计算非常有意义：

  • \(V^\dagger\) 可以由一个酉光学网络实现；
  • \(\Sigma\) 对应通道振幅的缩放；
  • \(U\) 可以由另一个酉光学网络实现。

因此，理想情况下，一般线性变换可以分解成：

\[ \boxed{ \text{酉变换} \longrightarrow \text{振幅缩放} \longrightarrow \text{酉变换}. } \]

注意，振幅缩放不是无损酉变换，它通常需要通过可调衰减、损耗通道或更复杂的光学结构实现。这也解释了为什么许多可编程光子计算架构会把 SVD 与 MZI 网格联系起来。
