第一章 量子测量的基本问题#

1.1 从量子态到测量结果#

在第一篇中，我们建立了量子态的数学描述：

\[ \rho\geq0,\qquad \operatorname{Tr}(\rho)=1. \]

量子态本身并不是实验中直接读取的物理量。实验者需要通过测量获得经典结果。

例如，一个量子比特处于：

\[ |\psi\rangle

\alpha|0\rangle+\beta|1\rangle. \]

若在计算基：

\[ {|0\rangle,|1\rangle} \]

下测量，实验结果只有两种可能：

\[ 0,\qquad 1. \]

对应概率为：

\[ p(0)=|\alpha|^2, \]

\[ p(1)=|\beta|^2. \]

因此，量子测量涉及三个问题：

  • 可能出现哪些结果？
  • 每种结果出现的概率是多少？
  • 测量后系统处于什么状态？

这三个问题共同构成量子测量理论。

1.2 经典测量与量子测量#

经典系统的测量通常被理想化为读取一个已经存在的物理量。

量子系统则具有不同结构。

例如，对：

\[ |+\rangle

\frac{|0\rangle+|1\rangle}{\sqrt2} \]

进行计算基测量：

\[ p(0)=p(1)=\frac12. \]

若得到结果 0，在理想投影测量下，系统将变为：

\[ |0\rangle. \]

因此，测量不仅产生经典信息，还可能改变量子态。

测量反作用是量子信息理论的基本现象。

第二章 可观测量与谱分解#

2.1 可观测量#

量子力学中，一个可观测量由希尔伯特空间上的厄米算符描述。

定义 2.1（可观测量）

线性算符 \(A\) 若满足：

\[ \boxed{A^\dagger=A,} \]

则称为厄米算符。

有限维厄米算符的本征值均为实数。

设：

\[ A|a_i\rangle=a_i|a_i\rangle. \]

其中：

  • \(a_i\) 是本征值；
  • \(|a_i\rangle\) 是对应本征态。

根据有限维谱定理，厄米算符可以进行谱分解。

若本征值互不相同，则：

\[ \boxed{ A=\sum_i a_i|a_i\rangle\langle a_i|. } \]

更一般地，若存在简并，则：

\[ \boxed{ A=\sum_i a_iP_i, } \]

其中 \(P_i\) 是投影到本征值 \(a_i\) 对应本征子空间的正交投影算符。

2.2 投影算符#

定义 2.2（正交投影算符）

算符 \(P\) 若满足：

\[ P^\dagger=P, \]

\[ P^2=P, \]

则称为正交投影算符。

若：

\[ P=|\phi\rangle\langle\phi|, \]

且：

\[ \langle\phi|\phi\rangle=1, \]

则 \(P\) 是投影到一维子空间的秩一投影。

投影算符满足：

\[ P|\phi\rangle=|\phi\rangle. \]

若：

\[ |\psi\rangle\perp|\phi\rangle, \]

则：

\[ P|\psi\rangle=0. \]

2.3 谱投影的性质#

对于：

\[ A=\sum_i a_iP_i, \]

不同本征值对应的投影满足：

\[ \boxed{ P_iP_j=\delta_{ij}P_i. } \]

并且：

\[ \boxed{ \sum_iP_i=I. } \]

因此，谱投影构成一组完备的正交投影。

2.4 量子比特的 Pauli 测量#

考虑：

\[ A=\sigma_z= \begin{pmatrix} 1&0\ 0&-1 \end{pmatrix}. \]

其本征值为：

\[ a_+=1,\qquad a_-=-1. \]

对应本征态：

\[ |0\rangle,\qquad |1\rangle. \]

谱分解：

\[ \sigma_z

|0\rangle\langle0|#

|1\rangle\langle1|. \]

定义：

\[ P_0=|0\rangle\langle0|, \qquad P_1=|1\rangle\langle1|. \]

则：

\[ \sigma_z=P_0-P_1. \]

同理：

\[ \sigma_x= |+\rangle\langle+|

|-\rangle\langle-|. \]

所以：

  • 测量 \(\sigma_z\)：在计算基测量；
  • 测量 \(\sigma_x\)：在 Hadamard 基测量；
  • 测量 \(\sigma_y\)：在圆偏振基测量。

这三种测量将在后续光子实验中反复出现。

第三章 Born 规则#

3.1 纯态的测量概率#

设系统处于纯态：

\[ |\psi\rangle. \]

对可观测量：

\[ A=\sum_i a_iP_i \]

进行测量。

Born 规则规定：

\[ \boxed{ p(a_i)=\langle\psi|P_i|\psi\rangle. } \]

若 \(P_i\) 是秩一投影：

\[ P_i=|a_i\rangle\langle a_i|, \]

则：

\[ p(a_i)

\langle\psi|a_i\rangle \langle a_i|\psi\rangle. \]

即：

\[ \boxed{ p(a_i)=|\langle a_i|\psi\rangle|^2. } \]

这就是量子测量概率的基本公式。

3.2 密度矩阵形式#

对一般量子态：

\[ \rho, \]

Born 规则推广为：

\[ \boxed{ p(a_i)=\operatorname{Tr}(\rho P_i). } \]

当：

\[ \rho=|\psi\rangle\langle\psi| \]

时：

\[ \operatorname{Tr}(\rho P_i)

\operatorname{Tr} ( |\psi\rangle\langle\psi|P_i ). \]

利用迹的循环性质：

\[ \operatorname{Tr}(ABC)

\operatorname{Tr}(BCA), \]

得到：

\[ \operatorname{Tr}(\rho P_i)

\langle\psi|P_i|\psi\rangle. \]

因此，密度矩阵形式包含纯态形式作为特殊情况。

3.3 概率归一化#

由：

\[ \sum_iP_i=I, \]

可得：

\[ \sum_ip(a_i)

\sum_i\operatorname{Tr}(\rho P_i). \]

利用迹的线性性：

\[#

\operatorname{Tr} \left( \rho\sum_iP_i \right). \]

因此：

\[#

\operatorname{Tr}(\rho I). \]

于是：

\[ \boxed{ \sum_ip(a_i)=1. } \]

Born 规则与投影完备性保证了概率归一化。

3.4 测量期望值#

测量结果为 \(a_i\) 的概率为：

\[ p(a_i)=\operatorname{Tr}(\rho P_i). \]

因此，测量结果的期望值：

\[ \mathbb E[A]

\sum_i a_ip(a_i). \]

代入：

\[ \mathbb E[A]

\sum_i a_i\operatorname{Tr}(\rho P_i). \]

利用迹的线性性：

\[#

\operatorname{Tr} \left[ \rho\sum_i a_iP_i \right]. \]

所以：

\[ \boxed{ \langle A\rangle

\operatorname{Tr}(\rho A). } \]

这是量子力学中最重要的期望值公式之一。

3.5 方差#

测量结果的方差定义为：

\[ (\Delta A)^2

\langle A^2\rangle-\langle A\rangle^2. \]

其中：

\[ \langle A^2\rangle

\operatorname{Tr}(\rho A^2). \]

因此：

\[ \boxed{ (\Delta A)^2

\operatorname{Tr}(\rho A^2)#

[\operatorname{Tr}(\rho A)]^2. } \]

第四章 投影测量与测量后状态#

4.1 Lüders 投影测量#

定义 4.1（投影测量）

一组投影算符：

\[ {P_i} \]

若满足：

\[ P_iP_j=\delta_{ij}P_i, \]

以及：

\[ \sum_iP_i=I, \]

则称其为一组投影测量。

当系统处于状态 \(\rho\) 时，结果 \(i\) 的概率为：

\[ \boxed{ p(i)=\operatorname{Tr}(\rho P_i). } \]

若测得结果 \(i\)，采用 Lüders 更新规则时，测量后的状态为：

\[ \boxed{ \rho_i= \frac{P_i\rho P_i} {\operatorname{Tr}(\rho P_i)}. } \]

这里假设：

\[ p(i)>0. \]

4.2 为什么需要左右各乘一个投影算符？#

不能简单地写：

\[ \rho_i=P_i\rho. \]

因为一般而言：

\[ P_i\rho \]

不一定是厄米算符。

同样：

\[ \rho P_i \]

也不一定是厄米算符。

而：

\[ P_i\rho P_i \]

满足厄米性，并且是正半定的。

此外：

\[ \operatorname{Tr}(P_i\rho P_i)

\operatorname{Tr}(\rho P_i^2)#

\operatorname{Tr}(\rho P_i). \]

因此，归一化后：

\[ \operatorname{Tr}(\rho_i)=1. \]

4.3 例题：测量一个叠加态#

考虑：

\[ |\psi\rangle

\frac{|0\rangle+|1\rangle}{\sqrt2}. \]

初态密度矩阵：

\[ \rho= \frac12 \begin{pmatrix} 1&1\ 1&1 \end{pmatrix}. \]

在计算基进行投影测量：

\[ P_0= \begin{pmatrix} 1&0\ 0&0 \end{pmatrix}, \]

\[ P_1= \begin{pmatrix} 0&0\ 0&1 \end{pmatrix}. \]

结果 0 的概率：

\[ p(0)=\operatorname{Tr}(\rho P_0)=\frac12. \]

测量后：

\[ \rho_0

\frac{P_0\rho P_0}{p(0)}. \]

计算：

\[ P_0\rho P_0

\frac12 \begin{pmatrix} 1&0\ 0&0 \end{pmatrix}. \]

所以：

\[ \boxed{ \rho_0= \begin{pmatrix} 1&0\ 0&0 \end{pmatrix}

|0\rangle\langle0|. } \]

同理：

\[ \rho_1=|1\rangle\langle1|. \]

这说明计算基测量会将原来的相干叠加态投影到某个计算基态。

4.4 非选择性测量#

有时实验者只知道测量发生了，但不记录测量结果。

此时，测量后的状态是：

\[ \boxed{ \rho'

\sum_iP_i\rho P_i. } \]

这称为非选择性投影测量。

对上一节的叠加态：

\[ \rho= \frac12 \begin{pmatrix} 1&1\ 1&1 \end{pmatrix}, \]

有：

\[ \rho'

P_0\rho P_0+P_1\rho P_1. \]

因此：

\[ \boxed{ \rho'

\frac12 \begin{pmatrix} 1&0\ 0&1 \end{pmatrix}. } \]

原来的非对角元消失了。

这说明测量在计算基中消除了不同基态之间的相干项。

4.5 退相干的数学表达#

对于一般密度矩阵：

\[ \rho= \begin{pmatrix} \rho_{00}&\rho_{01}\ \rho_{10}&\rho_{11} \end{pmatrix}, \]

计算基非选择性投影测量给出：

\[ \boxed{ \rho’= \begin{pmatrix} \rho_{00}&0\ 0&\rho_{11} \end{pmatrix}. } \]

这称为完全去相干信道（在该基下）。

注意：这里消失的是指定测量基下的非对角元。退相干并不是无条件地把所有基下的相干性都消除。

第五章 一般 POVM#

投影测量是量子测量的一种重要形式，但并不是最一般的形式。

实际实验中，探测器可能不完美，测量结果也可能包含多个非正交的响应。

因此，需要更一般的测量理论。

5.1 POVM 的定义#

定义 5.1（POVM）

设：

\[ {E_i}_{i=1}^n \]

是一组作用于希尔伯特空间 \(\mathcal H\) 的算符。

若满足：

\[ \boxed{ E_i\geq0 } \]

以及：

\[ \boxed{ \sum_iE_i=I, } \]

则称其为一个正算符值测量（Positive Operator-Valued Measure, POVM）。

其中：

\[ E_i \]

称为 POVM 元素。

对系统状态 \(\rho\)，测量结果 \(i\) 的概率为：

\[ \boxed{ p(i)=\operatorname{Tr}(\rho E_i). } \]

5.2 为什么 POVM 元素只要求正半定？#

由于测量概率必须满足：

\[ p(i)\geq0, \]

所以对任意纯态：

\[ |\psi\rangle, \]

必须有：

\[ \langle\psi|E_i|\psi\rangle\geq0. \]

这恰好要求：

\[ E_i\geq0. \]

而概率归一化要求：

\[ \sum_i p(i)=1. \]

即：

\[ \operatorname{Tr} \left( \rho\sum_iE_i \right)=1. \]

对所有密度矩阵都成立，因此：

\[ \sum_iE_i=I. \]

这就是 POVM 两个条件的来源。

5.3 投影测量是 POVM 的特殊情况#

若：

\[ E_i=P_i, \]

且：

\[ P_iP_j=\delta_{ij}P_i, \]

则：

\[ E_i\geq0, \qquad \sum_iE_i=I. \]

因此，投影测量是 POVM 的特殊情况。

但一般 POVM 不要求：

\[ E_i^2=E_i. \]

也不要求：

\[ E_iE_j=0 \qquad(i\neq j). \]

这正是两者的区别。

5.4 POVM 元素的本征值范围#

因为：

\[ E_i\geq0, \]

所以所有本征值非负。

又因为：

\[ I-E_i

\sum_{j\neq i}E_j\geq0, \]

所以：

\[ E_i\leq I. \]

因此：

\[ \boxed{ 0\leq E_i\leq I. } \]

5.5 二结果 qubit POVM#

考虑：

\[ E_0= \frac12(I+\eta\sigma_z), \]

\[ E_1= \frac12(I-\eta\sigma_z). \]

其中：

\[ 0\leq\eta\leq1. \]

首先：

\[ E_0+E_1=I. \]

其次，\(\sigma_z\) 的本征值为 \(\pm1\)，因此：

\[ E_0 \]

的本征值为：

\[ \frac{1+\eta}{2}, \qquad \frac{1-\eta}{2}. \]

当：

\[ 0\leq\eta\leq1 \]

时，两者均非负。

同理：

\[ E_1\geq0. \]

所以这是一组合法 POVM。

其测量概率：

\[ p(0)=\operatorname{Tr}(\rho E_0), \]

\[ p(1)=\operatorname{Tr}(\rho E_1). \]

若：

\[ \rho= \frac12(I+r_x\sigma_x+r_y\sigma_y+r_z\sigma_z), \]

则：

\[ \boxed{ p(0)=\frac{1+\eta r_z}{2}, } \]

\[ \boxed{ p(1)=\frac{1-\eta r_z}{2}. } \]

参数 \(\eta\) 控制测量对 Bloch 向量 \(z\) 分量的敏感程度。

  • \(\eta=1\)：理想 \(z\) 方向投影测量；
  • \(\eta=0\)：两个结果各以 \(1/2\) 的概率出现，与输入态无关。

5.6 三结果 qubit POVM#

考虑三个单位向量：

\[ \vec n_1=(1,0,0), \]

\[ \vec n_2= \left(-\frac12,\frac{\sqrt3}{2},0\right), \]

\[ \vec n_3= \left(-\frac12,-\frac{\sqrt3}{2},0\right). \]

它们满足：

\[ |\vec n_i|=1, \]

以及：

\[ \sum_{i=1}^3\vec n_i=0. \]

定义：

\[ \boxed{ E_i= \frac13(I+\vec n_i\cdot\vec\sigma). } \]

验证正定性。

由于：

\[ (\vec n_i\cdot\vec\sigma)^2=I, \]

其本征值为：

\[ \pm1. \]

因此：

\[ I+\vec n_i\cdot\vec\sigma \]

的本征值为：

\[ 0,\quad2. \]

所以：

\[ E_i\geq0. \]

再验证完备性：

\[ \sum_iE_i

I+\frac13 \left( \sum_i\vec n_i \right)\cdot\vec\sigma. \]

由于：

\[ \sum_i\vec n_i=0, \]

所以：

\[ \boxed{ \sum_iE_i=I. } \]

这是一组合法的三结果 POVM。

5.7 POVM 的物理意义#

为什么需要多个非正交结果？

一个典型场景是量子态判别。

假设 Alice 可能制备两个非正交态：

\[ |\psi_0\rangle,\qquad |\psi_1\rangle. \]

Bob 希望判断 Alice 制备的是哪一个。

如果两个态不正交，则一般无法通过一次测量以概率 1 完美区分。

但通过合适的 POVM，可以实现：

  • 允许某些结果是不确定的；
  • 在给出确定判断时保证判断正确；
  • 或者最大化平均判别成功率。

这类问题称为量子态判别（Quantum State Discrimination）。

它是 POVM 的重要应用。

第六章 测量算符与 Kraus 表示#

POVM 只描述测量结果的概率，还不足以确定测量后状态。

为此，引入测量算符。

6.1 测量算符#

定义 6.1（测量算符）

一组算符：

\[ {M_i} \]

若满足：

\[ \boxed{ \sum_iM_i^\dagger M_i=I, } \]

则构成一组完备测量算符。

测量结果 \(i\) 的概率为：

\[ \boxed{ p(i)= \operatorname{Tr} (M_i\rho M_i^\dagger). } \]

利用迹的循环性质：

\[ p(i)

\operatorname{Tr} (\rho M_i^\dagger M_i). \]

定义：

\[ \boxed{ E_i=M_i^\dagger M_i. } \]

则：

\[ p(i)=\operatorname{Tr}(\rho E_i). \]

因此，测量算符总能诱导一个 POVM。

6.2 测量后的状态#

若测得结果 \(i\)，则：

\[ \boxed{ \rho_i= \frac{ M_i\rho M_i^\dagger }{ \operatorname{Tr}(M_i\rho M_i^\dagger) }. } \]

如果不记录测量结果：

\[ \boxed{ \rho’= \sum_iM_i\rho M_i^\dagger. } \]

注意：

\[ E_i=M_i^\dagger M_i \]

决定测量概率，但不唯一决定 \(M_i\)。

因此，同一个 POVM 可以对应不同的测量后状态。

6.3 同一 POVM 的不同测量实现#

设：

\[ E_i \]

为给定 POVM 元素。

利用极分解，可以写成：

\[ M_i=U_i\sqrt{E_i}, \]

其中 \(U_i\) 是适当的酉算符或部分等距算符。

于是：

\[ M_i^\dagger M_i

\sqrt{E_i}U_i^\dagger U_i\sqrt{E_i}. \]

在相关支撑空间上：

\[ M_i^\dagger M_i=E_i. \]

但测量后：

\[ M_i\rho M_i^\dagger

U_i\sqrt{E_i}\rho\sqrt{E_i}U_i^\dagger. \]

不同 \(U_i\) 会导致不同的测量后状态。

所以：

\[ \boxed{ \text{相同 POVM} \not\Rightarrow \text{相同测量反作用}. } \]

6.4 Lüders 测量#

对 POVM：

\[ {E_i}, \]

一种自然的测量实现是：

\[ \boxed{ M_i=\sqrt{E_i}. } \]

此时：

\[ \rho_i

\frac{ \sqrt{E_i}\rho\sqrt{E_i} }{ \operatorname{Tr}(\rho E_i) }. \]

对于投影测量：

\[ E_i=P_i, \]

由于：

\[ \sqrt{P_i}=P_i, \]

所以恢复：

\[ \rho_i= \frac{P_i\rho P_i} {\operatorname{Tr}(\rho P_i)}. \]

这正是 Lüders 更新规则。

第七章 量子仪器与量子信道#

7.1 为什么还需要量子仪器？#

POVM 描述：

\[ \text{测量结果的概率}. \]

测量算符描述：

\[ \text{给定测量结果后的状态更新}. \]

但实验中可能存在更复杂的过程：

  • 一个测量结果对应多个内部测量路径；
  • 辅助系统被丢弃；
  • 环境与系统发生相互作用；
  • 不同 Kraus 算符对应同一个经典结果。

因此，需要进一步推广。

7.2 量子仪器#

定义 7.1（量子仪器）

一个量子仪器由一组完全正的线性映射：

\[ {\mathcal I_i} \]

组成，使得：

\[ \mathcal I=\sum_i\mathcal I_i \]

是一个迹保持量子信道。

测量结果 \(i\) 的概率：

\[ \boxed{ p(i)=\operatorname{Tr}[\mathcal I_i(\rho)]. } \]

测量后的条件态：

\[ \boxed{ \rho_i= \frac{\mathcal I_i(\rho)}{p(i)}. } \]

非选择性输出态：

\[ \boxed{ \rho’=\sum_i\mathcal I_i(\rho). } \]

7.3 Kraus 表示#

每个完全正映射都可以写成 Kraus 形式：

\[ \boxed{ \mathcal I_i(\rho)

\sum_\alpha K_{i\alpha}\rho K_{i\alpha}^\dagger. } \]

其中：

\[ E_i= \sum_\alpha K_{i\alpha}^\dagger K_{i\alpha}. \]

整体完备性条件：

\[ \boxed{ \sum_{i,\alpha} K_{i\alpha}^\dagger K_{i\alpha}=I. } \]

这里：

  • \(i\)：实际记录的测量结果；
  • \(\alpha\)：同一结果下未被区分的内部过程。

7.4 POVM 与量子仪器的关系#

给定一个量子仪器：

\[ {\mathcal I_i}, \]

可以定义：

\[ E_i=\mathcal I_i^*(I), \]

其中 \(\mathcal I_i^*\) 是其对偶映射。

于是：

\[ p(i)=\operatorname{Tr}(\rho E_i). \]

因此，每个量子仪器都诱导一个 POVM。

但是反过来：

给定一个 POVM，并不能唯一确定对应的量子仪器。

这再次说明：

\[ \boxed{ \text{POVM 描述统计结果，量子仪器描述完整测量过程}. } \]

7.5 量子信道#

忽略测量结果后：

\[ \mathcal E(\rho)

\sum_{i,\alpha} K_{i\alpha}\rho K_{i\alpha}^\dagger. \]

这是一个量子信道。

其满足：

  1. 完全正性；
  2. 迹保持性。

迹保持性：

\[ \operatorname{Tr}[\mathcal E(\rho)]

\operatorname{Tr}(\rho). \]

完全正性要求即使系统与任意辅助系统纠缠，扩展映射仍保持正性。

量子信道是量子噪声和开放系统动力学的基本数学对象。

第八章 Naimark 扩张定理#

POVM 与投影测量之间存在一个深刻关系。

定理 8.1（Naimark 扩张定理）

任意有限维 POVM 都可以通过扩展希尔伯特空间上的投影测量实现。

换言之：

在适当引入辅助系统后，一般 POVM 可以看作更大系统上的投影测量。

8.1 定理的构造思路#

设原系统希尔伯特空间为：

\[ \mathcal H. \]

给定 POVM：

\[ {E_i}_{i=1}^n. \]

定义辅助空间：

\[ \mathcal K=\mathbb C^n. \]

取其标准正交基：

\[ {|i\rangle}_{i=1}^n. \]

构造映射：

\[ V:\mathcal H\rightarrow\mathcal H\otimes\mathcal K, \]

令：

\[ \boxed{ V|\psi\rangle

\sum_i\sqrt{E_i}|\psi\rangle\otimes|i\rangle. } \]

首先验证 \(V\) 是等距映射：

\[ V^\dagger V

\sum_iE_i#

I. \]

所以：

\[ \langle V\psi|V\psi\rangle

\langle\psi|\psi\rangle. \]

定义扩展空间上的投影：

\[ P_i=I\otimes|i\rangle\langle i|. \]

则：

\[ V^\dagger P_iV

E_i. \]

因此：

\[ \boxed{ \langle\psi|E_i|\psi\rangle

\langle V\psi|P_i|V\psi\rangle. } \]

左边是原系统的 POVM 概率，右边是扩展系统的投影测量概率。

这证明了 POVM 可以由扩展空间上的投影测量实现。

8.2 物理解释#

可以将整个过程理解为：

  1. 原系统与辅助系统组合；
  2. 通过适当的相互作用建立系统与辅助系统之间的关联；
  3. 对辅助系统或扩展系统进行投影测量；
  4. 将辅助自由度忽略。

因此，原系统上的非投影测量可以通过更大的系统上的投影测量实现。

Naimark 扩张揭示了 POVM 与投影测量在数学上的统一性。

第九章 测量反作用与量子退相干#

9.1 一个噪声化 qubit 测量#

考虑：

\[ E_\pm= \frac12(I\pm\eta\sigma_z), \]

其中：

\[ 0\leq\eta\leq1. \]

采用 Lüders 实现：

\[ M_\pm=\sqrt{E_\pm}. \]

因为：

\[ \sigma_z= \begin{pmatrix} 1&0\ 0&-1 \end{pmatrix}, \]

所以：

\[ E_+

\begin{pmatrix} \frac{1+\eta}{2}&0\ 0&\frac{1-\eta}{2} \end{pmatrix}. \]

于是：

\[ M_+

\begin{pmatrix} \sqrt{\frac{1+\eta}{2}}&0\ 0&\sqrt{\frac{1-\eta}{2}} \end{pmatrix}. \]

同理：

\[ M_-

\begin{pmatrix} \sqrt{\frac{1-\eta}{2}}&0\ 0&\sqrt{\frac{1+\eta}{2}} \end{pmatrix}. \]

9.2 非选择性测量信道#

设输入态：

\[ \rho= \begin{pmatrix} \rho_{00}&\rho_{01}\ \rho_{10}&\rho_{11} \end{pmatrix}. \]

测量后：

\[ \rho'

M_+\rho M_+ + M_-\rho M_-. \]

先计算第一项：

\[ M_+\rho M_+

\begin{pmatrix} \frac{1+\eta}{2}\rho_{00} & \frac{\sqrt{1-\eta^2}}2\rho_{01} \ \frac{\sqrt{1-\eta^2}}2\rho_{10} & \frac{1-\eta}{2}\rho_{11} \end{pmatrix}. \]

第二项：

\[ M_-\rho M_-

\begin{pmatrix} \frac{1-\eta}{2}\rho_{00} & \frac{\sqrt{1-\eta^2}}2\rho_{01} \ \frac{\sqrt{1-\eta^2}}2\rho_{10} & \frac{1+\eta}{2}\rho_{11} \end{pmatrix}. \]

相加：

\[ \boxed{ \rho'

\begin{pmatrix} \rho_{00}&\sqrt{1-\eta^2}\rho_{01}\ \sqrt{1-\eta^2}\rho_{10}&\rho_{11} \end{pmatrix}. } \]

因此：

  • \(z\) 方向的布居不变；
  • \(x,y\) 方向的相干性被削弱。

9.3 Bloch 球上的测量反作用#

输入态：

\[ \rho= \frac12 (I+r_x\sigma_x+r_y\sigma_y+r_z\sigma_z). \]

输出态：

\[ \boxed{ \rho'

\frac12 \left[ I+ \sqrt{1-\eta^2}r_x\sigma_x + \sqrt{1-\eta^2}r_y\sigma_y + r_z\sigma_z \right]. } \]

因此 Bloch 向量变为：

\[ \boxed{ \vec r'

\left( \sqrt{1-\eta^2}r_x, \sqrt{1-\eta^2}r_y, r_z \right). } \]

这是一个沿 \(z\) 方向保留、横向收缩的变换。

当：

\[ \eta=0 \]

时：

\[ \vec r’=\vec r. \]

测量不提取任何关于 \(z\) 分量的信息，也不扰动系统。

当：

\[ \eta=1 \]

时：

\[ \vec r’=(0,0,r_z). \]

所有横向相干性消失。

这就是理想 \(z\) 基测量造成的完全退相干。

9.4 信息提取与测量扰动#

测量锐度 \(\eta\) 越大，测量结果越能反映输入态的 \(z\) 分量。

但与此同时，横向相干性损失越大。

因此，信息提取与量子态扰动之间存在权衡。

这正是后续序贯测量研究的基础：

  • 第一个观察者希望提取尽可能多的信息；
  • 后续观察者希望系统保留尽可能多的量子特征。

两者的目标并不总是一致。

第十章 本篇总结与核心概念辨析#

本篇建立了量子测量的完整数学框架。

10.1 四个核心层次#

数学对象描述内容
可观测量 \(A\)物理量及其可能测量值
POVM \({E_i}\)测量结果的概率统计

量子仪器 \({\mathcal I_i}\)完整的测量结果与条件态演化

10.2 重要公式#

投影测量概率：

\[ p(i)=\operatorname{Tr}(\rho P_i). \]

投影测量后状态：

\[ \rho_i= \frac{P_i\rho P_i}{p(i)}. \]

非选择性投影测量：

\[ \rho’=\sum_iP_i\rho P_i. \]

POVM 完备性：

\[ E_i\geq0, \qquad \sum_iE_i=I. \]

POVM 概率：

\[ p(i)=\operatorname{Tr}(\rho E_i). \]

测量算符与 POVM：

\[ E_i=M_i^\dagger M_i. \]

\[ \sum_iM_i^\dagger M_i=I. \]
