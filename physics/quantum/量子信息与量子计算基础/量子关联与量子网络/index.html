第一章　从 Bell 不等式到相关集合#

1.1 Bell 实验的概率描述#

考虑两个空间分离的实验者 Alice 和 Bob。

Alice 的测量设置为

\[ x\in\mathcal X, \]

测量结果为

\[ a\in\mathcal A. \]

Bob 的测量设置为

\[ y\in\mathcal Y, \]

测量结果为

\[ b\in\mathcal B. \]

整个实验由条件概率分布

\[ \boxed{p(a,b|x,y)} \]

描述。

对于固定的输入集合和输出集合，一个 Bell 场景对应一个有限维概率空间。

例如，CHSH 场景中：

\[ \mathcal X=\mathcal Y={0,1}, \]

\[ \mathcal A=\mathcal B={-1,+1}. \]

因此共有

\[ 2\times2\times2\times2=16 \]

个条件概率。

但这些概率并非相互独立，因为每组输入都必须满足归一化：

\[ \sum_{a,b}p(a,b|x,y)=1. \]

此外，若要求无信号，还需要满足额外约束。

1.2 无信号相关集合#

定义 Alice 的边缘概率：

\[ p_A(a|x,y)=\sum_b p(a,b|x,y). \]

无信号条件要求

\[ \boxed{ p_A(a|x,y)=p_A(a|x). } \]

类似地，

\[ \boxed{ p_B(b|x,y)=p_B(b|y). } \]

所有满足概率非负、归一化和无信号条件的概率分布构成无信号相关集合：

\[ \mathcal{NS}. \]

即

\[ \mathcal{NS}

\left{ p(a,b|x,y): p\ge0,\ \text{归一化},\ \text{无信号} \right}. \]

这些约束都是线性的，因此 \(\mathcal{NS}\) 是一个凸多面体。

第二章　三类相关集合#

2.1 局域相关集合#

如果概率分布可以写成

\[ p(a,b|x,y)

\int d\lambda, q(\lambda) p(a|x,\lambda) p(b|y,\lambda), \]

则称其为局域相关。

所有这样的概率分布构成局域相关集合：

\[ \boxed{\mathcal L.} \]

在有限输入输出场景中，局域相关集合是有限个确定性局域策略的凸包。

因此它是一个凸多面体。

2.2 量子相关集合#

如果存在某个双体量子态

\[ \rho_{AB} \]

以及局域 POVM

\[ {E_{a|x}}a,\qquad {F{b|y}}_b, \]

使得

\[ \boxed{ p(a,b|x,y)

\operatorname{Tr} \left[ \rho_{AB} (E_{a|x}\otimes F_{b|y}) \right], } \]

则称该概率分布为量子相关。

所有量子相关构成集合

\[ \boxed{\mathcal Q.} \]

2.3 集合包含关系#

显然：

\[ \boxed{ \mathcal L\subseteq\mathcal Q\subseteq\mathcal{NS}. } \]

第一层包含关系来自：局域概率模型可以由乘积态和经典共享随机变量实现。

第二层包含关系来自量子测量的无信号性质。

但是反向包含关系不成立。

  • 有些量子相关无法由局域隐变量模型解释；
  • 有些无信号相关甚至无法由量子力学实现。

因此，三类集合之间存在严格的层次结构。

2.4 几何图像#

可以将三类相关集合想象为同一个有限维概率空间中的三个嵌套集合：

需要注意，\(\mathcal L\) 和 \(\mathcal{NS}\) 是多面体，而 \(\mathcal Q\) 的精确几何结构更复杂，不能简单将其视为一个已知有限面数的多面体。

第三章　凸几何基础#

3.1 凸集#

定义 3.1

集合 \(C\subseteq\mathbb R^n\) 称为凸集，如果对任意

\[ x,y\in C,\qquad t\in[0,1], \]

都有

\[ \boxed{ tx+(1-t)y\in C. } \]

直观而言，集合中任意两点之间的线段都属于集合。

3.2 为什么相关集合是凸的？#

假设两个概率分布

\[ p_1(a,b|x,y),\qquad p_2(a,b|x,y) \]

都属于某个相关集合。

如果实验者以概率 \(t\) 使用第一种策略，以概率 \(1-t\) 使用第二种策略，那么得到的分布为

\[ p

tp_1+(1-t)p_2. \]

因此，局域相关、量子相关和无信号相关集合都具有凸性。

对于量子相关，混合可以通过引入经典标记系统实现，或者直接将两个量子实现的状态与测量进行直和构造。

3.3 凸包与极点#

若集合由有限个点

\[ v_1,\ldots,v_N \]

生成，则其凸包为

\[ \operatorname{conv}{v_1,\ldots,v_N}

\left{ \sum_{i=1}^N\lambda_iv_i: \lambda_i\ge0,\ \sum_i\lambda_i=1 \right}. \]

其中不能再由其他点凸组合表示的点称为极点。

对于有限 Bell 场景，局域相关集合由确定性局域策略构成的有限集合生成。

这就是局域相关集合成为多面体的原因。

3.4 Bell 不等式作为超平面#

设相关分布用向量

\[ p\in\mathbb R^n \]

表示。

一个线性 Bell 不等式可以写为

\[ \boxed{ \beta\cdot p\le c. } \]

它定义一个半空间：

\[ H={p:\beta\cdot p\le c}. \]

如果该不等式对所有局域相关成立，那么

\[ \mathcal L\subseteq H. \]

当不等式对应局域多面体的一个面时，它称为 facet Bell inequality。

CHSH 不等式就是最著名的例子之一。

第四章　CHSH 场景的概率几何#

4.1 关联表示#

在二输入二输出场景中，令输出

\[ a,b\in{-1,+1}. \]

定义局域平均值：

\[ A_x=\sum_a a,p(a|x), \]

\[ B_y=\sum_b b,p(b|y). \]

定义关联函数：

\[ E_{xy}

\sum_{a,b}ab,p(a,b|x,y). \]

在无信号条件下，概率分布可以由以下八个参数表示：

\[ A_0,A_1,B_0,B_1, E_{00},E_{01},E_{10},E_{11}. \]

联合概率可重构为

\[ \boxed{ p(a,b|x,y)

\frac14 \left( 1+aA_x+bB_y+abE_{xy} \right). } \]

这里 \(a,b=\pm1\)。

该表达式可通过对 \(1,a,b,ab\) 四个函数作离散 Fourier 展开得到。

4.2 CHSH 不等式#

CHSH 表达式为

\[ S=E_{00}+E_{01}+E_{10}-E_{11}. \]

所有局域相关满足

\[ |S|\le2. \]

而量子相关可以达到

\[ |S|=2\sqrt2. \]

4.3 一个超量子相关：PR box#

考虑如下概率分布：

\[ \boxed{ p(a,b|x,y)

\begin{cases} \frac12,&ab=(-1)^{xy},\ 0,&\text{其他}. \end{cases} } \]

其中

\[ x,y\in{0,1},\qquad a,b\in{-1,+1}. \]

这个分布称为 Popescu–Rohrlich box，简称 PR box。

其物理含义是：

  • 当 \(xy=0\) 时，双方输出相同；
  • 当 \(xy=1\) 时，双方输出相反。

因此

\[ E_{00}=E_{01}=E_{10}=1, \]

\[ E_{11}=-1. \]

所以

\[ \boxed{S=4.} \]

这达到了 CHSH 表达式在无信号理论中的代数最大值。

但它不能由量子力学实现，因为量子理论满足 Tsirelson 界：

\[ |S|\le2\sqrt2. \]

4.4 PR box 为什么无信号？#

当固定 \(x,y\) 时，PR box 的两个允许输出对各自概率为 \(1/2\)。

对 Bob 的输出求和：

\[ p(a|x,y)=\frac12. \]

因此 Alice 的边缘概率与 Bob 的输入 \(y\) 无关。

同理，

\[ p(b|x,y)=\frac12. \]

所以 PR box 满足无信号条件。

这说明：

\[ \boxed{ \text{无信号性并不足以刻画量子力学。} } \]

量子理论对关联结构施加了比无信号性更强的限制。

第五章　量子相关集合的结构#

5.1 量子相关的参数化#

对于二值 qubit 测量，可以写成

\[ A_x=\vec a_x\cdot\vec\sigma, \]

\[ B_y=\vec b_y\cdot\vec\sigma. \]

关联函数为

\[ E_{xy}

\operatorname{Tr} \left[ \rho_{AB} (A_x\otimes B_y) \right]. \]

如果状态为单态：

\[ |\Psi^-\rangle

\frac{|01\rangle-|10\rangle}{\sqrt2}, \]

则

\[ E_{xy}

-\vec a_x\cdot\vec b_y. \]

所以量子相关集合受到向量几何与量子态结构的共同约束。

5.2 Tsirelson 不等式#

在 CHSH 场景中，量子相关必须满足

\[ |S|\le2\sqrt2. \]

这是一条量子相关集合的边界约束。

不过，Tsirelson 不等式并不能完全刻画整个量子相关集合。

它只是众多量子约束中的一个。

5.3 量子相关集合与半定规划#

对于更一般的 Bell 场景，直接优化量子态和 POVM 通常十分困难。

一个重要方法是利用矩阵半正定性。

考虑一组量子算符：

\[ O_1,\ldots,O_N. \]

定义 Gram 矩阵：

\[ \Gamma_{ij}

\langle O_i^\dagger O_j\rangle. \]

对任意复向量 \(c\)，有

\[ \begin{aligned} c^\dagger\Gamma c &= \sum_{i,j}c_i^*c_j \langle O_i^\dagger O_j\rangle\ &= \left\langle \left(\sum_i c_iO_i\right)^\dagger \left(\sum_jc_jO_j\right) \right\rangle\ &\ge0. \end{aligned} \]

所以

\[ \boxed{\Gamma\succeq0.} \]

即 Gram 矩阵必须是半正定矩阵。

这为量子相关优化提供了半定规划（Semidefinite Programming, SDP）方法。

5.4 NPA 层级#

Navascués–Pironio–Acín（NPA）层级利用不同阶数的算符乘积构造矩阵：

\[ \Gamma_{u,v}

\langle u^\dagger v\rangle. \]

通过要求

\[ \Gamma\succeq0 \]

并加入算符代数关系，例如

\[ A_x^2=I,\qquad B_y^2=I, \]

以及不同实验者算符之间的对易关系：

\[ [A_x,B_y]=0, \]

可以构造一系列半定规划松弛。

随着层级提高，这些约束越来越强。

在标准有限维 Bell 场景的适当闭包意义下，NPA 层级给出量子相关集合的系统性刻画。

它的价值在于：即使无法显式构造量子态与测量，也可以通过 SDP 对量子相关进行上界估计和非量子性检验。

第六章　多方量子关联#

6.1 三方 Bell 场景#

考虑三个实验者：

\[ A,\quad B,\quad C. \]

他们分别选择测量设置：

\[ x,y,z \]

并获得输出：

\[ a,b,c. \]

联合概率为

\[ p(a,b,c|x,y,z). \]

三方局域隐变量模型要求

\[ \boxed{ p(a,b,c|x,y,z)

\int d\lambda,q(\lambda) p(a|x,\lambda) p(b|y,\lambda) p(c|z,\lambda). } \]

6.2 GHZ 态#

一个重要的三量子比特纠缠态为

\[ \boxed{ |GHZ\rangle

\frac1{\sqrt2} (|000\rangle+|111\rangle). } \]

它不能写成任意两个子系统与第三个子系统的乘积态。

GHZ 态具有非常强的多体关联。

6.3 GHZ 矛盾#

定义 Pauli 算符：

\[ X=\sigma_x,\qquad Y=\sigma_y. \]

GHZ 态满足：

\[ X\otimes X\otimes X,|GHZ\rangle

|GHZ\rangle, \]

\[ X\otimes Y\otimes Y,|GHZ\rangle

-|GHZ\rangle, \]

\[ Y\otimes X\otimes Y,|GHZ\rangle

-|GHZ\rangle, \]

\[ Y\otimes Y\otimes X,|GHZ\rangle

-|GHZ\rangle. \]

因此量子力学预测：

\[ \langle XXX\rangle=1, \]

\[ \langle XYY\rangle

\langle YXY\rangle#

\langle YYX\rangle =-1. \]

假设存在确定性局域隐变量模型，令每个实验者的结果为

\[ A_X,A_Y,B_X,B_Y,C_X,C_Y\in{\pm1}. \]

那么局域模型必须满足

\[ A_XB_XC_X=1, \]

\[ A_XB_YC_Y=-1, \]

\[ A_YB_XC_Y=-1, \]

\[ A_YB_YC_X=-1. \]

将四个等式相乘：

左边为

\[ A_X^2A_Y^2B_X^2B_Y^2C_X^2C_Y^2=1. \]

右边为

\[ 1\cdot(-1)\cdot(-1)\cdot(-1)=-1. \]

于是得到

\[ 1=-1, \]

矛盾。

这就是 GHZ 的无不等式矛盾（all-versus-nothing argument）。

它表明，在理想预测下，局域确定性模型无法解释 GHZ 态的关联。

对于一般随机局域隐变量模型，可以通过将相关期望值的确定性约束作凸化，得到相应的 Bell 不等式形式。

第七章　量子网络非局域性#

7.1 从双体 Bell 场景到网络#

传统 Bell 实验通常假设 Alice 和 Bob 共享一个纠缠源。

但实际量子网络中可能存在多个独立纠缠源。

例如：

\[ A\longleftrightarrow C\longleftrightarrow B. \]

其中：

  • 第一个源连接 Alice 与中间节点 Charlie；
  • 第二个源连接 Charlie 与 Bob；
  • 两个源在实验设计中相互独立。

这构成最简单的双源网络，也称 bilocal scenario。

7.2 双源网络的经典模型#

令两个独立隐变量分别为

\[ \lambda,\qquad\mu. \]

源独立性要求

\[ \boxed{ q(\lambda,\mu)=q_1(\lambda)q_2(\mu). } \]

联合概率可以写为

\[ \begin{aligned} p(a,b,c|x,z)

\int d\lambda,d\mu, &q_1(\lambda)q_2(\mu)\ &\times p(a|x,\lambda) p(c|\lambda,\mu) p(b|z,\mu). \end{aligned} \]

这称为双局域模型（bilocal model）。

它与普通 Bell 局域模型的关键区别在于：

\[ q(\lambda,\mu) \]

必须因源独立性而分解。

7.3 为什么源独立性重要？#

如果不要求

\[ q(\lambda,\mu)=q_1(\lambda)q_2(\mu), \]

两个隐变量可以存在任意相关性。

这时中间节点的关联可能被一个共同隐变量解释。

因此，源独立性为网络实验引入了额外的结构约束。

它使得某些网络任务能够展示传统 Bell 场景中无法直接表达的非局域性资源。

7.4 双局域不等式#

在一个标准双源网络中，可以构造如下形式的双局域不等式：

\[ \boxed{ \sqrt{|I|}+\sqrt{|J|}\le1. } \]

这里 \(I,J\) 是由特定联合概率或关联函数构造的量。

该不等式的具体形式依赖于网络结构、中间节点的测量方式以及输出编码，不能脱离实验定义单独使用。

其重要特点是：它不是普通 Bell 多面体上的线性不等式，而是利用独立隐变量分布得到的非线性约束。

第八章　实验数据分析#

8.1 从实验计数得到概率#

对于三方实验，记录

\[ N_{abc|xyz} \]

表示输入设置 \((x,y,z)\) 下输出 \((a,b,c)\) 的计数。

总计数为

\[ N_{xyz}

\sum_{a,b,c}N_{abc|xyz}. \]

经验概率为

\[ \boxed{ \hat p(a,b,c|x,y,z)

\frac{N_{abc|xyz}}{N_{xyz}}. } \]

随后可以计算多体关联函数，例如

\[ E_{xyz}

\sum_{a,b,c} abc,p(a,b,c|x,y,z). \]

8.2 GHZ 实验统计量#

对 GHZ 实验，可以估计：

\[ \hat E_{XXX}, \quad \hat E_{XYY}, \quad \hat E_{YXY}, \quad \hat E_{YYX}. \]

理想情况下：

\[ E_{XXX}=1, \]

\[ E_{XYY}=E_{YXY}=E_{YYX}=-1. \]

因此可以构造 Mermin 型 Bell 统计量：

\[ \boxed{ M= E_{XXX} -E_{XYY} -E_{YXY} -E_{YYX}. } \]

量子力学对 GHZ 态预测：

\[ M=4. \]

对于标准三方局域隐变量模型：

\[ |M|\le2. \]

因此观察到

\[ |M|>2 \]

意味着违反该 Bell 不等式。

8.3 统计误差#

对于每个设置，令

\[ X=abc\in{-1,+1}. \]

若进行 \(N\) 次独立试验，则

\[ \hat E=\frac1N\sum_{k=1}^N X_k. \]

其标准误差近似为

\[ \boxed{ \Delta\hat E

\sqrt{\frac{1-\hat E^2}{N}}. } \]

若四组测量设置独立，则

\[ \boxed{ \Delta\hat M

\sqrt{ \sum_{s} \frac{1-\hat E_s^2}{N_s} }. } \]

有限统计下，应结合置信区间、实验采样方案和潜在系统误差判断 Bell 违反是否显著。

第九章　量子网络的应用#

9.1 量子中继#

远距离量子通信会受到光纤损耗的影响。

通过引入中间节点，可以使用纠缠交换建立远距离纠缠。

假设有两个 Bell 对：

\[ |\Phi^+\rangle_{AC_1} \otimes |\Phi^+\rangle_{C_2B}. \]

Charlie 对 \(C_1C_2\) 实施 Bell 态测量。

测量后，Alice 和 Bob 的系统可以投影到某个 Bell 态。

这就是纠缠交换（entanglement swapping）。

它是量子中继和量子网络的基础操作之一。

9.2 设备无关量子密码学#

Bell 非局域性可以用于设备无关量子密码学。

其基本思想是：

即使实验者不完全信任内部量子设备，只要观察到足够强的 Bell 违反，就可以对设备内部的某些行为作出严格的统计约束。

例如，适当的 Bell 违反可以用于认证随机性。

9.3 网络非局域性的研究方向#

量子网络研究还涉及：

  • 多源网络非局域性；
  • 纠缠交换；
  • 网络 steering；

本讲小结#

本讲将 Bell 非局域性从一个具体不等式推广为完整的概率几何问题。

核心结构：

\[ \boxed{ \mathcal L\subseteq\mathcal Q\subseteq\mathcal{NS}. } \]

其中：

  • \(\mathcal L\)：局域相关；
  • \(\mathcal Q\)：量子相关；
  • \(\mathcal{NS}\)：无信号相关。

我们进一步研究了：

\[ \text{凸几何} \longrightarrow \text{Bell 不等式} \longrightarrow \text{NPA 半定规划} \longrightarrow \text{多方量子关联} \longrightarrow \text{量子网络}. \]

下一讲将转向 量子纠缠的实验制备与表征：从 SPDC 光子源出发，研究 Bell 态制备、量子态层析、保真度估计、纠缠见证、密度矩阵重构及实验不确定度分析。
