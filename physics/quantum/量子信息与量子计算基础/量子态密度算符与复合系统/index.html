第一章 希尔伯特空间与量子态#

1.1 量子态的数学载体#

经典力学中，一个粒子的状态可以由位置和动量描述：

\[ (q,p)\in\Gamma, \]

其中 \(\Gamma\) 是相空间。

量子力学采用不同的数学结构：一个纯量子态由复希尔伯特空间中的单位向量描述。

定义 1.1（希尔伯特空间）

复内积空间 \(\mathcal H\) 若关于由内积诱导的范数完备，则称为复希尔伯特空间。

量子信息中最常见的是有限维希尔伯特空间：

\[ \mathcal H=\mathbb C^d. \]

在量子比特系统中：

\[ \mathcal H=\mathbb C^2. \]

我们通常选取一组标准正交基：

\[ |0\rangle= \begin{pmatrix} 1\0 \end{pmatrix}, \qquad |1\rangle= \begin{pmatrix} 0\1 \end{pmatrix}. \]

它们满足：

\[ \langle0|0\rangle=1, \qquad \langle1|1\rangle=1, \]

\[\langle0|1\rangle=\langle1|0\rangle=0. \]

任意量子比特纯态都可以写成：

\[ \boxed{ |\psi\rangle=\alpha|0\rangle+\beta1\rangle } \]

其中：

\[ \alpha,\beta\in\mathbb C. \]

归一化条件为：

\[ \boxed{ |\alpha|^2+|\beta|^2=1. } \]

这里的 \(\alpha,\beta\) 称为概率振幅。

注意：概率振幅是复数，不能直接把它们当作概率。实际测量概率由振幅的模平方给出。

1.2 Dirac 符号#

Dirac 符号是量子信息中最常用的记号。

一个态矢量写作：

\[ |\psi\rangle. \]

它称为 ket。

其共轭转置写作：

\[ \langle\psi|. \]

它称为 bra。

若：

\[ |\psi\rangle= \begin{pmatrix} \alpha\ \beta \end{pmatrix}, \]

则：

\[ \langle\psi|

\begin{pmatrix} \alpha^&\beta^ \end{pmatrix}. \]

内积#

\[ \langle\phi|\psi\rangle \]

是一个复数。

例如：

\[ |\psi\rangle= \frac1{\sqrt2} \begin{pmatrix} 1\i \end{pmatrix}, \qquad |\phi\rangle= \begin{pmatrix} 1\0 \end{pmatrix}. \]

则：

\[ \langle\phi|\psi\rangle

\frac1{\sqrt2}. \]

外积#

\[ |\psi\rangle\langle\phi| \]

是一个线性算符。

例如：

\[ |0\rangle\langle1|

\begin{pmatrix} 1\0 \end{pmatrix} \begin{pmatrix} 0&1 \end{pmatrix}

\begin{pmatrix} 0&1\ 0&0 \end{pmatrix}. \]

必须区分：

\[ \underbrace{\langle\phi|\psi\rangle}_{\text{内积：复数}} \]

与

\[ \underbrace{|\psi\rangle\langle\phi|}_{\text{外积：矩阵}}. \]

这是后续密度矩阵、投影算符和量子测量的基础。

1.3 整体相位与物理态#

考虑：

\[ |\psi\rangle

\alpha|0\rangle+\beta|1\rangle \]

和

\[ |\psi’\rangle

e^{i\theta} (\alpha|0\rangle+\beta|1\rangle). \]

二者的振幅不同，但所有测量概率都相同。

因为：

\[ |\langle\phi|\psi’\rangle|^2

|e^{i\theta}\langle\phi|\psi\rangle|^2#

|\langle\phi|\psi\rangle|^2. \]

所以：

\[ \boxed{ |\psi\rangle\sim e^{i\theta}|\psi\rangle. } \]

物理纯态不是希尔伯特空间中的某个具体单位向量，而是相差非零复数倍的向量所确定的射线。

这意味着纯态空间在数学上对应射影希尔伯特空间。

1.4 叠加原理#

若：

\[ |\psi_1\rangle,\ |\psi_2\rangle\in\mathcal H, \]

则它们的线性组合：

\[ |\psi\rangle

c_1|\psi_1\rangle+c_2|\psi_2\rangle \]

仍然属于 \(\mathcal H\)。

归一化后，它可以作为一个量子态。

例如：

\[ |+\rangle

\frac{|0\rangle+|1\rangle}{\sqrt2}, \]

\[ |-\rangle

\frac{|0\rangle-|1\rangle}{\sqrt2}. \]

这两个态构成另一组标准正交基。

它们与计算基之间的关系为：

\[ |+\rangle

\frac1{\sqrt2}|0\rangle+ \frac1{\sqrt2}|1\rangle, \]

\[ |-\rangle

\frac1{\sqrt2}|0\rangle- \frac1{\sqrt2}|1\rangle. \]

量子叠加不是经典概率混合。二者的区别将在第三章严格讨论。

第二章 纯态与密度算符#

2.1 为什么需要密度算符？#

纯态矢量：

\[ |\psi\rangle \]

能够描述一个已知的纯量子态。

但在量子信息实验中，我们经常面对以下情况：

  • 系统以概率 \(p_1\) 处于状态 \(|\psi_1\rangle\)；
  • 以概率 \(p_2\) 处于状态 \(|\psi_2\rangle\)；
  • 以概率 \(p_3\) 处于状态 \(|\psi_3\rangle\)。

其中：

\[ p_i\geq0, \qquad \sum_i p_i=1. \]

此时，单个态矢量无法完整描述统计状态。

我们需要一种能够统一描述纯态和统计混合的数学对象。

这就是密度算符。

2.2 纯态密度算符#

给定归一化纯态：

\[ |\psi\rangle, \]

定义：

\[ \boxed{ \rho=|\psi\rangle\langle\psi|. } \]

例如：

\[ |\psi\rangle

\alpha|0\rangle+\beta|1\rangle. \]

则：

\[ |\psi\rangle

\begin{pmatrix} \alpha\ \beta \end{pmatrix}, \]

\[ \langle\psi|

\begin{pmatrix} \alpha^&\beta^ \end{pmatrix}. \]

因此：

\[ \rho

\begin{pmatrix} \alpha\ \beta \end{pmatrix} \begin{pmatrix} \alpha^&\beta^ \end{pmatrix}. \]

得到：

\[ \boxed{ \rho= \begin{pmatrix} |\alpha|^2&\alpha\beta^\ \alpha^\beta&|\beta|^2 \end{pmatrix}. } \]

注意，密度矩阵的非对角元包含相干信息。

2.3 混态密度算符#

定义 2.1（密度算符）

量子态由满足以下条件的算符 \(\rho\) 描述：

  1. 厄米性：

\[ \rho^\dagger=\rho; \]

  1. 正半定性：

\[ \rho\geq0; \]

  1. 归一化：

\[ \operatorname{Tr}(\rho)=1. \]

若系统以概率 \(p_i\) 处于纯态 \(|\psi_i\rangle\)，则其密度算符为：

\[ \boxed{ \rho= \sum_i p_i|\psi_i\rangle\langle\psi_i|. } \]

其中：

\[ p_i\geq0, \qquad \sum_i p_i=1. \]

这种表示称为系综分解。

例如，考虑：

\[ \rho= \frac12|0\rangle\langle0| + \frac12|1\rangle\langle1|. \]

因为：

\[ |0\rangle\langle0|

\begin{pmatrix} 1&0\ 0&0 \end{pmatrix}, \]

\[ |1\rangle\langle1|

\begin{pmatrix} 0&0\ 0&1 \end{pmatrix}, \]

所以：

\[ \boxed{ \rho= \frac12 \begin{pmatrix} 1&0\ 0&1 \end{pmatrix}

\frac I2. } \]

这称为最大混态。

2.4 密度算符的基本性质#

定理 2.1

密度算符的所有本征值均为非负实数，且本征值之和为 1。

证明

由：

\[ \rho^\dagger=\rho, \]

知 \(\rho\) 为厄米算符，因此其本征值均为实数。

设：

\[ \rho|v\rangle=\lambda|v\rangle. \]

则：

\[ \langle v|\rho|v\rangle

\lambda\langle v|v\rangle. \]

由正半定性：

\[ \langle v|\rho|v\rangle\geq0. \]

因此：

\[ \lambda\geq0. \]

又由迹的性质：

\[ \operatorname{Tr}(\rho)

\sum_i\lambda_i=1. \]

证毕。

推论

任意密度算符都可以谱分解为：

\[ \boxed{ \rho=\sum_i\lambda_i|i\rangle\langle i|, } \]

其中：

\[ \lambda_i\geq0, \qquad \sum_i\lambda_i=1. \]

这说明密度算符可以表示为一组正交纯态的概率混合。

2.5 纯态与混态的判据#

定理 2.2

密度算符 \(\rho\) 对应纯态，当且仅当：

\[ \boxed{ \rho^2=\rho. } \]

等价地：

\[ \boxed{ \operatorname{Tr}(\rho^2)=1. } \]

证明

先考虑纯态：

\[ \rho=|\psi\rangle\langle\psi|. \]

则：

\[ \rho^2

|\psi\rangle \langle\psi|\psi\rangle \langle\psi|. \]

由于：

\[ \langle\psi|\psi\rangle=1, \]

所以：

\[ \rho^2=\rho. \]

于是：

\[ \operatorname{Tr}(\rho^2)

\operatorname{Tr}(\rho)=1. \]

反过来，设：

\[ \rho=\sum_i\lambda_i|i\rangle\langle i|. \]

则：

\[ \operatorname{Tr}(\rho^2)

\sum_i\lambda_i^2. \]

已知：

\[ \lambda_i\geq0, \qquad \sum_i\lambda_i=1. \]

因此：

\[ \sum_i\lambda_i^2\leq \left(\sum_i\lambda_i\right)^2=1. \]

等号成立当且仅当只有一个本征值非零，即某个本征值为 1，其余为 0。

此时：

\[ \rho=|\psi\rangle\langle\psi|. \]

证毕。

2.6 纯度#

定义：

\[ \boxed{ \gamma(\rho)=\operatorname{Tr}(\rho^2). } \]

称为态的纯度。

对 \(d\) 维系统：

\[ \frac1d\leq\gamma(\rho)\leq1. \]

  • \(\gamma=1\)：纯态；
  • \(\gamma=1/d\)：最大混态；
  • 中间值：一般混态。

对量子比特：

\[ \frac12\leq\gamma\leq1. \]

纯度是实验中判断量子态混合程度的重要指标。

第三章 叠加与统计混合#

这是初学量子信息时最容易混淆的地方。

3.1 两种不同的状态#

考虑两个量子比特状态：

\[ |+\rangle

\frac{|0\rangle+|1\rangle}{\sqrt2}. \]

它是一个纯态。

其密度矩阵为：

\[ \rho_+

|+\rangle\langle+|. \]

展开：

\[ \rho_+

\frac12 (|0\rangle+|1\rangle) (\langle0|+\langle1|). \]

因此：

\[ \boxed{ \rho_+

\frac12 \begin{pmatrix} 1&1\ 1&1 \end{pmatrix}. } \]

另一方面，考虑以相同概率制备：

\[ |0\rangle,\quad |1\rangle. \]

其密度矩阵为：

\[ \rho_{\mathrm{mix}}

\frac12|0\rangle\langle0| + \frac12|1\rangle\langle1|. \]

因此：

\[ \boxed{ \rho_{\mathrm{mix}}

\frac12 \begin{pmatrix} 1&0\ 0&1 \end{pmatrix}. } \]

二者并不相等：

\[ \rho_+\neq\rho_{\mathrm{mix}}. \]

关键区别在于非对角元：

\[ \rho_+: \quad \rho_{01}=\rho_{10}=\frac12, \]

而：

\[ \rho_{\mathrm{mix}}: \quad \rho_{01}=\rho_{10}=0. \]

这些非对角元描述相干性。

3.2 如何通过实验区分？#

如果沿计算基测量：

\[ {|0\rangle,|1\rangle}, \]

则两个状态都给出：

\[ p(0)=p(1)=\frac12. \]

所以仅通过计算基测量无法区分它们。

但是，如果改为测量：

\[ {|+\rangle,|-\rangle}, \]

则对于纯态 \(|+\rangle\)：

\[ p(+)=1, \qquad p(-)=0. \]

对于最大混态：

\[ p(+)=p(-)=\frac12. \]

因此，二者可以通过适当选择测量基区分。

结论：

叠加态具有相干性，而统计混合态不一定具有相干性。

不能仅凭某一组测量得到相同概率，就断言两个量子态相同。

第四章 量子比特与 Bloch 球#

4.1 Pauli 矩阵#

定义：

\[ \sigma_x= \begin{pmatrix} 0&1\ 1&0 \end{pmatrix}, \]

\[ \sigma_y= \begin{pmatrix} 0&-i\ i&0 \end{pmatrix}, \]

\[ \sigma_z= \begin{pmatrix} 1&0\ 0&-1 \end{pmatrix}. \]

以及：

\[ \sigma_0=I. \]

它们满足：

\[ \sigma_i^2=I, \]

\[ \operatorname{Tr}(\sigma_i)=0, \]

\[ \operatorname{Tr}(\sigma_i\sigma_j)

2\delta_{ij}. \]

还满足：

\[ [\sigma_i,\sigma_j]

2i\sum_k\epsilon_{ijk}\sigma_k, \]

\[ {\sigma_i,\sigma_j}

2\delta_{ij}I. \]

这里：

\[ [A,B]=AB-BA, \]

\[ {A,B}=AB+BA. \]

4.2 密度矩阵的 Pauli 展开#

任意 \(2\times2\) 厄米矩阵都可以写成：

\[ \rho=a_0I+a_x\sigma_x+a_y\sigma_y+a_z\sigma_z. \]

由：

\[ \operatorname{Tr}(\rho)=1, \]

得到：

\[ 2a_0=1. \]

因此：

\[ a_0=\frac12. \]

令：

\[ r_i=\operatorname{Tr}(\rho\sigma_i), \]

则：

\[ a_i=\frac{r_i}{2}. \]

所以：

\[ \boxed{ \rho= \frac12 (I+r_x\sigma_x+r_y\sigma_y+r_z\sigma_z). } \]

简写：

\[ \boxed{ \rho= \frac12(I+\vec r\cdot\vec\sigma). } \]

其中：

\[ \vec r=(r_x,r_y,r_z). \]

4.3 推导 Bloch 球条件#

由：

\[ \rho= \frac12(I+\vec r\cdot\vec\sigma), \]

利用 Pauli 矩阵的反对易关系：

\[ (\vec r\cdot\vec\sigma)^2

|\vec r|^2I. \]

因此，\(\vec r\cdot\vec\sigma\) 的本征值为：

\[ \pm|\vec r|. \]

所以 \(\rho\) 的本征值为：

\[ \lambda_\pm

\frac{1\pm|\vec r|}{2}. \]

密度矩阵正半定要求：

\[ \lambda_\pm\geq0. \]

于是：

\[ \boxed{ |\vec r|\leq1. } \]

这就是 Bloch 球的数学来源。

4.4 纯态与 Bloch 球表面#

计算：

\[ \rho^2

\frac14 (I+2\vec r\cdot\vec\sigma +|\vec r|^2I). \]

取迹：

\[ \operatorname{Tr}(\rho^2)

\frac12(1+|\vec r|^2). \]

因此：

\[ \boxed{ \operatorname{Tr}(\rho^2)

\frac{1+|\vec r|^2}{2}. } \]

纯态满足：

\[ \operatorname{Tr}(\rho^2)=1. \]

所以：

\[ |\vec r|=1. \]

最大混态满足：

\[ \vec r=0. \]

于是：

  • Bloch 球表面：纯态；
  • Bloch 球内部：混态；
  • 球心：最大混态。

4.5 球坐标表示#

纯态可写为：

\[ \boxed{ |\psi\rangle

\cos\frac\theta2|0\rangle + e^{i\phi}\sin\frac\theta2|1\rangle. } \]

对应 Bloch 向量：

\[ \boxed{ \vec r= (\sin\theta\cos\phi, \sin\theta\sin\phi, \cos\theta). } \]

特殊情况：

\[ |0\rangle \longleftrightarrow (0,0,1), \]

\[ |1\rangle \longleftrightarrow (0,0,-1), \]

\[ |+\rangle \longleftrightarrow (1,0,0), \]

\[ |-\rangle \longleftrightarrow (-1,0,0). \]

第五章 复合量子系统与张量积#

5.1 复合系统的希尔伯特空间#

设系统 \(A\) 的希尔伯特空间为：

\[ \mathcal H_A, \]

系统 \(B\) 的希尔伯特空间为：

\[ \mathcal H_B. \]

复合系统的希尔伯特空间为：

\[ \boxed{ \mathcal H_{AB}

\mathcal H_A\otimes\mathcal H_B. } \]

若：

\[ \dim\mathcal H_A=d_A, \qquad \dim\mathcal H_B=d_B, \]

则：

\[ \boxed{ \dim\mathcal H_{AB}=d_Ad_B. } \]

例如两个量子比特：

\[ \mathcal H_{AB}

\mathbb C^2\otimes\mathbb C^2#

\mathbb C^4. \]

5.2 张量积基#

设：

\[ {|0\rangle,|1\rangle} \]

是系统 \(A\) 的一组基，

\[ {|0\rangle,|1\rangle} \]

是系统 \(B\) 的一组基。

复合系统的标准基为：

\[ \boxed{ |00\rangle,\ |01\rangle,\ |10\rangle,\ |11\rangle. } \]

这里：

\[ |ij\rangle

|i\rangle_A\otimes|j\rangle_B. \]

按照这个约定：

\[ |0\rangle\otimes|1\rangle

|01\rangle. \]

5.3 张量积的矩阵计算#

设：

\[ |a\rangle= \begin{pmatrix} a_0\a_1 \end{pmatrix}, \qquad |b\rangle= \begin{pmatrix} b_0\b_1 \end{pmatrix}. \]

则：

\[ |a\rangle\otimes|b\rangle

\begin{pmatrix} a_0b_0\ a_0b_1\ a_1b_0\ a_1b_1 \end{pmatrix}. \]

例如：

\[ \frac{|0\rangle+|1\rangle}{\sqrt2} \otimes \frac{|0\rangle-|1\rangle}{\sqrt2} \]

等于：

\[ \boxed{ \frac12 (|00\rangle-|01\rangle+|10\rangle-|11\rangle). } \]

5.4 算符的张量积#

设：

\[ A= \begin{pmatrix} a_{11}&a_{12}\ a_{21}&a_{22} \end{pmatrix}, \]

\[ B= \begin{pmatrix} b_{11}&b_{12}\ b_{21}&b_{22} \end{pmatrix}. \]

则：

\[ A\otimes B

\begin{pmatrix} a_{11}B&a_{12}B\ a_{21}B&a_{22}B \end{pmatrix}. \]

例如：

\[ X\otimes I

\begin{pmatrix} 0&I\ I&0 \end{pmatrix}. \]

其作用于两个量子比特时，只翻转第一个量子比特。

类似地：

\[ I\otimes X \]

只翻转第二个量子比特。

一般而言：

\[ (A\otimes B)(C\otimes D)

AC\otimes BD. \]

这条性质是计算多量子比特量子线路的基础。

第六章 可分态与纠缠态#

6.1 乘积态#

若一个双量子比特纯态能够写成：

\[ |\psi\rangle_{AB}

|\phi\rangle_A\otimes|\chi\rangle_B, \]

则称其为乘积态。

例如：

\[ |\psi\rangle

\frac{|0\rangle+|1\rangle}{\sqrt2} \otimes|0\rangle. \]

展开：

\[ |\psi\rangle

\frac{|00\rangle+|10\rangle}{\sqrt2}. \]

这是一个乘积态。

6.2 Bell 态#

定义四个 Bell 态：

\[ |\Phi^+\rangle

\frac{|00\rangle+|11\rangle}{\sqrt2}, \]

\[ |\Phi^-\rangle

\frac{|00\rangle-|11\rangle}{\sqrt2}, \]

\[ |\Psi^+\rangle

\frac{|01\rangle+|10\rangle}{\sqrt2}, \]

\[ |\Psi^-\rangle

\frac{|01\rangle-|10\rangle}{\sqrt2}. \]

它们构成四维复合系统的一组标准正交基。

6.3 Bell 态为什么不是乘积态？#

考虑：

\[ |\Phi^+\rangle

\frac{|00\rangle+|11\rangle}{\sqrt2}. \]

假设它可以写成：

\[ |\Phi^+\rangle

(a|0\rangle+b|1\rangle) \otimes (c|0\rangle+d|1\rangle). \]

展开：

\[#

ac|00\rangle +ad|01\rangle +bc|10\rangle +bd|11\rangle. \]

比较系数：

\[ ac=\frac1{\sqrt2}, \]

\[ ad=0, \]

\[ bc=0, \]

\[ bd=\frac1{\sqrt2}. \]

由于：

\[ ac\neq0,\qquad bd\neq0, \]

所以：

\[ a,b,c,d\neq0. \]

但这与：

\[ ad=0,\qquad bc=0 \]

矛盾。

因此：

\[ \boxed{ |\Phi^+\rangle \neq |\phi\rangle_A\otimes|\chi\rangle_B. } \]

它是纠缠态。

6.4 可分混态#

纯态的可分性要求：

\[ |\psi\rangle_{AB}

|\phi\rangle_A\otimes|\chi\rangle_B. \]

但混态的可分性需要更一般的定义。

定义 6.1（可分态）

若双系统密度算符可以表示为：

\[ \boxed{ \rho_{AB}

\sum_i p_i \rho_A^{(i)}\otimes\rho_B^{(i)}, } \]

其中：

\[ p_i\geq0, \qquad \sum_i p_i=1, \]

则称 \(\rho_{AB}\) 为可分态。

不能写成这种形式的态称为纠缠态。

因此，混态即使不能写成单个乘积态，也不一定是纠缠态。

第七章 偏迹与约化密度矩阵#

这是量子信息中极为重要的计算工具。

7.1 为什么需要偏迹？#

考虑一个由两个子系统组成的复合系统：

\[ AB. \]

如果我们只关心系统 \(A\)，而不关心系统 \(B\)，应该怎样描述 \(A\)？

答案是：对 \(B\) 取偏迹。

定义 7.1（偏迹）

设复合系统密度算符为 \(\rho_{AB}\)，则系统 \(A\) 的约化密度算符定义为：

\[ \boxed{ \rho_A=\operatorname{Tr}B(\rho{AB}). } \]

在选定系统 \(B\) 的一组标准正交基：

\[ {|j\rangle_B} \]

后：

\[ \boxed{ \operatorname{Tr}B(\rho{AB})

\sum_j (I_A\otimes\langle j|) \rho_{AB} (I_A\otimes|j\rangle). } \]

这是偏迹的计算公式。

7.2 基本计算规则#

对于张量积算符：

\[ A\otimes B, \]

有：

\[ \boxed{ \operatorname{Tr}_B(A\otimes B)

A\operatorname{Tr}(B). } \]

特别地：

\[ \operatorname{Tr}_B ( |i\rangle\langle j| \otimes |k\rangle\langle l| )

|i\rangle\langle j| \langle l|k\rangle. \]

因此：

\[ \operatorname{Tr}_B ( |i\rangle\langle j| \otimes |k\rangle\langle l| )

\delta_{kl}|i\rangle\langle j|. \]

7.3 Bell 态偏迹的完整计算#

考虑：

\[ |\Phi^+\rangle

\frac{|00\rangle+|11\rangle}{\sqrt2}. \]

密度矩阵：

\[ \rho_{AB}

|\Phi^+\rangle\langle\Phi^+|. \]

展开：

\[ \rho_{AB}

\frac12 \left( |00\rangle\langle00| + |00\rangle\langle11| + |11\rangle\langle00| + |11\rangle\langle11| \right). \]

对第二个系统取偏迹。

第一项：

\[ \operatorname{Tr}_B (|00\rangle\langle00|)

|0\rangle\langle0|. \]

第二项：

\[ \operatorname{Tr}_B (|00\rangle\langle11|)

|0\rangle\langle1| \langle1|0\rangle =0. \]

第三项：

\[ \operatorname{Tr}_B (|11\rangle\langle00|)

|1\rangle\langle0| \langle0|1\rangle =0. \]

第四项：

\[ \operatorname{Tr}_B (|11\rangle\langle11|)

|1\rangle\langle1|. \]

所以：

\[ \rho_A

\frac12 \left( |0\rangle\langle0| + |1\rangle\langle1| \right). \]

即：

\[ \boxed{ \rho_A=\frac I2. } \]

同理：

\[ \boxed{ \rho_B=\frac I2. } \]

7.4 整体纯态与局部混态#

我们已经得到：

\[ \rho_{AB}

|\Phi^+\rangle\langle\Phi^+|. \]

所以：

\[ \operatorname{Tr}(\rho_{AB}^2)=1. \]

但：

\[ \rho_A=\frac I2. \]

因此：

\[ \operatorname{Tr}(\rho_A^2)

\operatorname{Tr} \left( \frac{I}{4} \right)

\frac12. \]

同理：

\[ \operatorname{Tr}(\rho_B^2)=\frac12. \]

于是：

\[ \boxed{ \text{整体纯态} \quad\not\Rightarrow\quad \text{局部纯态}. } \]

这是纠缠的核心现象之一。

系统 \(A\) 的约化态是混态，并不意味着整体系统一定处于混态。

7.5 偏迹与局域测量概率#

偏迹并非纯粹的数学操作，它有明确的物理意义。

若只对系统 \(A\) 测量 POVM：

\[ {E_a}, \]

则：

\[ p(a)

\operatorname{Tr} [ \rho_{AB}(E_a\otimes I_B) ]. \]

利用迹的性质：

\[ \boxed{ p(a)=\operatorname{Tr}(\rho_AE_a). } \]

其中：

\[ \rho_A=\operatorname{Tr}B(\rho{AB}). \]

因此，约化密度矩阵包含了系统 \(A\) 所有局域测量能够得到的统计信息。

7.6 Schmidt 分解定理#

定理 7.1（Schmidt 分解）

任意双系统纯态：

\[ |\psi\rangle_{AB} \in \mathcal H_A\otimes\mathcal H_B \]

都可以表示为：

\[ \boxed{ |\psi\rangle_{AB}

\sum_{i=1}^{r} \sqrt{\lambda_i} |u_i\rangle_A|v_i\rangle_B, } \]

其中：

\[ \lambda_i>0, \qquad \sum_i\lambda_i=1, \]

\({|u_i\rangle}\) 与 \({|v_i\rangle}\) 分别为两个子系统中的标准正交集。

证明思路：

将双系统纯态写成系数矩阵：

\[ |\psi\rangle

\sum_{ij}c_{ij}|i\rangle_A|j\rangle_B. \]

对矩阵 \(C=(c_{ij})\) 作奇异值分解：

\[ C=U\Sigma V^\dagger. \]

将酉矩阵 \(U,V\) 对应到两侧的新正交基，即得到 Schmidt 分解。

Schmidt 系数平方：

\[ \lambda_i \]

恰好是约化密度矩阵的非零本征值。

因此：

\[ \rho_A

\sum_i\lambda_i|u_i\rangle\langle u_i|, \]

\[ \rho_B

\sum_i\lambda_i|v_i\rangle\langle v_i|. \]

推论 7.1

双系统纯态可分，当且仅当 Schmidt 秩为 1。

双系统纯态纠缠，当且仅当 Schmidt 秩大于 1。

7.7 纠缠熵#

对纯态：

\[ |\psi\rangle_{AB}, \]

定义：

\[ \boxed{ S(\rho_A)

-\operatorname{Tr}(\rho_A\log\rho_A). } \]

称为纠缠熵。

对 Bell 态：

\[ \rho_A=\frac I2. \]

因此：

\[ S(\rho_A)

-\frac12\log\frac12 -\frac12\log\frac12. \]

若采用以 2 为底的对数：

\[ \boxed{ S(\rho_A)=1\ \text{bit}. } \]

而对于乘积纯态：

\[ \rho_A=|\phi\rangle\langle\phi|, \]

有：

\[ S(\rho_A)=0. \]

所以，对双系统纯态而言，约化态的熵可以作为纠缠量的度量。

第八章 本篇总结#

本篇建立了量子信息理论最基础的数学语言。

核心对象：

\[ |\psi\rangle \]

描述纯态；

\[ \rho \]

描述一般量子态；

\[ \mathcal H_A\otimes\mathcal H_B \]

描述复合系统；

\[ \rho_A=\operatorname{Tr}B(\rho{AB}) \]

描述局部子系统。

需要牢固掌握以下逻辑：

\[ \boxed{ \begin{aligned} &\text{纯态} &&\longleftrightarrow \rho^2=\rho,\ &\text{混态} &&\longleftrightarrow \operatorname{Tr}(\rho^2)<1,\ &\text{复合系统} &&\longleftrightarrow \mathcal H_A\otimes\mathcal H_B,\ &\text{乘积纯态} &&\longleftrightarrow |\psi\rangle=|\phi\rangle_A\otimes|\chi\rangle_B,\ &\text{纠缠纯态} &&\longleftrightarrow \text{Schmidt 秩}>1,\ &\text{局部状态} &&\longleftrightarrow \rho_A=\operatorname{Tr}B(\rho{AB}). \end{aligned} } \]

下一篇将在此基础上建立量子测量理论，从 Born 规则出发，系统讨论投影测量、POVM、测量算符、量子仪器以及 Naimark 扩张定理。
