第九讲：从经典光场到量子光场——电磁场的量子化#

前面几讲，我们一直用复振幅描述光：

\[ E(z,t)=\operatorname{Re} \left[Ae^{i(kz-\omega t)}\right]. \]

在集成光子芯片中，我们把多个光学模式的复振幅组织成向量：

\[ \mathbf a_{\mathrm{out}}=U\mathbf a_{\mathrm{in}}. \]

这套理论属于经典电磁场理论。

但当我们研究单光子干涉、量子隐形传态、玻色采样和光量子计算时，仅仅描述光场的经典振幅就不够了。

我们需要回答：

  • 一个光学模式中有多少个光子？
  • 什么是单光子态？
  • 光子如何通过分束器？
  • 两个光子为什么会发生不同于经典光波的干涉？

这些问题需要量子化电磁场理论。

本讲的核心路线是：

\[ \boxed{ \text{经典电磁场} \longrightarrow \text{谐振子} \longrightarrow \text{产生与湮灭算符} \longrightarrow \text{Fock 态} \longrightarrow \text{相干态} } \]

我们从最基础的数学结构开始。

9.1 为什么需要量子化电磁场？#

9.1.1 经典光场的描述#

在经典理论中，一个单色光学模式可以用复振幅描述：

\[ E(t)=A\cos(\omega t+\phi). \]

这里：

  • \(A\) 表示场振幅；
  • \(\omega\) 表示角频率；
  • \(\phi\) 表示相位。

在经典理论中，\(A\) 和 \(\phi\) 是确定的参数。

但是，光与物质的相互作用具有量子性质。例如光电效应、单光子探测和原子能级跃迁，都需要引入光子的概念。

我们需要一种理论，既能描述电磁场的传播，又能描述能量以光子为单位的量子化特征。

这就是量子化电磁场。

9.1.2 一个重要思想：电磁场可以分解为模式#

回顾第二讲的波导模式：

\[ \mathbf E(x,y,z) = \mathbf e(x,y)e^{i\beta z}. \]

这里的横向分布 \(\mathbf e(x,y)\) 对应一个波导模式。

更一般地，在适当的边界条件下，电磁场可以分解为一组独立的正常模式（Normal Modes）。

例如，一个理想谐振腔中的电磁场可以写成：

\[ \mathbf E(\mathbf r,t) = \sum_m q_m(t)\mathbf u_m(\mathbf r), \]

其中：

  • \(\mathbf u_m(\mathbf r)\)：第 \(m\) 个空间模式；
  • \(q_m(t)\)：对应模式的时间振幅。

经典电磁场的能量可以表示为各模式能量之和：

\[ H=\sum_m H_m. \]

在适当归一化下，每个模式都具有与简谐振子相同的数学结构。

这就是量子化电磁场的关键入口。

9.2 从简谐振子到量子谐振子#

9.2.1 经典简谐振子#

考虑一个质量为 \(m\)、角频率为 \(\omega\) 的一维简谐振子。

其势能为：

\[ V(x)=\frac12m\omega^2x^2. \]

动能为：

\[ T=\frac{p^2}{2m}. \]

因此哈密顿量为：

\[ \boxed{ H=\frac{p^2}{2m} +\frac12m\omega^2x^2. } \tag{9.1} \]

其中 \(x\) 是位置，\(p\) 是动量。

经典运动方程为：

\[ \dot x=\frac{p}{m}, \qquad \dot p=-m\omega^2x. \]

于是：

\[ \ddot x+\omega^2x=0. \]

其解为：

\[ x(t)=A\cos(\omega t+\phi). \]

注意，这与单个经典电磁模式的振荡形式完全相似。

9.2.2 量子化#

量子力学中，位置和动量不再是普通数值，而是厄米算符：

\[ \hat x,\qquad \hat p. \]

它们满足正则对易关系：

\[ \boxed{ [\hat x,\hat p]=i\hbar. } \tag{9.2} \]

这里：

\[ [\hat A,\hat B] = \hat A\hat B-\hat B\hat A \]

称为对易子。

\(\hbar\) 是约化普朗克常数：

\[ \hbar=\frac{h}{2\pi}. \]

量子谐振子的哈密顿算符为：

\[ \boxed{ \hat H= \frac{\hat p^2}{2m} +\frac12m\omega^2\hat x^2. } \tag{9.3} \]

接下来，我们希望把它改写成一种更简洁的形式。

9.3 产生算符与湮灭算符#

9.3.1 定义#

定义湮灭算符：

\[ \boxed{ \hat a= \sqrt{\frac{m\omega}{2\hbar}}\hat x + \frac{i}{\sqrt{2m\hbar\omega}}\hat p. } \tag{9.4} \]

其厄米共轭称为产生算符：

\[ \boxed{ \hat a^\dagger= \sqrt{\frac{m\omega}{2\hbar}}\hat x - \frac{i}{\sqrt{2m\hbar\omega}}\hat p. } \tag{9.5} \]

为什么这样定义？

因为它们能够把哈密顿量写成非常简洁的形式，并且具有明确的升降能级作用。

9.3.2 推导对易关系#

记：

\[ \alpha=\sqrt{\frac{m\omega}{2\hbar}}, \qquad \beta=\frac{1}{\sqrt{2m\hbar\omega}}. \]

那么：

\[ \hat a=\alpha\hat x+i\beta\hat p, \]

\[ \hat a^\dagger=\alpha\hat x-i\beta\hat p. \]

计算：

\[ [\hat a,\hat a^\dagger] = [\alpha\hat x+i\beta\hat p, \alpha\hat x-i\beta\hat p]. \]

利用对易子的双线性：

\[ \begin{aligned} [\hat a,\hat a^\dagger] ={}&-i\alpha\beta[\hat x,\hat p]\\ &+i\alpha\beta[\hat p,\hat x]. \end{aligned} \]

又因为：

\[ [\hat p,\hat x]=-[\hat x,\hat p]=-i\hbar, \]

所以：

\[ \begin{aligned} [\hat a,\hat a^\dagger] &=-i\alpha\beta(i\hbar) +i\alpha\beta(-i\hbar)\\ &=2\alpha\beta\hbar. \end{aligned} \]

而：

\[ \alpha\beta=\frac12\frac1{\hbar}. \]

因此：

\[ \boxed{ [\hat a,\hat a^\dagger]=1. } \tag{9.6} \]

同时：

\[ \boxed{ [\hat a,\hat a]= [\hat a^\dagger,\hat a^\dagger]=0. } \]

这是玻色产生与湮灭算符的基本对易关系。

9.3.3 哈密顿量的改写#

由定义可得：

\[ \hat x= \sqrt{\frac{\hbar}{2m\omega}} (\hat a+\hat a^\dagger), \]

\[ \hat p= -i\sqrt{\frac{m\hbar\omega}{2}} (\hat a-\hat a^\dagger). \]

代入哈密顿量：

\[ \hat H= \frac{\hat p^2}{2m} +\frac12m\omega^2\hat x^2. \]

整理得到：

\[ \hat H = \frac{\hbar\omega}{4} \left[ -(\hat a-\hat a^\dagger)^2 +(\hat a+\hat a^\dagger)^2 \right]. \]

展开：

\[ \hat H = \frac{\hbar\omega}{2} (\hat a\hat a^\dagger+\hat a^\dagger\hat a). \]

利用：

\[ \hat a\hat a^\dagger = \hat a^\dagger\hat a+1, \]

最终得到：

\[ \boxed{ \hat H= \hbar\omega \left( \hat a^\dagger\hat a+\frac12 \right). } \tag{9.7} \]

定义数算符：

\[ \boxed{ \hat n=\hat a^\dagger\hat a. } \]

因此：

\[ \boxed{ \hat H=\hbar\omega \left(\hat n+\frac12\right). } \]

这个公式是量子光学的基础之一。

它说明一个模式的能量具有离散结构：

\[ E_n=\hbar\omega\left(n+\frac12\right). \]

其中 \(n=0,1,2,\ldots\)。

9.4.1 数算符的本征态#

数算符：

\[ \hat n=\hat a^\dagger\hat a. \]

它的本征态满足：

\[ \boxed{ \hat n|n\rangle=n|n\rangle. } \tag{9.8} \]

这里的 \(|n\rangle\) 称为 Fock 态（Fock State），也叫光子数态。

它表示一个光学模式中恰好有 \(n\) 个光子。

例如：

\[ |0\rangle:\text{真空态}, \]

\[ |1\rangle:\text{单光子态}, \]

\[ |2\rangle:\text{双光子态}. \]

对应的能量分别为：

\[ E_0=\frac12\hbar\omega, \]

\[ E_1=\frac32\hbar\omega, \]

\[ E_2=\frac52\hbar\omega. \]

注意：即使没有光子，真空态的能量仍然不是零，而是：

\[ E_0=\frac12\hbar\omega. \]

这称为零点能（Zero-Point Energy）。

9.4.2 湮灭算符的作用#

湮灭算符满足：

\[ \boxed{ \hat a|n\rangle = \sqrt n\,|n-1\rangle. } \tag{9.9} \]

它使光子数减少一个。

特别地：

\[ \hat a|0\rangle=0. \]

因为真空态中没有光子可供湮灭。

9.4.3 产生算符的作用#

产生算符满足：

\[ \boxed{ \hat a^\dagger|n\rangle = \sqrt{n+1}\,|n+1\rangle. } \tag{9.10} \]

它使光子数增加一个。

例如：

\[ |1\rangle=\hat a^\dagger|0\rangle, \]

\[ |2\rangle= \frac{(\hat a^\dagger)^2}{\sqrt{2!}}|0\rangle. \]

一般地：

\[ \boxed{ |n\rangle= \frac{(\hat a^\dagger)^n}{\sqrt{n!}}|0\rangle. } \tag{9.11} \]

这就是 Fock 态的构造公式。

9.4.4 为什么有 \(\sqrt n\) 这个系数？#

我们可以从对易关系推导。

首先：

\[ \hat n=\hat a^\dagger\hat a. \]

并且：

\[ [\hat n,\hat a]=-\hat a. \]

因此：

\[ \hat n\hat a|n\rangle = (n-1)\hat a|n\rangle. \]

这说明 \(\hat a|n\rangle\) 是数算符本征值为 \(n-1\) 的态，所以它必然与 \(|n-1\rangle\) 成比例：

\[ \hat a|n\rangle=c_n|n-1\rangle. \]

利用态的归一化：

\[ \begin{aligned} |c_n|^2 &=\langle n|\hat a^\dagger\hat a|n\rangle\\ &=\langle n|\hat n|n\rangle\\ &=n. \end{aligned} \]

选择适当的相位 convention，可取：

\[ c_n=\sqrt n. \]

因此：

\[ \hat a|n\rangle=\sqrt n|n-1\rangle. \]

产生算符的关系也可以类似推导。

9.5 多模电磁场的量子化#

前面我们研究的是一个量子谐振子。现在回到电磁场。

一个实际的光学系统通常包含多个模式。例如：

  • 不同传播方向的模式；
  • 不同频率的模式；
  • 不同偏振的模式；
  • 不同波导通道中的模式。

设系统具有 \(M\) 个独立的电磁模式。每个模式都可以看作一个量子谐振子。

因此，整个电磁场的哈密顿量可以写成：

\[ \boxed{ \hat H = \sum_{m=1}^{M} \hbar\omega_m \left( \hat a_m^\dagger\hat a_m+\frac12 \right). } \tag{9.12} \]

其中：

  • \(\omega_m\)：第 \(m\) 个模式的角频率；
  • \(\hat a_m\)：第 \(m\) 个模式的湮灭算符；
  • \(\hat a_m^\dagger\)：第 \(m\) 个模式的产生算符。

不同模式之间满足：

\[ \boxed{ [\hat a_m,\hat a_n^\dagger]=\delta_{mn}, } \tag{9.13} \]

\[ [\hat a_m,\hat a_n]=0, \qquad [\hat a_m^\dagger,\hat a_n^\dagger]=0. \]

这里的 Kronecker delta 定义为：

\[ \delta_{mn}= \begin{cases} 1,&m=n,\\ 0,&m\neq n. \end{cases} \]

这意味着不同模式的产生与湮灭算符彼此对易。

9.5.1 多模 Fock 态#

单模 Fock 态写作：

\[ |n\rangle. \]

对于多个模式，我们用：

\[ \boxed{ |n_1,n_2,\ldots,n_M\rangle } \]

表示各个模式的光子数。

例如，两个模式的状态：

\[ |1,0\rangle \]

表示第一个模式中有一个光子，第二个模式中没有光子。

而：

\[ |0,1\rangle \]

表示第一个模式中没有光子，第二个模式中有一个光子。

它们是两个不同的量子态。

特别注意：

\[ |1,0\rangle\neq|0,1\rangle. \]

尽管两者都包含一个光子，但光子占据的模式不同。

9.5.2 多模 Fock 态的构造#

定义真空态：

\[ |0,0,\ldots,0\rangle. \]

那么：

\[ \boxed{ |n_1,\ldots,n_M\rangle = \prod_{m=1}^{M} \frac{(\hat a_m^\dagger)^{n_m}}{\sqrt{n_m!}} |0,\ldots,0\rangle. } \tag{9.14} \]

由于不同模式的产生算符彼此对易，因此乘积的排列顺序不影响结果。

9.5.3 为什么多模表示对集成光子计算重要？#

现在回忆我们之前使用的光学网络：

\[ \mathbf a_{\mathrm{out}} = U\mathbf a_{\mathrm{in}}. \]

这里的 \(\mathbf a\) 是经典复振幅向量。

如果我们研究量子光学，就要把它提升为算符向量：

\[ \boxed{ \hat{\mathbf a} = \begin{pmatrix} \hat a_1\\ \hat a_2\\ \vdots\\ \hat a_M \end{pmatrix}. } \]

对于一个无损线性光学网络，其模式变换可以写成：

\[ \boxed{ \hat{\mathbf a}_{\mathrm{out}} = U\hat{\mathbf a}_{\mathrm{in}}. } \tag{9.15} \]

其中 \(U\) 是酉矩阵。

这与经典光学的矩阵形式非常相似，但现在矩阵作用的对象是算符，而不是普通复数。

这是从经典集成光子计算走向量子光子计算的关键一步。

9.6 相干态：最接近经典光场的量子态#

前面我们介绍了 Fock 态：

\[ |0\rangle,\quad |1\rangle,\quad |2\rangle,\ldots \]

它们具有确定的光子数。

但实验室中的激光通常并不是确定光子数的状态。

描述理想激光场时，一个非常重要的量子态是相干态（Coherent State）。

9.6.1 相干态的定义#

相干态 \(|\alpha\rangle\) 定义为湮灭算符的本征态：

\[ \boxed{ \hat a|\alpha\rangle = \alpha|\alpha\rangle. } \tag{9.16} \]

这里 \(\alpha\) 是复数：

\[ \alpha=|\alpha|e^{i\phi}. \]

这意味着相干态具有确定的复振幅参数。

注意：相干态不是数算符的本征态，因此它通常不具有确定的光子数。

9.6.2 用 Fock 态展开相干态#

设：

\[ |\alpha\rangle = \sum_{n=0}^{\infty}c_n|n\rangle. \]

将其代入本征方程：

\[ \hat a|\alpha\rangle = \alpha|\alpha\rangle. \]

利用：

\[ \hat a|n\rangle = \sqrt n|n-1\rangle, \]

左边变成：

\[ \sum_{n=1}^{\infty} c_n\sqrt n|n-1\rangle. \]

令 \(m=n-1\)，得到：

\[ \sum_{m=0}^{\infty} c_{m+1}\sqrt{m+1}|m\rangle. \]

右边为：

\[ \alpha\sum_{m=0}^{\infty}c_m|m\rangle. \]

比较各个 Fock 态的系数：

\[ c_{m+1}\sqrt{m+1}=\alpha c_m. \]

于是：

\[ c_{m+1}=\frac{\alpha}{\sqrt{m+1}}c_m. \]

递推得到：

\[ c_n=\frac{\alpha^n}{\sqrt{n!}}c_0. \]

因此：

\[ |\alpha\rangle = c_0\sum_{n=0}^{\infty} \frac{\alpha^n}{\sqrt{n!}}|n\rangle. \]

利用归一化条件：

\[ \langle\alpha|\alpha\rangle=1, \]

可得：

\[ |c_0|^2e^{|\alpha|^2}=1. \]

选择 \(c_0\) 为正实数：

\[ c_0=e^{-|\alpha|^2/2}. \]

最终得到：

\[ \boxed{ |\alpha\rangle = e^{-|\alpha|^2/2} \sum_{n=0}^{\infty} \frac{\alpha^n}{\sqrt{n!}}|n\rangle. } \tag{9.17} \]

这就是相干态的 Fock 态展开。

9.6.3 相干态的光子数分布#

测量光子数时，得到 \(n\) 个光子的概率为：

\[ P(n)=|\langle n|\alpha\rangle|^2. \]

因此：

\[ \boxed{ P(n) = e^{-|\alpha|^2} \frac{|\alpha|^{2n}}{n!}. } \tag{9.18} \]

这是泊松分布（Poisson Distribution）。

其平均光子数为：

\[ \boxed{ \langle\hat n\rangle=|\alpha|^2. } \tag{9.19} \]

光子数方差为：

\[ \boxed{ (\Delta n)^2=|\alpha|^2. } \tag{9.20} \]

所以：

\[ \Delta n=\sqrt{\langle\hat n\rangle}. \]

当平均光子数很大时，相对涨落：

\[ \frac{\Delta n}{\langle\hat n\rangle} = \frac{1}{\sqrt{\langle\hat n\rangle}} \]

会变得很小。

这解释了为什么强激光场在许多实验中可以近似用经典电磁场描述。

9.6.4 相干态与经典光场的关系#

经典单色光场可以用复振幅表示：

\[ A=|A|e^{i\phi}. \]

相干态也具有复振幅参数：

\[ \alpha=|\alpha|e^{i\phi}. \]

它们之间存在对应关系：

  • \(|\alpha|\) 与模式的平均光子数有关；
  • \(\arg\alpha\) 与场的相位有关；
  • 相干态的平均电场表现出经典振荡形式。

不过，两者并不完全相同。

经典光场具有确定的场振幅；相干态则具有量子涨落。它是量子理论中最接近经典振荡场的一类状态。

9.8 电场算符与场的量子涨落#

现在我们已经有了产生算符和湮灭算符，可以进一步写出电磁场的算符形式。

对于一个固定频率的单一模式，在适当归一化下，电场算符可以写成：

\[ \boxed{ \hat E(t) = \mathcal E_0 \left( \hat a e^{-i\omega t} + \hat a^\dagger e^{i\omega t} \right). } \tag{9.21} \]

其中 \(\mathcal E_0\) 是由模式体积、频率及电磁场归一化决定的常数。

这里有两个部分：

\[ \hat a e^{-i\omega t} \]

对应正频率部分；

\[ \hat a^\dagger e^{i\omega t} \]

对应负频率部分。

二者互为厄米共轭，因此：

\[ \hat E^\dagger(t)=\hat E(t). \]

这保证了电场算符的可观测量性质。

9.8.1 为什么电场算符包含两个算符？#

经典实电场可以写成：

\[ E(t)=Ae^{-i\omega t}+A^*e^{i\omega t}. \]

量子化以后，复振幅 \(A\) 不再只是普通复数，而是由湮灭算符和产生算符承担相应角色：

\[ A\longrightarrow\mathcal E_0\hat a, \]

\[ A^*\longrightarrow\mathcal E_0\hat a^\dagger. \]

因此得到电场算符。

这不是简单地把经典振幅替换成算符就结束了。还必须满足正确的对易关系、归一化条件和电磁场的正则量子化结构。

9.8.2 平均电场与涨落#

对于任意量子态 \(|\psi\rangle\)，电场的期望值为：

\[ \langle\hat E(t)\rangle = \langle\psi|\hat E(t)|\psi\rangle. \]

对于真空态：

\[ \langle0|\hat a|0\rangle=0, \]

\[ \langle0|\hat a^\dagger|0\rangle=0. \]

因此：

\[ \boxed{ \langle0|\hat E(t)|0\rangle=0. } \]

但这并不意味着真空态中电场算符完全没有涨落。

电场方差定义为：

\[ (\Delta E)^2 = \langle\hat E^2\rangle - \langle\hat E\rangle^2. \]

在真空态中：

\[ \begin{aligned} \langle0|\hat E^2|0\rangle &= \mathcal E_0^2 \langle0| (\hat a e^{-i\omega t} +\hat a^\dagger e^{i\omega t})^2 |0\rangle\\ &= \mathcal E_0^2 \langle0| \hat a\hat a^\dagger |0\rangle\\ &=\mathcal E_0^2. \end{aligned} \]

因此：

\[ \boxed{ (\Delta E)^2=\mathcal E_0^2. } \tag{9.22} \]

真空态的平均电场为零，但电场涨落并不为零。

这是量子场论中非常重要的概念。

9.9 正交分量与相空间表示#

为了更直观地理解量子光场，我们定义两个正交分量（Quadratures）。

令：

\[ \boxed{ \hat X=\frac{\hat a+\hat a^\dagger}{\sqrt2}, } \tag{9.23} \]

\[ \boxed{ \hat P=\frac{\hat a-\hat a^\dagger}{i\sqrt2}. } \tag{9.24} \]

它们分别对应量子谐振子的无量纲位置和动量变量。

利用：

\[ [\hat a,\hat a^\dagger]=1, \]

可以计算：

\[ \boxed{ [\hat X,\hat P]=i. } \tag{9.25} \]

于是海森堡不确定性关系给出：

\[ \boxed{ \Delta X\Delta P\geq\frac12. } \tag{9.26} \]

这意味着光场的两个正交分量不可能同时具有任意小的量子不确定性。

9.9.1 相干态在相空间中的位置#

对于相干态：

\[ \hat a|\alpha\rangle=\alpha|\alpha\rangle. \]

因此：

\[ \langle\hat X\rangle = \frac{\alpha+\alpha^*}{\sqrt2} = \sqrt2\operatorname{Re}\alpha, \]

\[ \langle\hat P\rangle = \frac{\alpha-\alpha^*}{i\sqrt2} = \sqrt2\operatorname{Im}\alpha. \]

所以复数 \(\alpha\) 可以对应相空间中的一个点：

\[ \boxed{ (X,P)= (\sqrt2\operatorname{Re}\alpha, \sqrt2\operatorname{Im}\alpha). } \]

\[ \Delta X=\Delta P=\frac1{\sqrt2}. \]

因此：

\[ \Delta X\Delta P=\frac12. \]

相干态是达到上述不确定性下界的一类量子态。

这也解释了它为什么在数学结构上与经典光场如此接近：它在相空间中具有确定的中心位置，同时保留最小量子涨落。

PART VI · 光量子信息与量子计算#

第十讲：分束器的量子理论与 Hong–Ou–Mandel 干涉#

上一讲，我们从经典电磁场出发，建立了量子光场的基本数学结构：

\[ [\hat a,\hat a^\dagger]=1, \qquad \hat n=\hat a^\dagger\hat a. \]

并且引入了 Fock 态：

\[ |n\rangle = \frac{(\hat a^\dagger)^n}{\sqrt{n!}}|0\rangle. \]

现在回到第三讲中的定向耦合器和 MZI。

经典光学中，一个无损分束器可以用酉矩阵描述：

\[ \begin{pmatrix} a_{\mathrm{out}}\\ b_{\mathrm{out}} \end{pmatrix} = U \begin{pmatrix} a_{\mathrm{in}}\\ b_{\mathrm{in}} \end{pmatrix}. \]

量子光学中，我们将复振幅替换为湮灭算符：

\[ \boxed{ \begin{pmatrix} \hat a_{\mathrm{out}}\\ \hat b_{\mathrm{out}} \end{pmatrix} = U \begin{pmatrix} \hat a_{\mathrm{in}}\\ \hat b_{\mathrm{in}} \end{pmatrix}. } \]

这看起来只是一个形式替换，但它会产生非常不同的物理结果。

本讲要理解的核心现象是：

两个完全相同的单光子，同时进入一个 50:50 分束器时，它们会倾向于从同一个输出端离开。

这就是 Hong–Ou–Mandel 干涉，简称 HOM 干涉。

10.1 两个光学模式与 Fock 态#

考虑两个输入模式，分别记为 \(a\) 和 \(b\)。

对应的湮灭算符为：

\[ \hat a,\qquad\hat b, \]

产生算符为：

\[ \hat a^\dagger,\qquad\hat b^\dagger. \]

它们满足：

\[ [\hat a,\hat a^\dagger]=1, \qquad [\hat b,\hat b^\dagger]=1. \]

不同模式之间满足：

\[ [\hat a,\hat b^\dagger]=0, \qquad [\hat a,\hat b]=0. \]

两个模式的真空态记为：

\[ |0,0\rangle. \]

其中第一个位置表示模式 \(a\) 的光子数，第二个位置表示模式 \(b\) 的光子数。

例如：

\[ |1,0\rangle \]

表示模式 \(a\) 中有一个光子，模式 \(b\) 中没有光子。

而：

\[ |0,1\rangle \]

表示模式 \(a\) 中没有光子，模式 \(b\) 中有一个光子。

它们可以通过产生算符构造：

\[ \boxed{ |1,0\rangle=\hat a^\dagger|0,0\rangle, } \]

\[ \boxed{ |0,1\rangle=\hat b^\dagger|0,0\rangle. } \]

如果两个模式中各有一个光子：

\[ \boxed{ |1,1\rangle = \hat a^\dagger\hat b^\dagger|0,0\rangle. } \]

注意，这里的乘积没有额外归一化因子，因为两个模式各自的光子数都是 1：

\[ \frac{(\hat a^\dagger)^1}{\sqrt{1!}} \frac{(\hat b^\dagger)^1}{\sqrt{1!}} |0,0\rangle. \]

10.2 分束器的经典矩阵#

先回顾一个无损、对称的 50:50 分束器。

我们采用如下相位约定：

\[ \boxed{ U_{\mathrm{BS}} = \frac1{\sqrt2} \begin{pmatrix} 1&i\\ i&1 \end{pmatrix}. } \tag{10.1} \]

于是经典复振幅满足：

\[ \begin{pmatrix} a_{\mathrm{out}}\\ b_{\mathrm{out}} \end{pmatrix} = \frac1{\sqrt2} \begin{pmatrix} 1&i\\ i&1 \end{pmatrix} \begin{pmatrix} a_{\mathrm{in}}\\ b_{\mathrm{in}} \end{pmatrix}. \]

也就是：

\[ a_{\mathrm{out}} = \frac{a_{\mathrm{in}}+ib_{\mathrm{in}}}{\sqrt2}, \]

\[ b_{\mathrm{out}} = \frac{ia_{\mathrm{in}}+b_{\mathrm{in}}}{\sqrt2}. \]

这个矩阵是酉矩阵：

\[ U_{\mathrm{BS}}^\dagger U_{\mathrm{BS}}=I. \]

因此它保持总光功率。

10.2.1 量子算符变换#

在量子理论中，对应的变换为：

\[ \boxed{ \hat a_{\mathrm{out}} = \frac{\hat a_{\mathrm{in}}+i\hat b_{\mathrm{in}}}{\sqrt2}, } \tag{10.2} \]

\[ \boxed{ \hat b_{\mathrm{out}} = \frac{i\hat a_{\mathrm{in}}+\hat b_{\mathrm{in}}}{\sqrt2}. } \tag{10.3} \]

这两个式子是 HOM 干涉推导的起点。

但是，接下来我们要注意一个容易混淆的问题：

我们有时需要从输入态求输出态，而有时需要把输出产生算符表示成输入产生算符的组合。

这两种写法涉及变换方向，不能随意混用。

10.3 产生算符如何变换？#

我们已知湮灭算符的变换：

\[ \hat{\mathbf a}_{\mathrm{out}} = U\hat{\mathbf a}_{\mathrm{in}}. \]

对两边取厄米共轭：

\[ \hat{\mathbf a}_{\mathrm{out}}^\dagger = \hat{\mathbf a}_{\mathrm{in}}^\dagger U^\dagger. \]

因此：

\[ \hat{\mathbf a}_{\mathrm{in}}^\dagger = \hat{\mathbf a}_{\mathrm{out}}^\dagger U. \]

对称 50:50 分束器的矩阵满足：

\[ U^T=U. \]

所以产生算符也具有相同形式的系数：

\[ \boxed{ \hat a_{\mathrm{in}}^\dagger = \frac{\hat a_{\mathrm{out}}^\dagger +i\hat b_{\mathrm{out}}^\dagger}{\sqrt2}, } \tag{10.4} \]

\[ \boxed{ \hat b_{\mathrm{in}}^\dagger = \frac{i\hat a_{\mathrm{out}}^\dagger +\hat b_{\mathrm{out}}^\dagger}{\sqrt2}. } \tag{10.5} \]

我们将用这两个公式直接计算输入态经过分束器后的输出态。

这里把输入、输出模式写成不同的符号，是为了避免把同一个算符在不同时间或不同位置的定义混在一起。

10.4 单光子经过 50:50 分束器#

先考虑最简单的输入：

\[ |\psi_{\mathrm{in}}\rangle=|1,0\rangle_{\mathrm{in}}. \]

也就是说，输入端口 \(a\) 有一个光子，端口 \(b\) 是真空。

根据：

\[ |1,0\rangle_{\mathrm{in}} = \hat a_{\mathrm{in}}^\dagger|0,0\rangle, \]

以及式 (10.4)：

\[ \hat a_{\mathrm{in}}^\dagger = \frac{\hat a_{\mathrm{out}}^\dagger +i\hat b_{\mathrm{out}}^\dagger}{\sqrt2}, \]

得到：

\[ \begin{aligned} |\psi_{\mathrm{out}}\rangle &= \frac{\hat a_{\mathrm{out}}^\dagger +i\hat b_{\mathrm{out}}^\dagger}{\sqrt2} |0,0\rangle\\ &= \frac1{\sqrt2} \left( |1,0\rangle_{\mathrm{out}} +i|0,1\rangle_{\mathrm{out}} \right). \end{aligned} \]

因此：

\[ \boxed{ |1,0\rangle_{\mathrm{in}} \longrightarrow \frac{|1,0\rangle_{\mathrm{out}} +i|0,1\rangle_{\mathrm{out}}}{\sqrt2}. } \tag{10.6} \]

这意味着单光子经过 50:50 分束器后，输出态是两个模式的量子叠加。

如果在输出端进行光子数测量：

\[ P(1,0)=\frac12, \qquad P(0,1)=\frac12. \]

但要注意：

\[ \frac{|1,0\rangle+i|0,1\rangle}{\sqrt2} \]

不是说光子被经典地切成了两半，而是说测量结果具有两个可能性，量子态包含两个输出模式的相干叠加。

单光子干涉的关键在于：即使输入端只有一个光子，两个输出路径仍然可以处于量子叠加状态。

10.5 两个光子同时输入分束器#

现在进入 HOM 干涉的核心。

考虑两个输入端口各有一个光子：

\[ \boxed{ |\psi_{\mathrm{in}}\rangle=|1,1\rangle_{\mathrm{in}}. } \]

根据 Fock 态的定义：

\[ |1,1\rangle_{\mathrm{in}} = \hat a_{\mathrm{in}}^\dagger \hat b_{\mathrm{in}}^\dagger |0,0\rangle. \]

我们已经知道：

\[ \hat a_{\mathrm{in}}^\dagger = \frac{\hat a_{\mathrm{out}}^\dagger +i\hat b_{\mathrm{out}}^\dagger}{\sqrt2}, \]

\[ \hat b_{\mathrm{in}}^\dagger = \frac{i\hat a_{\mathrm{out}}^\dagger +\hat b_{\mathrm{out}}^\dagger}{\sqrt2}. \]

代入：

\[ \begin{aligned} |\psi_{\mathrm{out}}\rangle ={}& \frac12 (\hat a^\dagger+i\hat b^\dagger) (i\hat a^\dagger+\hat b^\dagger) |0,0\rangle. \end{aligned} \]

为简洁起见，以下省略算符的 out 下标。

展开：

\[ \begin{aligned} |\psi_{\mathrm{out}}\rangle =\frac12\Big[ &i(\hat a^\dagger)^2 +\hat a^\dagger\hat b^\dagger\\ &-\hat b^\dagger\hat a^\dagger +i(\hat b^\dagger)^2 \Big]|0,0\rangle. \end{aligned} \]

现在用到一个非常关键的性质：

\[ \boxed{ [\hat a^\dagger,\hat b^\dagger]=0. } \]

因此：

\[ \hat a^\dagger\hat b^\dagger = \hat b^\dagger\hat a^\dagger. \]

中间两项恰好抵消：

\[ \hat a^\dagger\hat b^\dagger - \hat b^\dagger\hat a^\dagger=0. \]

于是：

\[ |\psi_{\mathrm{out}}\rangle = \frac{i}{2} \left[ (\hat a^\dagger)^2+ (\hat b^\dagger)^2 \right]|0,0\rangle. \]

利用归一化关系：

\[ |2,0\rangle = \frac{(\hat a^\dagger)^2}{\sqrt{2!}}|0,0\rangle, \]

\[ |0,2\rangle = \frac{(\hat b^\dagger)^2}{\sqrt{2!}}|0,0\rangle, \]

最终得到：

\[ \boxed{ |\psi_{\mathrm{out}}\rangle = \frac{i}{\sqrt2} \left( |2,0\rangle_{\mathrm{out}} + |0,2\rangle_{\mathrm{out}} \right). } \tag{10.7} \]

整体相位 \(i\) 不影响测量概率，因此也可以写成：

\[ \boxed{ |\psi_{\mathrm{out}}\rangle \sim \frac{|2,0\rangle+|0,2\rangle}{\sqrt2}. } \tag{10.8} \]

核心结果

两个光子同时从两个输入端口进入理想 50:50 分束器，输出态中没有一个光子分别出现在两个输出端口的项。

换句话说：

\[ P(1,1)_{\mathrm{out}}=0. \]

两个光子要么同时从端口 \(a\) 出来，要么同时从端口 \(b\) 出来：

\[ P(2,0)=P(0,2)=\frac12. \]

这就是 HOM 干涉的理想结果。

10.6 为什么中间两项会抵消？#

这是整讲最值得理解的地方。

我们从输入态：

\[ |1,1\rangle_{\mathrm{in}} \]

出发，展开后，原本存在四个代数项：

\[ \begin{aligned} & i(\hat a^\dagger)^2,\\ & \hat a^\dagger\hat b^\dagger,\\ & -\hat b^\dagger\hat a^\dagger,\\ & i(\hat b^\dagger)^2. \end{aligned} \]

其中：

  • 第一项对应两个光子从端口 \(a\) 输出；
  • 最后一项对应两个光子从端口 \(b\) 输出；
  • 中间两项对应两个光子分别从两个端口输出。

中间两项具有相同的产生算符结构，却带有相反的振幅：

\[ \hat a^\dagger\hat b^\dagger - \hat b^\dagger\hat a^\dagger=0. \]

所以它们发生了完全相消的量子干涉。

这不是两个光子之间存在某种经典意义上的排斥力，也不是光子在分束器中互相碰撞后改变方向。

它来自：

  1. 光子是玻色子；
  2. 不同模式的产生算符彼此对易；
  3. 分束器的透射与反射振幅具有特定相位关系；
  4. 不同概率振幅发生相干叠加。

HOM 干涉是概率振幅的干涉，而不是经典概率的简单相加。

典型 HOM 实验的结构如下：

  1. 准备两个单光子输入；
  2. 让它们分别进入一个 50:50 分束器；
  3. 在两个输出端分别放置单光子探测器；
  4. 记录两个探测器的符合计数。

所谓符合计数（Coincidence Count），就是在一个很短的时间窗口内，两个探测器都记录到光子的事件数。

如果两个光子完全不可区分，并且同时到达分束器，那么：

\[ P_{\mathrm{coin}}=0. \]

也就是理想情况下不会出现两个输出端各探测到一个光子的事件。

10.7.1 为什么需要不可区分性？#

现在考虑两个光子不完全相同的情况。

例如：

  • 它们的到达时间不同；
  • 它们的频率不同；
  • 它们的偏振不同；
  • 它们的空间模式不同。

这时，两个光子携带了可以区分它们的信息。

原来发生相消的两条概率振幅不再完全重合，因此符合计数不再为零。

这就使得 HOM 干涉成为检验光子不可区分性的实验工具。

10.8 时间延迟与 HOM Dip#

实验中，我们通常通过改变其中一个光子的传播路径长度，控制两个光子的到达时间差。

设两个光子的时间延迟为 \(\tau\)。

当：

\[ \tau=0 \]

时，两个光子同时到达分束器。

当：

\[ |\tau|\gg\tau_c \]

时，两个光子到达时间相差较大，\(\tau_c\) 是光子的相干时间尺度。

10.8.1 部分可区分的光子#

假设两个光子的内部态分别为：

\[ |\xi\rangle,\qquad|\eta\rangle. \]

这里的内部自由度可以包含频谱、偏振、时间波包等信息。

定义它们的态重叠：

\[ \boxed{ \mu=\langle\xi|\eta\rangle. } \]

由于态已归一化：

\[ 0\leq|\mu|^2\leq1. \]

  • \(|\mu|^2=1\)：两个内部态完全相同；
  • \(|\mu|^2=0\)：两个内部态正交，完全可区分；
  • \(0<|\mu|^2<1\)：部分不可区分。

对于理想 50:50 分束器、纯单光子输入以及只考虑这类内部态差异的情形，可以得到符合概率：

\[ \boxed{ P_{\mathrm{coin}} = \frac12(1-|\mu|^2). } \tag{10.9} \]

这个公式很重要。

当两个光子完全不可区分时：

\[ |\mu|^2=1, \]

所以：

\[ P_{\mathrm{coin}}=0. \]

当两个光子完全可区分时：

\[ |\mu|^2=0, \]

所以：

\[ P_{\mathrm{coin}}=\frac12. \]

因此，光子的不可区分程度直接决定 HOM 干涉的可见度。

10.8.2 HOM Dip 的形成#

当我们逐渐改变两个光子的时间延迟，符合概率会发生变化。

典型曲线呈现一个谷形结构：

  • 延迟很大时，两个光子基本可区分，符合概率趋近 \(1/2\)；

  • 两个光子完全重合时，符合概率达到最小值。

这个符合计数曲线中的凹陷称为：

\[ \boxed{\text{HOM Dip}.} \]

它是量子光学实验中非常经典的特征。

实际 HOM Dip 的宽度和形状取决于光子的频谱、时间波包、滤波器以及实验装置的色散等因素，不能仅凭一个通用公式确定。

10.9 HOM 干涉与玻色子交换对称性#

现在从更抽象的角度理解 HOM 干涉。

10.9.1 什么是玻色子？#

量子粒子可以按照交换两个相同粒子时波函数的变化分为两类：

玻色子（Bosons）：

交换两个相同粒子，波函数保持不变：

\[ \boxed{ \Psi(1,2)=\Psi(2,1). } \]

费米子（Fermions）：

交换两个相同粒子，波函数改变符号：

\[ \boxed{ \Psi(1,2)=-\Psi(2,1). } \]

光子属于玻色子。

因此，两个相同光子的联合量子态必须满足玻色交换对称性。

10.9.2 对称性如何体现在 Fock 空间中？#

回顾两个模式的双光子态：

\[ |1,1\rangle = \hat a^\dagger\hat b^\dagger|0,0\rangle. \]

由于：

\[ [\hat a^\dagger,\hat b^\dagger]=0, \]

所以：

\[ \hat a^\dagger\hat b^\dagger = \hat b^\dagger\hat a^\dagger. \]

这正是玻色子交换对称性在产生算符代数中的体现。

对于费米子，相应的产生算符满足反对易关系：

\[ \{\hat c_i^\dagger,\hat c_j^\dagger\}=0, \]

其中：

\[ \{A,B\}=AB+BA. \]

因此：

\[ \hat c_i^\dagger\hat c_j^\dagger = -\hat c_j^\dagger\hat c_i^\dagger. \]

两种粒子的交换性质不同，导致它们在相同线性光学结构中的干涉规律也不同。

10.9.3 HOM 干涉不是光子之间的直接作用力#

这一点值得特别强调。

在理想 HOM 实验中，两个光子可以在一个线性、无损的分束器中独立传播。

它们不需要发生直接的相互作用。

产生 HOM 干涉的根本原因是：

\[ \boxed{ \text{玻色交换对称性} + \text{概率振幅相干叠加}. } \]

这也是为什么 HOM 干涉在光量子信息中如此重要：它提供了一种利用线性光学器件实现多光子量子干涉的方法。

10.10 HOM 干涉有什么用？#

HOM 干涉并不是一个孤立的实验现象，它在量子信息中具有重要用途。

1. 测量光子不可区分性#

通过测量 HOM Dip 的深度，可以评估两个光子的模式重叠程度。

如果符合概率能够降到接近零，说明两个光子具有很高的不可区分性。

2. 光子干涉与量子信息处理#

量子光学计算通常需要让多个光子通过分束器、相移器和其他线性光学器件。

HOM 干涉是理解多光子干涉的基本例子。

3. 光子量子门#

单纯的无损线性光学器件不会直接提供任意强度的光子间相互作用。

但借助辅助光子、测量和条件操作，可以构造某些概率性的光子量子逻辑门。

这类方案是线性光学量子计算的重要组成部分。

4. 玻色采样#

玻色采样（Boson Sampling）研究大量不可区分的玻色子通过线性光学网络后的输出概率分布。

HOM 干涉是理解这类多光子干涉的最简单起点。

下一讲我们将把两个光子的例子推广到多个光子和多个模式。

10.11 从 HOM 干涉到矩阵永久式#

这里先介绍一个重要的数学预告。

经典线性光学网络满足：

\[ \mathbf a_{\mathrm{out}}=U\mathbf a_{\mathrm{in}}. \]

量子线性光学网络则满足：

\[ \hat{\mathbf a}_{\mathrm{out}} = U\hat{\mathbf a}_{\mathrm{in}}. \]

对于单光子输入，输出概率主要由矩阵元素的模平方决定。

但对于多个不可区分光子，多个不同的传播路径会发生相干叠加。

例如，两个光子从两个输入模式到两个输出模式时，某个输出振幅会包含两种可能的路径组合：

\[ U_{11}U_{22}+U_{12}U_{21}. \]

注意这里是加法，而不是概率相加。

对于一般的 \(N\) 光子、多模式线性光学网络，这种求和会推广为矩阵的永久式（Permanent）：

\[ \boxed{ \operatorname{Per}(A) = \sum_{\sigma\in S_N} \prod_{i=1}^{N}A_{i,\sigma(i)}. } \tag{10.10} \]

其中：

  • \(A\) 是一个 \(N\times N\) 矩阵；
  • \(S_N\) 是 \(N\) 个元素的所有排列组成的集合；
  • \(\sigma\) 表示一种排列。

与行列式不同，永久式没有排列符号：

\[ \det(A) = \sum_{\sigma\in S_N} \operatorname{sgn}(\sigma) \prod_{i=1}^{N}A_{i,\sigma(i)}. \]

永久式与行列式的区别是：

\[ \boxed{ \text{行列式有排列符号，永久式没有。} } \]

这是玻色子与费米子多粒子干涉的一个重要数学分野。

不过，完整的多光子输出振幅还需要考虑输入、输出模式的光子占据数以及相应的归一化因子。我们将在下一讲系统推导，不能把任意输入输出情形都直接写成一个未经修正的永久式。

PART VI · 光量子信息与量子计算#

第十一讲：玻色采样与多光子干涉——从 HOM 到永久式#

上一讲，我们研究了两个不可区分光子通过 50:50 分束器的情形：

\[ |1,1\rangle \longrightarrow \frac{i}{\sqrt2}(|2,0\rangle+|0,2\rangle). \]

HOM 干涉揭示了一个重要事实：多个光子的输出概率振幅，取决于不同传播路径的相干叠加。

现在把问题推广：

  • 不再只有两个输入模式，而是 \(M\) 个模式；
  • 不再只有两个光子，而是 \(N\) 个光子；
  • 不再只有一个分束器，而是任意由分束器和相移器组成的线性光学网络。

我们将得到一个非常漂亮的数学结果：

\[ \boxed{ \text{多光子干涉振幅} \quad\longleftrightarrow\quad \text{矩阵永久式}. } \]

这就是玻色采样（Boson Sampling）的数学基础。

11.1 多模线性光学网络#

考虑一个包含 \(M\) 个光学模式的无损线性光学网络。

将输入模式的湮灭算符写成列向量：

\[ \hat{\mathbf a}_{\mathrm{in}} = \begin{pmatrix} \hat a_1\\ \hat a_2\\ \vdots\\ \hat a_M \end{pmatrix}. \]

输出模式的湮灭算符为：

\[ \hat{\mathbf a}_{\mathrm{out}} = \begin{pmatrix} \hat b_1\\ \hat b_2\\ \vdots\\ \hat b_M \end{pmatrix}. \]

线性光学网络由一个酉矩阵 \(U\in U(M)\) 描述：

\[ \boxed{ \hat{\mathbf b}=U\hat{\mathbf a}. } \tag{11.1} \]

这里为了简化记号，省略了 in、out 下标。

矩阵元素满足：

\[ b_j=\sum_{k=1}^{M}U_{jk}a_k. \]

其物理意义是：输入模式 \(k\) 对输出模式 \(j\) 的贡献由 \(U_{jk}\) 决定。

由于网络无损：

\[ \boxed{U^\dagger U=I_M.} \tag{11.2} \]

11.1.1 产生算符的变换#

对式 (11.1) 取厄米共轭：

\[ \hat{\mathbf b}^{\dagger} = \hat{\mathbf a}^{\dagger}U^\dagger. \]

因此：

\[ \boxed{ \hat{\mathbf a}^{\dagger} = \hat{\mathbf b}^{\dagger}U. } \tag{11.3} \]

逐分量写出：

\[ \boxed{ \hat a_k^\dagger = \sum_{j=1}^{M}U_{jk}\hat b_j^\dagger. } \tag{11.4} \]

这表示：输入模式 \(k\) 的一个光子，在输出端可以分布到所有模式，其概率振幅由矩阵第 \(k\) 列决定。

注意，这里的矩阵指标非常重要：

\[ \hat a_k^\dagger = \sum_j U_{jk}\hat b_j^\dagger. \]

输入模式对应列指标，输出模式对应行指标。

后续推导永久式时，我们会严格保留这个约定。

11.2 多光子输入态与输出态#

11.2.1 输入态的占据数表示#

对于 \(M\) 个模式，我们用：

\[ |s_1,s_2,\ldots,s_M\rangle \]

表示输入态，其中 \(s_k\) 是第 \(k\) 个模式中的光子数。

记：

\[ \mathbf s=(s_1,\ldots,s_M). \]

总光子数为：

\[ N=\sum_{k=1}^{M}s_k. \]

根据上一讲的 Fock 态构造公式：

\[ \boxed{ |\mathbf s\rangle = \prod_{k=1}^{M} \frac{(\hat a_k^\dagger)^{s_k}}{\sqrt{s_k!}} |0,\ldots,0\rangle. } \tag{11.5} \]

例如，三个模式、两个光子的输入态：

\[ |1,0,1\rangle = \hat a_1^\dagger\hat a_3^\dagger|0,0,0\rangle. \]

而：

\[ |2,0,0\rangle = \frac{(\hat a_1^\dagger)^2}{\sqrt{2!}} |0,0,0\rangle. \]

注意归一化因子：

\[ \frac1{\sqrt{2!}}. \]

它来自同一模式中两个相同玻色子的 Fock 态归一化。

11.2.2 输出态的占据数表示#

类似地，定义输出占据数：

\[ \mathbf t=(t_1,\ldots,t_M), \]

满足：

\[ \sum_{j=1}^{M}t_j=N. \]

对应的输出 Fock 态为：

\[ \boxed{ |\mathbf t\rangle = \prod_{j=1}^{M} \frac{(\hat b_j^\dagger)^{t_j}}{\sqrt{t_j!}} |0,\ldots,0\rangle. } \tag{11.6} \]

我们的目标是计算：

\[ \boxed{ A(\mathbf t|\mathbf s) = \langle\mathbf t|\hat U|\mathbf s\rangle. } \tag{11.7} \]

这里 \(\hat U\) 是光学网络在量子态空间中的酉演化算符。

它表示：给定输入占据数 \(\mathbf s\)，得到输出占据数 \(\mathbf t\) 的概率振幅。

最终的测量概率为：

\[ \boxed{ P(\mathbf t|\mathbf s) = |A(\mathbf t|\mathbf s)|^2. } \tag{11.8} \]

11.3 从算符变换推导多光子输出振幅#

这是本讲最重要的数学推导。

输入态为：

\[ |\mathbf s\rangle = \prod_{k=1}^{M} \frac{(\hat a_k^\dagger)^{s_k}}{\sqrt{s_k!}} |0\rangle. \]

利用产生算符变换：

\[ \hat a_k^\dagger = \sum_{j=1}^{M}U_{jk}\hat b_j^\dagger, \]

得到：

\[ |\psi_{\mathrm{out}}\rangle = \prod_{k=1}^{M} \frac{ \left(\sum_{j=1}^{M}U_{jk}\hat b_j^\dagger\right)^{s_k} }{ \sqrt{s_k!} } |0\rangle. \tag{11.9} \]

现在我们要从这个展开式中，提取输出态：

\[ |\mathbf t\rangle = \prod_{j=1}^{M} \frac{(\hat b_j^\dagger)^{t_j}}{\sqrt{t_j!}}|0\rangle \]

对应的系数。

11.3.1 为什么会出现排列求和？#

先考虑最简单的情形：

\[ N=2,\qquad s_1=s_2=1. \]

输入态为：

\[ |\mathbf s\rangle = \hat a_1^\dagger\hat a_2^\dagger|0\rangle. \]

经过网络：

\[ \begin{aligned} |\psi_{\mathrm{out}}\rangle ={}& \left(\sum_{j=1}^{M}U_{j1}\hat b_j^\dagger\right)\\ &\cdot \left(\sum_{\ell=1}^{M}U_{\ell2}\hat b_\ell^\dagger\right) |0\rangle. \end{aligned} \]

展开：

\[ |\psi_{\mathrm{out}}\rangle = \sum_{j,\ell} U_{j1}U_{\ell2} \hat b_j^\dagger\hat b_\ell^\dagger|0\rangle. \]

现在假设我们关心两个不同输出模式 \(p,q\)，即：

\[ \mathbf t=(0,\ldots,1_p,\ldots,1_q,\ldots,0). \]

产生这个输出态的路径有两种：

  1. 输入模式 1 的光子到达 \(p\)，输入模式 2 的光子到达 \(q\)；
  2. 输入模式 1 的光子到达 \(q\)，输入模式 2 的光子到达 \(p\)。

对应的振幅分别是：

\[ U_{p1}U_{q2}, \]

\[ U_{q1}U_{p2}. \]

由于两个光子不可区分，无法通过输出测量区分这两种路径。

所以总振幅是：

\[ \boxed{ A=U_{p1}U_{q2}+U_{q1}U_{p2}. } \tag{11.10} \]

这就是一个 \(2\times2\) 矩阵的永久式：

\[ A= \operatorname{Per} \begin{pmatrix} U_{p1}&U_{p2}\\ U_{q1}&U_{q2} \end{pmatrix}. \]

注意：这里必须先把振幅相加，再取模平方：

\[ P=|A|^2. \]

不能先分别计算两条路径的概率再相加，否则就丢失了干涉项。

11.3.2 推广到 \(N\) 个光子#

现在推广到一般情况。

先考虑无碰撞输入和输出：

\[ s_k,t_j\in\{0,1\}. \]

也就是说，每个占据模式恰好有一个光子或没有光子。

将输入占据模式写成：

\[ S=(s_1’,\ldots,s_N’), \]

将输出占据模式写成：

\[ T=(t_1’,\ldots,t_N’). \]

这里 \(s_r’\) 表示第 \(r\) 个被占据的输入模式编号，\(t_r’\) 表示第 \(r\) 个被占据的输出模式编号。

从输入到输出，每个光子都必须分配到一个输出模式。

对于给定的输出集合，所有可能的光子分配方式由排列：

\[ \sigma\in S_N \]

描述。

某个排列对应的振幅为：

\[ \prod_{r=1}^{N} U_{t_r’,s_{\sigma(r)}’}. \]

由于光子是不可区分的玻色子，所有排列对应的振幅相干相加：

\[ \boxed{ A(T|S) = \sum_{\sigma\in S_N} \prod_{r=1}^{N} U_{t_r’,s_{\sigma(r)}’}. } \tag{11.11} \]

这恰好就是子矩阵：

\[ U_{T,S} \]

的永久式：

\[ \boxed{ A(T|S)=\operatorname{Per}(U_{T,S}). } \tag{11.12} \]

其中 \(U_{T,S}\) 是从 \(U\) 中选取对应输出行和输入列得到的 \(N\times N\) 子矩阵。

因此：

\[ \boxed{ P(T|S)=|\operatorname{Per}(U_{T,S})|^2. } \tag{11.13} \]

这就是无碰撞情形下，多光子线性光学网络的输出概率公式。

11.4 一般情形：允许多个光子占据同一模式#

刚才的永久式公式假设输入和输出都没有两个光子占据同一个模式。

但真实的多光子干涉中，完全可能出现：

\[ |2,0,1,0,\ldots\rangle \]

这样的占据态。

因此，我们需要更一般的公式。

11.4.1 重复行与重复列#

给定输入占据数：

\[ \mathbf s=(s_1,\ldots,s_M), \]

输出占据数：

\[ \mathbf t=(t_1,\ldots,t_M). \]

总光子数满足：

\[ \sum_k s_k=\sum_j t_j=N. \]

构造一个 \(N\times N\) 矩阵 \(U_{\mathbf t,\mathbf s}\)：

  • 第 \(j\) 行重复 \(t_j\) 次；
  • 第 \(k\) 列重复 \(s_k\) 次。

换句话说，如果输出模式 2 有两个光子，那么矩阵中对应输出模式 2 的那一行就重复两次；如果输入模式 1 有两个光子，对应输入模式 1 的列就重复两次。

这样仍然得到一个 \(N\times N\) 矩阵。

11.4.2 一般的输出振幅公式#

此时，输出振幅为：

\[ \boxed{ A(\mathbf t|\mathbf s) = \frac{ \operatorname{Per}(U_{\mathbf t,\mathbf s}) }{ \sqrt{ \prod_{j=1}^{M}t_j! \prod_{k=1}^{M}s_k! } }. } \tag{11.14} \]

所以输出概率为：

\[ \boxed{ P(\mathbf t|\mathbf s) = \frac{ |\operatorname{Per}(U_{\mathbf t,\mathbf s})|^2 }{ \prod_jt_j!\prod_ks_k! }. } \tag{11.15} \]

这就是一般多光子线性光学网络的核心公式。

分母中的阶乘来自 Fock 态的归一化。

11.4.3 用 HOM 干涉验证公式#

考虑两个模式的 50:50 分束器：

\[ U= \frac1{\sqrt2} \begin{pmatrix} 1&i\\ i&1 \end{pmatrix}. \]

输入态为：

\[ \mathbf s=(1,1). \]

考虑输出态：

\[ \mathbf t=(2,0). \]

对应子矩阵需要把第一行重复两次：

\[ U_{\mathbf t,\mathbf s} = \frac1{\sqrt2} \begin{pmatrix} 1&i\\ 1&i \end{pmatrix}. \]

计算永久式：

\[ \begin{aligned} \operatorname{Per}(U_{\mathbf t,\mathbf s}) &= \frac1{\sqrt2}\frac{i}{\sqrt2} + \frac{i}{\sqrt2}\frac1{\sqrt2}\\ &=i. \end{aligned} \]

根据公式：

\[ A((2,0)|(1,1)) = \frac{i}{\sqrt{2!}} = \frac{i}{\sqrt2}. \]

因此：

\[ P(2,0)=\frac12. \]

同理：

\[ P(0,2)=\frac12. \]

而：

\[ P(1,1)=0. \]

这与上一讲直接使用产生算符得到的 HOM 结果完全一致。

推导闭合

这说明 HOM 干涉实际上是永久式描述多光子干涉的最简单非平凡例子。

11.5 永久式与行列式：为什么玻色子和费米子不同？#

上一讲我们已经介绍了：

\[ \operatorname{Per}(A) = \sum_{\sigma\in S_N} \prod_{i=1}^{N}A_{i,\sigma(i)} \]

以及：

\[ \det(A) = \sum_{\sigma\in S_N} \operatorname{sgn}(\sigma) \prod_{i=1}^{N}A_{i,\sigma(i)}. \]

两者形式非常相似，区别在于行列式包含排列符号：

\[ \operatorname{sgn}(\sigma)= \begin{cases} +1,&\sigma\text{ 为偶排列},\\ -1,&\sigma\text{ 为奇排列}. \end{cases} \]

永久式没有这个符号。

11.5.1 两个粒子的例子#

设：

\[ A= \begin{pmatrix} a&b\\ c&d \end{pmatrix}. \]

永久式为：

\[ \boxed{\operatorname{Per}(A)=ad+bc.} \]

行列式为：

\[ \boxed{\det(A)=ad-bc.} \]

对于两个玻色子，不同路径的振幅以相同的排列符号相加。

对于两个费米子，交换粒子会引入负号，因此不同路径的振幅按照反对称结构相加。

这也是两类粒子在多粒子干涉中呈现不同统计行为的原因。

需要注意：这里讨论的是理想的不可区分粒子及其相应的线性单粒子模式变换。永久式和行列式分别是玻色、费米多粒子振幅结构的核心数学对象。

现在我们终于可以介绍玻色采样。

**玻色采样（Boson Sampling）**是一类利用不可区分玻色子通过线性光学网络产生复杂输出概率分布的计算模型。

它的基本结构是：

\[ \boxed{ \text{单光子输入} \longrightarrow \text{多模线性光学网络} \longrightarrow \text{光子数测量}. } \]

11.6.1 典型实验模型#

假设有：

  • \(M\) 个光学模式；
  • \(N\) 个单光子输入；
  • 一个 \(M\times M\) 的随机酉矩阵 \(U\)；
  • 输出端的光子数探测器。

通常选择：

\[ M\gg N. \]

这意味着光子数远小于模式数。

例如：

\[ N=3,\qquad M=8. \]

可以选择输入态：

\[ |\psi_{\mathrm{in}}\rangle = |1,1,1,0,0,0,0,0\rangle. \]

三个光子分别从前三个输入模式进入网络。

经过网络后，可能得到：

\[ |0,1,0,1,0,0,1,0\rangle, \]

也可能得到：

\[ |0,0,2,0,0,1,0,0\rangle. \]

这些不同输出态构成一个概率分布。

我们的任务不是简单计算某个矩阵乘法结果，而是从这个多光子输出分布中抽取样本。

11.6.2 无碰撞输出#

在 \(M\gg N\) 的条件下，我们尤其关注无碰撞输出：

\[ t_j\in\{0,1\}. \]

也就是说，每个输出模式最多只有一个光子。

此时，对于一个固定的输入模式集合 \(S\) 和输出模式集合 \(T\)，概率为：

\[ \boxed{ P(T|S)=|\operatorname{Per}(U_{T,S})|^2. } \tag{11.16} \]

例如，三个光子从输入模式 \(1,2,3\) 出发，最后分别出现在输出模式 \(2,5,7\)。

那么对应的矩阵是：

\[ U_{T,S} = \begin{pmatrix} U_{21}&U_{22}&U_{23}\\ U_{51}&U_{52}&U_{53}\\ U_{71}&U_{72}&U_{73} \end{pmatrix}. \]

输出概率为：

\[ P(2,5,7|1,2,3) = \left| \operatorname{Per}(U_{T,S}) \right|^2. \]

永久式展开为：

\[ \begin{aligned} \operatorname{Per}(U_{T,S}) ={}&U_{21}U_{52}U_{73} +U_{21}U_{53}U_{72}\\ &+U_{22}U_{51}U_{73} +U_{22}U_{53}U_{71}\\ &+U_{23}U_{51}U_{72} +U_{23}U_{52}U_{71}. \end{aligned} \]

一共：

\[ 3!=6 \]

项。

对于 \(N\) 个光子，永久式一般包含：

\[ N! \]

项。

这就是问题复杂性迅速增长的一个直观原因。

11.7 为什么玻色采样与计算复杂性有关？#

现在进入本讲最重要的理论问题：

为什么人们认为玻色采样可能具有经典计算机难以模拟的输出分布？

这需要先区分两个不同的问题。

11.7.1 计算一个永久式#

给定一个 \(N\times N\) 矩阵：

\[ A=(a_{ij}), \]

永久式定义为：

\[ \operatorname{Per}(A) = \sum_{\sigma\in S_N} \prod_{i=1}^{N}a_{i,\sigma(i)}. \]

直接计算需要处理 \(N!\) 个排列。

例如：

当然，直接枚举并不是唯一的算法。存在比 \(N!\) 更快的永久式计算算法，例如 Ryser 算法，其复杂度为：

\[ O(N2^N). \]

不过，永久式计算仍然是一个计算复杂度很高的问题。

一个重要的复杂性理论结果是：

计算一般复矩阵的永久式属于 \(\#P\)-困难问题。

这里的 \(\#P\) 是一种描述计数问题的复杂性类别。直观地说，它涉及计算满足某种条件的解的数量，而不仅仅是判断是否存在解。

11.7.2 玻色采样不是简单地计算一个永久式#

玻色采样真正要解决的是：

\[ \boxed{ \text{从永久式决定的多光子概率分布中抽取样本。} } \]

对于某个特定输出事件，概率由一个永久式的模平方决定。

但玻色采样要求生成整个输出分布中的样本，而不是只计算一个固定的永久式。

这两个任务相关，却不能直接等同。

11.7.3 为什么经典模拟可能困难？#

在标准玻色采样理论中，研究者考虑随机线性光学网络。

当输入光子不可区分、网络足够随机、模式数足够大时，输出概率包含大量不同路径的相干叠加。

其经典模拟涉及大量永久式计算。

Aaronson–Arkhipov 的经典复杂性论证表明，在若干复杂性理论假设成立的条件下，经典计算机即使只近似抽样，也难以高效模拟理想玻色采样分布。

这里必须强调两个限制：

  1. 这不是一个无条件证明，结论依赖复杂性理论假设。
  2. 实际实验中的损耗、光子不可区分性不足和探测误差，都会改变理想模型。

所以更准确的说法是：

玻色采样提供了一类具有理论计算复杂性优势证据的光量子计算模型，而不是已经证明任何规模的光学芯片都能超越经典计算机。

11.8 集成光子芯片如何实现玻色采样？#

我们已经学习过：

  • 波导模式；
  • 定向耦合器；
  • MZI；
  • Reck 与 Clements 网格；
  • Fock 态；
  • 多光子干涉。

一个典型的集成玻色采样系统包括四个部分。

11.8.1 单光子源#

首先需要制备单光子输入。

常见方案包括：

  • 自发参量下转换（SPDC）；
  • 自发四波混频（SFWM）；
  • 量子点单光子源。

这些方案的物理机制不同，但目标相同：

\[ \text{制备具有所需频谱、偏振和时间模式的单光子态}. \]

我们此前学过四波混频，它不仅可以用于经典非线性光学，也可以用于产生光子对。

不过，光子对产生过程本身具有概率性，需要考虑多光子污染和源的亮度等问题。

11.8.2 线性光学网络#

光子进入芯片后，经过一系列波导、分束器和相位调制器。

其整体作用由：

\[ U\in U(M) \]

描述。

如果采用通用 MZI 网格，就可以通过配置不同的耦合角和相位，实现目标酉矩阵。

这直接连接到第四讲的 Reck 与 Clements 分解。

11.8.3 光子探测器#

输出端需要测量每个模式中的光子数。

理想情况下，我们希望获得：

\[ (t_1,t_2,\ldots,t_M). \]

常见探测器包括：

  • 单光子雪崩二极管（SPAD）；
  • 超导纳米线单光子探测器（SNSPD）；
  • 能够分辨光子数的探测器。

普通探测器可能只能区分“有光子”和“没有光子”，无法直接分辨两个光子同时到达。

因此，实际实验还需要根据探测器能力设计测量方案。

11.8.4 经典控制与数据处理#

实验系统还需要：

  • 配置光学网络；
  • 控制相位调制器；
  • 同步光子源和探测器；
  • 记录输出事件；
  • 统计输出概率分布；
  • 与理论模型比较。

因此，玻色采样不是一块光学芯片单独完成的工作，而是一个完整的光量子实验系统。

11.9 现实中的主要误差#

理想玻色采样模型假设：

  • 光子完全不可区分；
  • 光学网络无损；
  • 器件变换精确；
  • 探测器理想。

真实芯片很难完全满足这些条件。

1. 光子不可区分性不足#

如果不同光子的频谱、偏振或时间波包不一致，那么多光子干涉的可见度会下降。

HOM 干涉可以用来测试这种不可区分性。

2. 光学损耗#

光子可能在传播、耦合和探测过程中丢失。

损耗会使实际检测到的光子数低于输入光子数。

3. 器件误差#

MZI 的相位和分束比存在偏差：

\[ U_{\mathrm{real}}\neq U_{\mathrm{target}}. \]

这与第六讲的矩阵校准问题直接相关。

4. 探测器误差#

探测器可能出现：

  • 探测效率不足；
  • 暗计数；
  • 时间抖动；
  • 光子数分辨能力有限。

5. 多光子源污染#

实际单光子源可能偶尔产生多个光子，导致输入态偏离理想的 Fock 态。

这些因素会使实验采样分布偏离理论分布。

因此，研究实际玻色采样芯片时，不能只看模式数或输入光子数，还必须评估损耗、不可区分性和探测效率。
