Canonical Transformations#

General situation#

换一组相空间变量并试图让新变量仍满足 Hamilton’s equations 的标准形式，设变换为 $(q,p)\mapsto(Q,P)$；若存在新 Hamiltonian $K(Q,P,t)$ 使得 $\dot Q_i=\frac{\partial K}{\partial P_i},\ \dot P_i=-\frac{\partial K}{\partial Q_i}$，则这个变换就是 canonical transformation。

举一个简单例子：考虑一维相空间作变换 $Q=p,\ P=-q$，原 Hamilton’s equations 是 $\dot q=H_p,\ \dot p=-H_q$，因此 $\dot Q=\dot p=-H_q$；由于 $q=-P,\ p=Q$，定义 $K(Q,P,t)=H(-P,Q,t)$，那么 $\frac{\partial K}{\partial P}=-H_q,\ \frac{\partial K}{\partial Q}=H_p$，所以 $\dot Q=\frac{\partial K}{\partial P},\ \dot P=-\frac{\partial K}{\partial Q}$，新变量仍满足标准 Hamilton’s equations，因此这是一个 canonical transformation。

Generating function#

希望找到一种系统的方法构造 canonical transformations，而不是像刚才那样凭直觉猜变换。 写出 Hamiltonian Mechanics 的 action $S[q,p]=\int_{t_1}^{t_2}(p_i\dot q_i-H(q,p,t))dt$；对于 canonical transformation，要求新旧变量给出的动力学描述等价，一个充分的构造方式是让两个 action integrands 只相差一个 total derivative：

$p_i,dq_i-H,dt=P_i,dQ_i-K,dt+dF$

这里 $F$ 是某个函数；两边积分后 action 只相差端点项，因此固定适当的端点条件时，变分给出的运动方程保持等价。

第一类：Generating function#

假设 $F$ 可写成旧坐标 $q$、新坐标 $Q$ 和时间 $t$ 的函数 $F=F_1(q,Q,t)$，对其取全微分 $dF_1=\frac{\partial F_1}{\partial q_i}dq_i+\frac{\partial F_1}{\partial Q_i}dQ_i+\frac{\partial F_1}{\partial t}dt$；与前面的 action 关系比较系数得到

$p_i=\frac{\partial F_1}{\partial q_i},\qquad P_i=-\frac{\partial F_1}{\partial Q_i},\qquad K=H+\frac{\partial F_1}{\partial t}$

这些关系还需满足相应的局部可逆性条件，才能定义所需的 canonical transformation。

第二类 generating function 与恒等变换的构造#

取 $F_2=F_2(q,P,t)$，类似地得到 $p_i=\frac{\partial F_2}{\partial q_i}$、$Q_i=\frac{\partial F_2}{\partial P_i}$，以及

$K=H+\frac{\partial F_2}{\partial t}$

如果希望新旧变量完全相同 $Q_i=q_i,\ P_i=p_i$，选取 $F_2(q,P)=q_iP_i$ 即可；若 $F_2$ 不显含时间，则 $K=H$。

Time-independent Canonical Transformations 的 Poisson Bracket 判据#

考虑一个不显含时间的可逆变换 $Q_i=Q_i(q,p),\ P_i=P_i(q,p)$，希望新变量仍满足标准 Hamilton’s equations $\dot Q_i=\frac{\partial K}{\partial P_i},\ \dot P_i=-\frac{\partial K}{\partial Q_i}$；Poisson 判据可以做到这一点：

$[Q_i,Q_j]=0,\qquad [P_i,P_j]=0,\qquad [Q_i,P_j]=\delta_{ij}$

引理：Poisson bracket 在 canonical coordinates 下保持不变。 设旧变量为 $(q_i,p_i)$、新变量为 $(Q_i,P_i)$ 且新变量满足上述判据，要证对任意两个光滑函数 $f,g$ 有 $[f,g]_{q,p}=[f,g]_{Q,P}$：设 $f=f(Q,P)$，利用链式法则 $[f,Q_i]_{q,p}=\sum_j\left(\frac{\partial f}{\partial Q_j}[Q_j,Q_i]+\frac{\partial f}{\partial P_j}[P_j,Q_i]\right)$，因此 $[f,Q_i]_{q,p}=-\frac{\partial f}{\partial P_i}$；同理 $[f,P_i]_{q,p}=\sum_j\left(\frac{\partial f}{\partial Q_j}[Q_j,P_i]+\frac{\partial f}{\partial P_j}[P_j,P_i]\right)=\frac{\partial f}{\partial Q_i}$。

设 $g=g(Q,P)$，由刚才的关系和 Poisson bracket 的反对称性得 $[Q_i,g]_{q,p}=\frac{\partial g}{\partial P_i}$、$[P_i,g]_{q,p}=-\frac{\partial g}{\partial Q_i}$；代入后

$[f,g]_{q,p}=\sum_i\left(\frac{\partial f}{\partial Q_i}\frac{\partial g}{\partial P_i}-\frac{\partial f}{\partial P_i}\frac{\partial g}{\partial Q_i}\right)$

右边正是新变量下的 Poisson bracket，即 $[f,g]_{q,p}=[f,g]_{Q,P}$，说明 canonical transformation 保留了 Poisson bracket 的代数结构。

现在将 Hamiltonian 改写为新变量的函数 $K(Q,P)=H(q(Q,P),p(Q,P))$；对任意 $Q_i$ 使用链式法则 $[Q_i,K]_{Q,P}=\sum_j\left(\frac{\partial Q_i}{\partial Q_j}\frac{\partial K}{\partial P_j}-\frac{\partial Q_i}{\partial P_j}\frac{\partial K}{\partial Q_j}\right)=\frac{\partial K}{\partial P_i}$，由引理 $[Q_i,K]_{Q,P}=[Q_i,H]_{q,p}=\dot Q_i$，于是 $\dot Q_i=\frac{\partial K}{\partial P_i}$；同理 $[P_i,K]_{Q,P}=-\frac{\partial K}{\partial Q_i}=[P_i,H]_{q,p}=\dot P_i$，所以 $\dot P_i=-\frac{\partial K}{\partial Q_i}$。

Hamilton–Jacobi Theory#

Hamilton–Jacobi equation#

通常需要求解 Hamilton’s equations 这组关于 $2n$ 个变量的一阶常微分方程，而 Hamilton–Jacobi theory 尝试寻找一个新的描述：通过一个标量函数 $S(q,t)$ 把原来的动力学问题转化成一个偏微分方程，这个 $S$ 称为 Hamilton’s principal function。

考虑第二类 generating function $F_2(q,P,t)$，它定义的 canonical transformation 满足 $p_i=\frac{\partial F_2}{\partial q_i},\ Q_i=\frac{\partial F_2}{\partial P_i}$ 且 $K=H+\frac{\partial F_2}{\partial t}$；现在令新 Hamiltonian 恒等于零即 $K=0$，则新 Hamilton’s equations 变为 $\dot Q_i=\frac{\partial K}{\partial P_i}=0,\ \dot P_i=-\frac{\partial K}{\partial Q_i}=0$，因此所有 $Q_i,P_i$ 都是常数。 将生成函数记为 $F_2(q,P,t)=S(q,\alpha,t)$，其中 $\alpha=(\alpha_1,\ldots,\alpha_n)$ 是一组常数参数、对应新动量 $P_i=\alpha_i$；由 $K=H+\frac{\partial S}{\partial t}=0$ 以及 $p_i=\frac{\partial S}{\partial q_i}$ 得到

$H\left(q_1,\ldots,q_n,\frac{\partial S}{\partial q_1},\ldots,\frac{\partial S}{\partial q_n},t\right)+\frac{\partial S}{\partial t}=0$

这就是 Hamilton–Jacobi equation，它将原本关于坐标和动量的 Hamiltonian dynamics 转化成关于标量函数 $S(q,t)$ 的一阶偏微分方程。 这里需要一个技术条件：所寻找的 $S$ 必须足够完整，能够定义所需的局部可逆 canonical transformation；不是任意一个 Hamilton–Jacobi 方程的解，都能单独提供整个系统的完整运动。

time-independent Hamilton–Jacobi equation#

如果 Hamiltonian 不显含时间 $H=H(q,p)$，可尝试令 $S(q,t)=W(q)-Et$，代入 Hamilton–Jacobi equation 得到

$H\left(q,\frac{\partial W}{\partial q}\right)=E$

这就是 time-independent Hamilton–Jacobi equation；含时 PDE 被转化为不显含时间的方程，求出 $W$ 后可通过生成函数关系恢复轨迹。

以一维自由粒子为例，考虑 $H(q,p)=\frac{p^2}{2m}$，Hamilton–Jacobi equation 为 $\frac{\partial S}{\partial t}+\frac{1}{2m}\left(\frac{\partial S}{\partial q}\right)^2=0$；尝试解 $S(q,t;\alpha)=\alpha q-\frac{\alpha^2}{2m}t$，检验得 $\frac{\partial S}{\partial t}=-\frac{\alpha^2}{2m},\ \frac{\partial S}{\partial q}=\alpha$，代入方程确实为零。 进而 $p=\frac{\partial S}{\partial q}=\alpha$ 所以动量守恒；新坐标 $Q=\frac{\partial S}{\partial\alpha}=q-\frac{\alpha}{m}t$，因 $Q$ 是常数记为 $\beta$，于是

$q(t)=\beta+\frac{\alpha}{m}t$

这正是自由粒子的匀速直线运动，其中 $\alpha$ 是动量、$\beta$ 是初始位置常数。

对于复杂系统，若求得完整的 $S(q,t;\alpha)$，可通过 $\frac{\partial S}{\partial\alpha_i}=\beta_i$ 得到运动轨迹的隐式关系；这里 $\alpha_i,\beta_i$ 是 $2n$ 个积分常数的一种参数化方式，要得到完整解必须满足适当的非退化条件。 注意我们不是先解运动方程再构造 $S$，而是先找到 Hamilton–Jacobi equation 的一个完整解，再通过生成函数关系恢复运动，这正是 Hamilton–Jacobi 方法的价值。

Hamilton–Jacobi Theory 与 Action#

Hamiltonian formulation 中的 action 为 $\mathcal A[q,p]=\int_{t_1}^{t_2}(p_i\dot q^i-H)dt$；假设

$dS=p_i,dq^i-H,dt$

展开得 $dS=\frac{\partial S}{\partial q^i}dq^i+\frac{\partial S}{\partial t}dt$，比较系数就得到 $p_i=\frac{\partial S}{\partial q^i}$ 与 $\frac{\partial S}{\partial t}=-H$；把第一式代入第二式，正好恢复

$\frac{\partial S}{\partial t}+H\left(q,\frac{\partial S}{\partial q},t\right)=0$

这说明：

  • 从 PDE 角度看，Hamilton–Jacobi equation 是关于 $S(q,t)$ 的偏微分方程。
  • 从变分原理角度看，$S$ 是沿经典轨迹计算的 action 函数。

注意到，任意路径上的 action 是一个路径泛函；而 $S(q,t)$ 则是固定端点条件下，沿经典解得到的函数。
