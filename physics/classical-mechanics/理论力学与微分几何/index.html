学过 Differential Geometry 之后重新学 Classical Mechanics，有很多新的收获，此为学习笔记，持续更新。

Lagrangian Mechanics and Geometry#

Configuration Space#

设系统有 $n$ 个 degrees of freedom，写作 $q_1,q_2,\ldots,q_n$，则某一时刻的 configuration 可表示为 $q=(q_1,\ldots,q_n)$，所有可能的 configurations 构成 configuration space $\mathcal C$。 随时间演化 $q(t)=(q_1(t),\ldots,q_n(t))$，就是 $\mathcal C$ 中的一条 trajectory。

两个粒子的例子#

假设有两个粒子 $\mathbf r_1(t),\mathbf r_2(t)\in\mathbb R^3$，整个系统的 configuration 不是一个三维位置，而是 $q(t)=(\mathbf r_1(t),\mathbf r_2(t))$，因此 $Q=\mathbb R^3\times\mathbb R^3=\mathbb R^6$。 于是 system point 实际上是在 six-dimensional configuration space 中运动，即 $q(t)\in\mathbb R^6$；而物理上我们看到的是两条三维轨迹 $\mathbf r_1(t)$ 与 $\mathbf r_2(t)$。

自由 rigid body#

例如一个自由 rigid body，其 configuration 可用 $(x,y,z,\phi,\theta,\psi)$ 描述，故 $Q\simeq\mathbb R^3\times SO(3)$。 此时一个 configuration-space point $q=(x,y,z,\phi,\theta,\psi)$ 代表的是整个刚体当前的位置加当前的 orientation；随时间 $q(t)=(x(t),y(t),z(t),\phi(t),\theta(t),\psi(t))$，整个刚体的运动就是 $Q$ 中的一条 curve。

但这条 curve 显然不是某个刚体质点在 physical space 中画出来的轨迹。

Hamilton’s Principle#

构造一个 functional $S[q]=\int_{t_1}^{t_2}L(q,\dot q,t),dt$，Hamilton’s Principle 说 $\delta S=0$，即真实运动 $q(t)$ 是使 action stationary 的那条 curve。

更严格地说：在所有满足固定端点条件 $q(t_1)=q_1,\ q(t_2)=q_2$ 的 admissible curves 中，真实的 motion 是使 action $S[q]$ stationary 的那一条。

Lagrangian Mechanics 的 Geometry 视角#

我们已经有 $q(t)\in Q$，但仅仅知道一个 configuration 不够，因为 mechanics 研究的是运动，所以还需要 $\dot q(t)$。 于是 $L=L(q,\dot q,t)$ 实际上是在考虑 $(q,\dot q)$，它对应一个特定的 tangent space $T_qQ$，所以一个状态是 $(q,v)$，其中 $v\in T_qQ$。

把所有这些 tangent spaces 拼在一起就是 tangent bundle：

$TQ=\bigsqcup_{q\in Q}T_qQ$

因此 $(q,\dot q)\in TQ$；在一个 coordinate chart 中，$(q_1,\ldots,q_n,\dot q_1,\ldots,\dot q_n)$ 就是 $TQ$ 上的局部 coordinates，且 $\dim TQ=n+n=2n$。 于是 $L(q,\dot q,t)$ 本质上可以看成

$L:TQ\times\mathbb R\to\mathbb R$

Calculus of Variations#

Fundamental Lemma#

假设 $\int_{t_1}^{t_2}A(t)\eta(t),dt=0$ 对任意 admissible variation $\eta(t)$ 都成立，要证 $A(t)\equiv0$。 反设 $A$ 不恒为零，则存在某个区间 $I\subset(t_1,t_2)$ 使 $A$ 在那里不为零；若暂时假设 $A$ 连续，最简单的构造是 $\eta(t)=-A(t)$，但它必须满足 endpoint condition，故取一个只在内部非零的 bump function $\chi(t)$，令 $\eta(t)=-A(t)\chi(t)$，于是 $\eta(t_1)=\eta(t_2)=0$。

代回去得 $\int A\eta,dt=-\int A(t)^2\chi(t),dt$；选择 $\chi\geq0$ 且在 $A\neq0$ 处严格为正，就得到 $\int A(t)\eta(t),dt<0$，与原来的 $\int A\eta,dt=0$ 矛盾。 因此

$A(t)=0$

Euler-Lagrange Equation#

先考虑最简单的 functional $J[y]=\int_{x_1}^{x_2}F(y,y’,x),dx$，希望找到使 $J$ stationary 的 function $y(x)$。 取 $y(x)\to y(x)+\epsilon\eta(x)$，定义 $J(\epsilon)=\int_{x_1}^{x_2}F(y+\epsilon\eta,;y’+\epsilon\eta’,;x),dx$，于是 $\delta J=\int_{x_1}^{x_2}\left(\frac{\partial F}{\partial y}\eta+\frac{\partial F}{\partial y’}\eta’\right)dx$。

而 $\eta’=\frac{d\eta}{dx}$，第二项 integration by parts 把 $\int\frac{\partial F}{\partial y’}\eta’,dx$ 变成 $\left[\frac{\partial F}{\partial y’}\eta\right]_{x_1}^{x_2}-\int\frac{d}{dx}\left(\frac{\partial F}{\partial y’}\right)\eta,dx$；由于 $\eta(x_1)=\eta(x_2)=0$，boundary term 消失，于是 $\delta J=\int_{x_1}^{x_2}\left[\frac{\partial F}{\partial y}-\frac{d}{dx}\left(\frac{\partial F}{\partial y’}\right)\right]\eta,dx$。

而 $\eta(x)$ 在内部是任意的，因此只能有

$\frac{\partial F}{\partial y}-\frac{d}{dx}\frac{\partial F}{\partial y’}=0$

这就是 Euler–Lagrange equation。现在只需做 substitution，把 $x\to t,\ y\to q_i,\ y’\to\dot q_i,\ F\to L$，就得到

$\frac{d}{dt}\frac{\partial L}{\partial\dot q_i}-\frac{\partial L}{\partial q_i}=0$

关于端点条件的深层含义#

“如果起点和终点不同，就没有比较的意义了"准确地说是指：Hamilton’s Principle 把 actual motion 表述为一个 boundary-value problem $(q_1,t_1)\longrightarrow(q_2,t_2)$，在这个表述下我们问的是给定 initial configuration 和 final configuration，哪一条 admissible path 使 action stationary。 但这和说"实验上我们必须先知道最终位形，然后物理才预言路径"不是一回事，这是 formulation 和 physical prediction 的区别。

例如 Newtonian initial-value problem 通常给 $q(t_0),\ \dot q(t_0)$，然后由 equation of motion 预测未来 $q(t)$；而 Hamiltonian formulation 可以把同一个 dynamics 表述成 $q(t_1)=q_1,\ q(t_2)=q_2$ 之间的 variational problem。 所以

$\text{initial-value formulation}\neq\text{boundary-value formulation}$

但它们可以描述同一个 classical dynamics。

到底怎么定义 $L$？#

有一个逻辑上的"黑箱”：为什么自然界的 dynamics 恰好可以由 $L=T-V$ 描述？

先从最简单的一个粒子开始#

考虑保守场中的一维粒子，希望构造 $L(x,\dot x)$ 使 Euler–Lagrange equation $\frac{d}{dt}\frac{\partial L}{\partial\dot x}-\frac{\partial L}{\partial x}=0$ 恰好变成 Newton’s equation，最自然的尝试是 $L=\frac12m\dot x^2-V(x)$。 计算得 $\frac{d}{dt}\frac{\partial L}{\partial\dot x}=m\ddot x$，另一方面 $\frac{\partial L}{\partial x}=-V’(x)$，即

$m\ddot x=-V’(x)$

所以至少在这个例子里，$T-V$ 确实 reproduces Newtonian dynamics。

Lagrangian 的等价性#

假设不用 $L=T-V$ 而用 $L’=L+C$（$C$ 为 constant），那么 $\frac{\partial L’}{\partial q_i}=\frac{\partial L}{\partial q_i},\ \frac{\partial L’}{\partial\dot q_i}=\frac{\partial L}{\partial\dot q_i}$，Euler–Lagrange equations 完全不变，描述完全相同的 classical dynamics。

进一步，若 $L’=L+\frac{dF(q,t)}{dt}$，也给出相同的 Euler–Lagrange equations：action 变成 $S’=\int_{t_1}^{t_2}L’,dt=S+\int_{t_1}^{t_2}\frac{dF}{dt},dt$，所以 $S’=S+F(q_2,t_2)-F(q_1,t_1)$；由于 endpoints 固定，$\delta F(q_1,t_1)=\delta F(q_2,t_2)=0$，因此 $\delta S’=\delta S$。

真正具有物理意义的并不是某个唯一的函数 $L(q,\dot q,t)$，而是一个等价类

$L\sim L+\frac{dF}{dt}$

所以不能把 $L=T-V$ 理解成"自然界规定 Lagrangian 必须长这样"；更准确的是：对于 ordinary conservative mechanical systems，$T-V$ 是一个能够正确编码 dynamics 的 convenient Lagrangian。

一个非常漂亮的几何图景#

更一般地，对于 generalized coordinates，$T=\frac12\sum_{i,j}g_{ij}(q)\dot q_i\dot q_j$，考虑 $L=\frac12g_{ij}(q)\dot q^i\dot q^j-V(q)$。 计算得 $\frac{\partial L}{\partial\dot q^k}=g_{kj}\dot q^j$，于是 $\frac{d}{dt}(g_{kj}\dot q^j)=\frac{\partial g_{kj}}{\partial q^i}\dot q^i\dot q^j+g_{kj}\ddot q^j$；另一方面 $\frac{\partial L}{\partial q^k}=\frac12\frac{\partial g_{ij}}{\partial q^k}\dot q^i\dot q^j-\frac{\partial V}{\partial q^k}$。

代入 Euler–Lagrange equation 得 $g_{kj}\ddot q^j+\frac{\partial g_{kj}}{\partial q^i}\dot q^i\dot q^j-\frac12\frac{\partial g_{ij}}{\partial q^k}\dot q^i\dot q^j+\frac{\partial V}{\partial q^k}=0$；再乘 inverse metric $g^{\ell k}$，最终得到

$\ddot q^\ell+\Gamma^\ell_{ij}\dot q^i\dot q^j=-g^{\ell k}\partial_kV$

其中 $\Gamma^\ell_{ij}$ 是由 metric 决定的 Christoffel symbols。当 $V=0$ 时它变成

$\ddot q^\ell+\Gamma^\ell_{ij}\dot q^i\dot q^j=0$

这就是 geodesic equation。

协变导数的视角#

沿曲线 $q(t)$，速度向量为 $\dot q$，它沿自身运动的 covariant derivative 是 $(\nabla_{\dot q}\dot q)^\ell=\ddot q^\ell+\Gamma^\ell_{ij}\dot q^i\dot q^j$，所以刚才的方程恰好就是

$\nabla_{\dot q}\dot q=0$

这表示速度向量沿曲线被 parallel transported，没有相对于 manifold 的内禀加速度。 假设你沿着球面上的 great circle 运动，从三维空间看速度向量会不断改变方向，因为必须沿着球面运动；但这种变化有一部分只是因为球面本身弯曲了，并不意味着你在球面内部"转弯"了。

Affine Parameter#

同一条几何曲线可以用不同参数描述，例如平面上的直线可写成 $q(t)=(t,0)$，也可写成 $q(s)=(s^3,0)$；只要参数在考虑的区间内单调变化，两者就描述同一条直线上的同一段几何轨迹，只是走过各点的参数节奏不同。 但使用不同参数时，运动方程的形式不一定保持不变：对于 affine parameter $\lambda$，geodesic equation 写作

$\frac{d^2q^k}{d\lambda^2}+\Gamma^k_{ij}\frac{dq^i}{d\lambda}\frac{dq^j}{d\lambda}=0$

若改用任意非线性参数，方程通常会多出一项与速度成正比的项，而 affine parameter 能让 geodesic equation 保持标准形式；对于有质量的自由粒子，适当选择的固有时间 $\tau$ 就是一个 affine parameter。

Energy functional 与 Length functional#

自由粒子的 kinetic-energy action 是 $S[q]=\frac12\int g_{ij}\dot q^i\dot q^j,dt$，要求 $\delta S=0$ 从而导出标准形式的 geodesic equation，这里的参数必须满足相应的 affine 参数条件。 但若直接研究曲线的长度 $\ell[q]=\int\sqrt{g_{ij}\dot q^i\dot q^j},dt$，长度只关心曲线的几何形状，不关心沿曲线运动的速度有多快，因此：

  • Energy functional $S[q]=\frac12\int|\dot q|^2dt$：不仅涉及路径，还涉及参数化速度。
  • Length functional $\ell[q]=\int|\dot q|dt$：只依赖几何曲线本身，不依赖具体的单调参数化。

Symmetry and Conservation Laws: Noether Theorem#

Cyclic coordinate#

如果某个 generalized coordinate $q_j$ 不显式出现在 Lagrangian 中，即 $\frac{\partial L}{\partial q_j}=0$，就称 $q_j$ 为 cyclic coordinate（也叫 ignorable coordinate）。 Euler–Lagrange equation 立即给出 $\frac{d}{dt}\frac{\partial L}{\partial\dot q_j}=0$，定义 conjugate momentum $p_j:=\frac{\partial L}{\partial\dot q_j}$ 便得到

$p_j=\text{constant}$

也就是：如果 Lagrangian 不显含某个 coordinate，那么它对应的 conjugate momentum 守恒。

旋转对称性与角动量守恒#

考虑平面上的中心势 $V=V(r)$，Lagrangian 为 $L=\frac12m(\dot r^2+r^2\dot\theta^2)-V(r)$；做 transformation $\theta\mapsto\theta+\alpha$（$\alpha$ 为常数），意味着粒子的位置整体绕原点旋转角度 $\alpha$，但 $r$ 没变、速度大小没变、中心势 $V(r)$ 也没变，因此 $L(r,\dot r,\theta+\alpha,\dot\theta)=L(r,\dot r,\theta,\dot\theta)$，这就是 rotational symmetry。

于是

$\text{rotational symmetry}\Longrightarrow\theta\text{ 是 cyclic coordinate}\Longrightarrow p_\theta\text{ 守恒}$

这不是巧合，说明角动量守恒是旋转对称性在动力学中的体现。

平移对称性与动量守恒#

考虑一维自由粒子 $L=\frac12m\dot x^2$，做 spatial translation $x\mapsto x+a$；因为 Lagrangian 中没有显式的 $x$，所以 $L(x+a,\dot x)=L(x,\dot x)$，因此 $\frac{\partial L}{\partial x}=0$，Euler–Lagrange equation 给出 $\frac{d}{dt}\frac{\partial L}{\partial\dot x}=0$，也就是

$p=m\dot x=\text{constant}$

时间平移对称性和能量守恒#

假设 $L=L(q_i,\dot q_i)$ 不显式依赖时间 $t$，定义 $E=\sum_i\dot q_i\frac{\partial L}{\partial\dot q_i}-L$，记 $p_i=\frac{\partial L}{\partial\dot q_i}$ 则 $E=\sum_i\dot q_i p_i-L$。 两边对时间求全导数得 $\frac{dE}{dt}=\sum_i\ddot q_i p_i+\sum_i\dot q_i\frac{dp_i}{dt}-\frac{dL}{dt}$；把 chain rule 展开为 $\frac{dL}{dt}=\sum_i\frac{\partial L}{\partial q_i}\dot q_i+\sum_i p_i\ddot q_i+\frac{\partial L}{\partial t}$，代回去第一项与含 $\ddot q_i$ 的项抵消，得到 $\frac{dE}{dt}=\sum_i\dot q_i\left(\frac{dp_i}{dt}-\frac{\partial L}{\partial q_i}\right)-\frac{\partial L}{\partial t}$。

而 Euler–Lagrange equations 告诉我们 $\frac{dp_i}{dt}-\frac{\partial L}{\partial q_i}=0$，所以最终 $\frac{dE}{dt}=-\frac{\partial L}{\partial t}$；由于假设 $L$ 不显含时间，则

$\frac{dE}{dt}=0$

对于我们目前主要讨论的普通机械系统，若 $L=T-V$ 且 $T$ 是 velocities 的二次齐次函数、$V$ 不依赖 velocities，则 $E=\sum_i\dot q_i\frac{\partial T}{\partial\dot q_i}-(T-V)$；利用刚才的 Euler’s theorem 得 $E=2T-T+V$，因此

$E=T+V$

这就是通常意义上的 total mechanical energy。但要注意：一般 Lagrangian 的 $E=\sum_i\dot q_i\frac{\partial L}{\partial\dot q_i}-L$ 不一定总能直接解释为 $T+V$，尽管在不显含时间的条件下它仍然守恒。

可以从三个层次来看：

  • 物理层面：时间平移对称性与能量守恒相联系。
  • 数学层面：对满足 Euler–Lagrange equations 的轨迹，若 $L$ 不显含时间，则 $E_L$ 守恒。
  • 具体系统层面：在普通的 $L=T-V$ 形式下 $E_L=T+V$，因此得到熟悉的机械能守恒。

这三者并不矛盾，而是在不同层次描述同一结构。

Noether’s theorem#

何为 symmetry#

目前讨论的 symmetry 都比较特殊，可以通过某个 coordinate 不显含于 Lagrangian 来识别；但真正一般的情况更广：一个 transformation 可能同时改变很多 coordinates，如 $q^i\mapsto q^i+\epsilon,\xi^i(q,t)$，只要它满足适当条件使 action 保持不变（更一般地允许 Lagrangian 改变一个 total time derivative），就可能对应一个 conserved quantity，这就是 Noether’s theorem 的核心思想。

假设某个连续变换使 Lagrangian 发生变化，但变化量只是 total derivative $\delta L=\epsilon\frac{dF}{dt}$，这时 action 是否仍有足够的 symmetry 从而可能存在 conserved quantity？ 通常说 Lagrangian invariant 是指变换前后 $L’=L$，但 Noether’s theorem 允许更一般的 $\delta L=\epsilon\frac{dF}{dt}$，其中 $\epsilon$ 是 infinitesimal parameter、$F$ 是某个函数；之所以允许，是因为真正关心的 variational principle 是 action $S=\int_{t_1}^{t_2}L,dt$，变换后 $\delta S=\int_{t_1}^{t_2}\delta L,dt=\epsilon\int_{t_1}^{t_2}\frac{dF}{dt},dt$，因此

$\delta S=\epsilon\bigl[F(t_2)-F(t_1)\bigr]$

action 的变化只取决于 endpoints 而非路径内部的具体形状，这意味着在固定 endpoints 的变分问题中这个变化不会改变运动方程；严格来说这称为 quasi-symmetry，也常被纳入广义的 Noether symmetry，它不一定让 action 的数值严格不变，但足以让变分原理保持不变。

Noether’s theorem#

设 infinitesimal transformation 为 $\delta q_i=\epsilon,\xi_i(q,t)$ 且 $\delta L=\epsilon\frac{dF}{dt}$，要由此推出一个 conserved quantity。 关键步骤是把 $\delta L=\sum_i\frac{\partial L}{\partial q_i}\delta q_i+\sum_i\frac{\partial L}{\partial\dot q_i}\delta\dot q_i$ 与全导数形式结合，再使用 Euler–Lagrange equations，这会导出

$Q=\sum_i p_i\xi_i-F$

在适当的变换与参数化约定下，$Q$ 沿运动保持常数，其中 $p_i=\partial L/\partial\dot q_i$。 对称性允许 Lagrangian 改变一个 total derivative，而 Noether conserved quantity 会相应减去这个边界项对应的 $F$；注意这个公式目前针对只变换 $q_i$、不变换时间参数的情形，时间平移需要单独处理。

Noether 定理的应用#

考虑质量为 $m$ 的质点在中心势 $V$ 中运动，笛卡尔坐标下 $L=\frac12m(\dot x^2+\dot y^2)-V(\sqrt{x^2+y^2})$；考虑 infinitesimal rotation $\delta x=-\varepsilon y,\ \delta y=\varepsilon x$，因此变换生成元是 $\xi_x=-y,\ \xi_y=x$。 由于旋转不改变 $x^2+y^2$、速度模长也不变，所以 $\delta L=0$，对应 $F=0$；代入 Noether conserved quantity $Q=p_x\xi_x+p_y\xi_y$ 得 $Q=-yp_x+xp_y$，而平面运动角动量在 $z$ 方向的分量是 $L_z=xp_y-yp_x$，所以

$Q=L_z=\text{const}$

这里的关键不是"极坐标里 $\theta$ 不出现"，而是更深一层的事实：旋转对称性是几何性质，角动量是它对应的 Noether charge，cyclic coordinate 只是让我们更容易算出这个守恒量的一种坐标表达。

进一步推广到三维，infinitesimal rotation 可写成 $\delta\mathbf r=\varepsilon,\mathbf n\times\mathbf r$（$\mathbf n$ 为旋转轴方向的单位向量），对应 Noether charge 为 $Q=\mathbf p\cdot(\mathbf n\times\mathbf r)=\mathbf n\cdot(\mathbf r\times\mathbf p)$，因此

$Q=\mathbf n\cdot\mathbf L,\qquad \mathbf L=\mathbf r\times\mathbf p$

每一个旋转轴方向的对称性都对应角动量在该方向上的分量守恒；对于各向同性的中心势，三个空间方向的旋转对称性共同给出角动量向量守恒。 注意若系统只有绕某一固定轴的旋转对称性，一般只能保证角动量在该轴上的分量守恒，不一定保证整个角动量向量守恒。

Hamiltonian Mechanics and Symplectic Geometry#

Legendre Transform#

以下默认采用 Einstein summation convention

在 Lagrangian formulation 中，系统的状态由广义坐标和广义速度描述，运动方程是二阶微分方程；我们希望改用广义坐标 $q^i$ 和共轭动量 $p_i$ 描述状态并得到一阶方程，其中 $p_i=\frac{\partial L}{\partial\dot q^i}$。 如果可由这个关系解出 $\dot q^i=\dot q^i(q,p,t)$，就能把速度消去，构造只依赖 $q,p,t$ 的 Hamiltonian

$H(q,p,t)=p_i\dot q^i-L(q,\dot q,t)$

为此定义 velocity Hessian $W_{ij}=\frac{\partial^2L}{\partial\dot q^i\partial\dot q^j}$；若 $\det W\neq0$，则在局部能反解出 $\dot q^i=\dot q^i(q,p,t)$。 具体来说，固定 $q,t$ 考虑映射 $\dot q\mapsto p(\dot q)$，它对速度的 Jacobian 矩阵恰好是 $\frac{\partial p_i}{\partial\dot q^j}=W_{ij}$，因此由 inverse function theorem 只要 $\det W\neq0$ 就能局部反解；此时 Legendre map $\mathbb FL:TQ\to T^*Q,\ (q,\dot q)\mapsto\left(q,p_i=\frac{\partial L}{\partial\dot q^i}\right)$ 是局部微分同胚，只保证局部可逆，不能断言整个映射全局一一对应。 若全局可逆，这样的 Lagrangian 称为 regular Lagrangian；若 Hessian 奇异，Legendre transform 就可能无法唯一反解速度。

以下假定 Hessian 全局可逆，对 $H(q,p,t)=p_i\dot q^i-L(q,\dot q,t)$ 取全微分；注意此处 $\dot q^i$ 是由 $q,p,t$ 决定的函数，因此 $dH=\dot q^i,dp_i+p_i,d\dot q^i-\frac{\partial L}{\partial q^i}dq^i-\frac{\partial L}{\partial\dot q^i}d\dot q^i-\frac{\partial L}{\partial t}dt$，根据 $p_i=\frac{\partial L}{\partial\dot q^i}$ 两个含 $d\dot q^i$ 的项正好抵消，于是 $dH=\dot q^i,dp_i-\frac{\partial L}{\partial q^i}dq^i-\frac{\partial L}{\partial t}dt$。 另一方面把 $H$ 看成 $H(q,p,t)$，按定义有 $dH=\frac{\partial H}{\partial q^i}dq^i+\frac{\partial H}{\partial p_i}dp_i+\frac{\partial H}{\partial t}dt$，比较系数得到

$\dot q^i=\frac{\partial H}{\partial p_i},\qquad \dot p_i=-\frac{\partial H}{\partial q^i},\qquad \frac{\partial H}{\partial t}=-\frac{\partial L}{\partial t}$

前两式就是 Hamilton’s equations：原本的二阶运动方程现在变成关于 $q^i,p_i$ 的一阶方程组，它们与原来的 Euler–Lagrange equations 在 regular 条件下等价。

Hamiltonian Mechanics 的几何视角#

在给定的配置点 $q$，共轭动量 $p$ 是作用于虚位移的线性函数，更具体地说是一个 covector，即 $p\in T_q^*Q$。 证明：考虑配置坐标变换 $q’^a=q’^a(q)$，速度按 tangent vector 的变换规律变化为 $\dot q’^a=\frac{\partial q’^a}{\partial q^i}\dot q^i$；为了 $p_i\delta q^i$ 在坐标变换下保持不变，动量必须满足

$p’_a=p_i\frac{\partial q^i}{\partial q’^a}$

这正是 covector 的变换规律；因此所有可能的 $(q,p)$ 构成 $T^*Q=\bigcup_{q\in Q}T_q^*Q$，即 cotangent bundle。

典型例子是谐振子 $H(q,p)=\frac{p^2}{2m}+\frac12kq^2$，由 Hamilton’s equations 容易得到 $\ddot q+\omega^2q=0$，其中 $\omega=\sqrt{k/m}$，这与 Lagrangian Mechanics 得到的运动方程完全一致。 但 Hamiltonian formulation 还有新的几何视角：在 $(q,p)$ 平面上运动轨迹满足 $\frac{p^2}{2m}+\frac12kq^2=E$，当 $E>0$ 时这是相空间中的椭圆；系统的运动可理解为相空间中的一条轨迹，而 Hamilton’s equations 规定了轨迹的演化方向。

Symplectic Geometry#

$T^*Q$ 具有 symplectic form#

对一个自由度的系统，相空间局部坐标为 $(q,p)$，symplectic form 是 $\omega=dq\wedge dp$，它是一个可作用在两个 tangent vectors 上的 differential 2-form。 设 $u=a\frac{\partial}{\partial q}+b\frac{\partial}{\partial p},\ v=c\frac{\partial}{\partial q}+d\frac{\partial}{\partial p}$，则 $\omega(u,v)=ad-bc$，即两个向量在 $(q,p)$ 平面上张成的有向面积。

更一般地，在 $2n$ 维流形 $M$ 上，symplectic form 是满足以下条件的 2-form（$d$ 为 exterior derivative）：

  1. 闭合（closed）：$d\omega=0$，限制 $\omega$ 的微分结构。
  2. 非退化（non-degenerate）：$\omega(u,v)=0$ 对所有 $v\in T_xM$ 必须推出 $u=0$，保证它能有效把 tangent vectors 与 covectors 联系起来。

接下来证明 $T^*Q$ 天然具有 symplectic form：考虑 canonical one-form $\vartheta=p_i dq^i$，取外微分 $d\vartheta=d(p_i,dq^i)=dp_i\wedge dq^i$；因为 wedge product 反对称，$dp_i\wedge dq^i=-dq^i\wedge dp_i$，因此定义

$\omega=-d\vartheta=dq^i\wedge dp_i$

验证两个条件：第一，闭合性 $d\omega=-d^2\vartheta=0$ 成立；第二，设 $u=a^i\frac{\partial}{\partial q^i}+b_i\frac{\partial}{\partial p_i}$，对任意 $v=c^i\frac{\partial}{\partial q^i}+d_i\frac{\partial}{\partial p_i}$ 有 $\omega(u,v)=a^id_i-c^ib_i$，若它对所有 $v$ 都为零，任意选择 $c^i,d_i$ 都迫使 $a^i=0,\ b_i=0$，故 $u=0$，非退化性成立。 因此 cotangent bundle 上的 canonical symplectic form 确实满足 symplectic geometry 的定义；值得注意的是，虽然写出了局部坐标表达式 $dq^i\wedge dp_i$，但这个几何结构本身并不依赖特定坐标的选择。

Hamilton’s equations 的几何表达#

在相空间 $M=T^*Q$ 上给定 Hamiltonian $H=H(q,p,t)$，Hamiltonian vector field $X_H$ 定义为满足

$\iota_{X_H}\omega=dH$

的向量场，其中 $\iota_{X_H}\omega$ 表示把 $X_H$ 放进 2-form 的第一个位置得到一个 1-form。 在局部坐标下设 $X_H=\dot q^i\frac{\partial}{\partial q^i}+\dot p_i\frac{\partial}{\partial p_i}$，利用 $\omega=dq^i\wedge dp_i$ 可算出 $\iota_{X_H}\omega=\dot q^i dp_i-\dot p_i dq^i$；另一方面 $dH=\frac{\partial H}{\partial q^i}dq^i+\frac{\partial H}{\partial p_i}dp_i$，比较系数得到

$\dot q^i=\frac{\partial H}{\partial p_i},\qquad \dot p_i=-\frac{\partial H}{\partial q^i}$

这正是 Hamilton’s equations。可以概括为：$\omega$ 提供相空间的几何结构，$H$ 提供系统的动力学信息，两者共同确定 $X_H$，而 $X_H$ 的积分曲线就是系统在相空间中的运动轨迹。

Poisson bracket#

有了 Hamiltonian vector field，就可以定义任意两个 observables $f(q,p)$ 与 $g(q,p)$ 的 Poisson bracket

$[f,g]=\sum_i\left(\frac{\partial f}{\partial q^i}\frac{\partial g}{\partial p_i}-\frac{\partial f}{\partial p_i}\frac{\partial g}{\partial q^i}\right)$

根据 Hamilton’s equations，对任意不显含时间的函数 $f(q,p)$ 有 $\frac{df}{dt}=\frac{\partial f}{\partial q^i}\dot q^i+\frac{\partial f}{\partial p_i}\dot p_i=\frac{\partial f}{\partial q^i}\frac{\partial H}{\partial p_i}-\frac{\partial f}{\partial p_i}\frac{\partial H}{\partial q^i}=[f,H]$；若 $f$ 显含时间，则完整公式为

$\frac{df}{dt}=\frac{\partial f}{\partial t}+[f,H]$

因此守恒量可用 Poisson bracket 判定 $\frac{\partial f}{\partial t}+[f,H]=0$，对于不显含时间的 $f$ 简化为 $[f,H]=0$。

Canonical Transformations#

General situation#

换一组相空间变量并试图让新变量仍满足 Hamilton’s equations 的标准形式，设变换为 $(q,p)\mapsto(Q,P)$；若存在新 Hamiltonian $K(Q,P,t)$ 使得 $\dot Q_i=\frac{\partial K}{\partial P_i},\ \dot P_i=-\frac{\partial K}{\partial Q_i}$，则这个变换就是 canonical transformation。

举一个简单例子：考虑一维相空间作变换 $Q=p,\ P=-q$，原 Hamilton’s equations 是 $\dot q=H_p,\ \dot p=-H_q$，因此 $\dot Q=\dot p=-H_q$；由于 $q=-P,\ p=Q$，定义 $K(Q,P,t)=H(-P,Q,t)$，那么 $\frac{\partial K}{\partial P}=-H_q,\ \frac{\partial K}{\partial Q}=H_p$，所以 $\dot Q=\frac{\partial K}{\partial P},\ \dot P=-\frac{\partial K}{\partial Q}$，新变量仍满足标准 Hamilton’s equations，因此这是一个 canonical transformation。

Generating function#

希望找到一种系统的方法构造 canonical transformations，而不是像刚才那样凭直觉猜变换。 写出 Hamiltonian Mechanics 的 action $S[q,p]=\int_{t_1}^{t_2}(p_i\dot q_i-H(q,p,t))dt$；对于 canonical transformation，要求新旧变量给出的动力学描述等价，一个充分的构造方式是让两个 action integrands 只相差一个 total derivative：

$p_i,dq_i-H,dt=P_i,dQ_i-K,dt+dF$

这里 $F$ 是某个函数；两边积分后 action 只相差端点项，因此固定适当的端点条件时，变分给出的运动方程保持等价。

第一类：Generating function#

假设 $F$ 可写成旧坐标 $q$、新坐标 $Q$ 和时间 $t$ 的函数 $F=F_1(q,Q,t)$，对其取全微分 $dF_1=\frac{\partial F_1}{\partial q_i}dq_i+\frac{\partial F_1}{\partial Q_i}dQ_i+\frac{\partial F_1}{\partial t}dt$；与前面的 action 关系比较系数得到

$p_i=\frac{\partial F_1}{\partial q_i},\qquad P_i=-\frac{\partial F_1}{\partial Q_i},\qquad K=H+\frac{\partial F_1}{\partial t}$

这些关系还需满足相应的局部可逆性条件，才能定义所需的 canonical transformation。

第二类 generating function 与恒等变换的构造#

取 $F_2=F_2(q,P,t)$，类似地得到 $p_i=\frac{\partial F_2}{\partial q_i}$、$Q_i=\frac{\partial F_2}{\partial P_i}$，以及

$K=H+\frac{\partial F_2}{\partial t}$

如果希望新旧变量完全相同 $Q_i=q_i,\ P_i=p_i$，选取 $F_2(q,P)=q_iP_i$ 即可；若 $F_2$ 不显含时间，则 $K=H$。

Time-independent Canonical Transformations 的 Poisson Bracket 判据#

考虑一个不显含时间的可逆变换 $Q_i=Q_i(q,p),\ P_i=P_i(q,p)$，希望新变量仍满足标准 Hamilton’s equations $\dot Q_i=\frac{\partial K}{\partial P_i},\ \dot P_i=-\frac{\partial K}{\partial Q_i}$；Poisson 判据可以做到这一点：

$[Q_i,Q_j]=0,\qquad [P_i,P_j]=0,\qquad [Q_i,P_j]=\delta_{ij}$

引理：Poisson bracket 在 canonical coordinates 下保持不变。 设旧变量为 $(q_i,p_i)$、新变量为 $(Q_i,P_i)$ 且新变量满足上述判据，要证对任意两个光滑函数 $f,g$ 有 $[f,g]_{q,p}=[f,g]_{Q,P}$：设 $f=f(Q,P)$，利用链式法则 $[f,Q_i]_{q,p}=\sum_j\left(\frac{\partial f}{\partial Q_j}[Q_j,Q_i]+\frac{\partial f}{\partial P_j}[P_j,Q_i]\right)$，因此 $[f,Q_i]_{q,p}=-\frac{\partial f}{\partial P_i}$；同理 $[f,P_i]_{q,p}=\sum_j\left(\frac{\partial f}{\partial Q_j}[Q_j,P_i]+\frac{\partial f}{\partial P_j}[P_j,P_i]\right)=\frac{\partial f}{\partial Q_i}$。

设 $g=g(Q,P)$，由刚才的关系和 Poisson bracket 的反对称性得 $[Q_i,g]_{q,p}=\frac{\partial g}{\partial P_i}$、$[P_i,g]_{q,p}=-\frac{\partial g}{\partial Q_i}$；代入后

$[f,g]_{q,p}=\sum_i\left(\frac{\partial f}{\partial Q_i}\frac{\partial g}{\partial P_i}-\frac{\partial f}{\partial P_i}\frac{\partial g}{\partial Q_i}\right)$

右边正是新变量下的 Poisson bracket，即 $[f,g]_{q,p}=[f,g]_{Q,P}$，说明 canonical transformation 保留了 Poisson bracket 的代数结构。

现在将 Hamiltonian 改写为新变量的函数 $K(Q,P)=H(q(Q,P),p(Q,P))$；对任意 $Q_i$ 使用链式法则 $[Q_i,K]_{Q,P}=\sum_j\left(\frac{\partial Q_i}{\partial Q_j}\frac{\partial K}{\partial P_j}-\frac{\partial Q_i}{\partial P_j}\frac{\partial K}{\partial Q_j}\right)=\frac{\partial K}{\partial P_i}$，由引理 $[Q_i,K]_{Q,P}=[Q_i,H]_{q,p}=\dot Q_i$，于是 $\dot Q_i=\frac{\partial K}{\partial P_i}$；同理 $[P_i,K]_{Q,P}=-\frac{\partial K}{\partial Q_i}=[P_i,H]_{q,p}=\dot P_i$，所以 $\dot P_i=-\frac{\partial K}{\partial Q_i}$。

Hamilton–Jacobi Theory#

Hamilton–Jacobi equation#

通常需要求解 Hamilton’s equations 这组关于 $2n$ 个变量的一阶常微分方程，而 Hamilton–Jacobi theory 尝试寻找一个新的描述：通过一个标量函数 $S(q,t)$ 把原来的动力学问题转化成一个偏微分方程，这个 $S$ 称为 Hamilton’s principal function。

考虑第二类 generating function $F_2(q,P,t)$，它定义的 canonical transformation 满足 $p_i=\frac{\partial F_2}{\partial q_i},\ Q_i=\frac{\partial F_2}{\partial P_i}$ 且 $K=H+\frac{\partial F_2}{\partial t}$；现在令新 Hamiltonian 恒等于零即 $K=0$，则新 Hamilton’s equations 变为 $\dot Q_i=\frac{\partial K}{\partial P_i}=0,\ \dot P_i=-\frac{\partial K}{\partial Q_i}=0$，因此所有 $Q_i,P_i$ 都是常数。 将生成函数记为 $F_2(q,P,t)=S(q,\alpha,t)$，其中 $\alpha=(\alpha_1,\ldots,\alpha_n)$ 是一组常数参数、对应新动量 $P_i=\alpha_i$；由 $K=H+\frac{\partial S}{\partial t}=0$ 以及 $p_i=\frac{\partial S}{\partial q_i}$ 得到

$H\left(q_1,\ldots,q_n,\frac{\partial S}{\partial q_1},\ldots,\frac{\partial S}{\partial q_n},t\right)+\frac{\partial S}{\partial t}=0$

这就是 Hamilton–Jacobi equation，它将原本关于坐标和动量的 Hamiltonian dynamics 转化成关于标量函数 $S(q,t)$ 的一阶偏微分方程。 这里需要一个技术条件：所寻找的 $S$ 必须足够完整，能够定义所需的局部可逆 canonical transformation；不是任意一个 Hamilton–Jacobi 方程的解，都能单独提供整个系统的完整运动。

time-independent Hamilton–Jacobi equation#

如果 Hamiltonian 不显含时间 $H=H(q,p)$，可尝试令 $S(q,t)=W(q)-Et$，代入 Hamilton–Jacobi equation 得到

$H\left(q,\frac{\partial W}{\partial q}\right)=E$

这就是 time-independent Hamilton–Jacobi equation；含时 PDE 被转化为不显含时间的方程，求出 $W$ 后可通过生成函数关系恢复轨迹。

以一维自由粒子为例，考虑 $H(q,p)=\frac{p^2}{2m}$，Hamilton–Jacobi equation 为 $\frac{\partial S}{\partial t}+\frac{1}{2m}\left(\frac{\partial S}{\partial q}\right)^2=0$；尝试解 $S(q,t;\alpha)=\alpha q-\frac{\alpha^2}{2m}t$，检验得 $\frac{\partial S}{\partial t}=-\frac{\alpha^2}{2m},\ \frac{\partial S}{\partial q}=\alpha$，代入方程确实为零。 进而 $p=\frac{\partial S}{\partial q}=\alpha$ 所以动量守恒；新坐标 $Q=\frac{\partial S}{\partial\alpha}=q-\frac{\alpha}{m}t$，因 $Q$ 是常数记为 $\beta$，于是

$q(t)=\beta+\frac{\alpha}{m}t$

这正是自由粒子的匀速直线运动，其中 $\alpha$ 是动量、$\beta$ 是初始位置常数。

对于复杂系统，若求得完整的 $S(q,t;\alpha)$，可通过 $\frac{\partial S}{\partial\alpha_i}=\beta_i$ 得到运动轨迹的隐式关系；这里 $\alpha_i,\beta_i$ 是 $2n$ 个积分常数的一种参数化方式，要得到完整解必须满足适当的非退化条件。 注意我们不是先解运动方程再构造 $S$，而是先找到 Hamilton–Jacobi equation 的一个完整解，再通过生成函数关系恢复运动，这正是 Hamilton–Jacobi 方法的价值。

Hamilton–Jacobi Theory 与 Action#

Hamiltonian formulation 中的 action 为 $\mathcal A[q,p]=\int_{t_1}^{t_2}(p_i\dot q^i-H)dt$；假设

$dS=p_i,dq^i-H,dt$

展开得 $dS=\frac{\partial S}{\partial q^i}dq^i+\frac{\partial S}{\partial t}dt$，比较系数就得到 $p_i=\frac{\partial S}{\partial q^i}$ 与 $\frac{\partial S}{\partial t}=-H$；把第一式代入第二式，正好恢复

$\frac{\partial S}{\partial t}+H\left(q,\frac{\partial S}{\partial q},t\right)=0$

这说明：

  • 从 PDE 角度看，Hamilton–Jacobi equation 是关于 $S(q,t)$ 的偏微分方程。
  • 从变分原理角度看，$S$ 是沿经典轨迹计算的 action 函数。

注意到，任意路径上的 action 是一个路径泛函；而 $S(q,t)$ 则是固定端点条件下，沿经典解得到的函数。
